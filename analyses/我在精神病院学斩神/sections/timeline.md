# 叙述顺序、历史与终局时间线

先用六卷定位第一次阅读时看到事件的顺序，再用后文回查同一事件在历史、时间干预和宇宙循环中的位置。卷界采用底本目录序号，卷名据卷末正文题记及作者感言。独立作者感言在序号和笔记范围中占位，原稿误题、重复段和改写稿见[底本校勘](../source/底本校勘.md)。

## 按历史、干预方式和世界层回查

| 时间或叙事层 | 发生的事及辨认依据 |
| --- | --- |
| 西汉与两千年后的当代 | 林七夜和乌泉实际抵达西汉。第一圣约及其后续履约、镇邪司与守夜人的继承关系、迦蓝入玄阴木棺等待，都从这里接回当代。林七夜遮蔽因果后，档案证据留下空位，后世人物认出他还有其他途径。[抵达](../notes/segment-341.md) · [因果遮蔽](../notes/segment-349.md) · [入棺](../notes/segment-358.md) · [传承](../notes/segment-359.md) |
| 1921年与当代昆仑 | 昆仑遮掩褪去后，剪影重演1921年生还日。见证与守碑段相接，古今人物分别作出守护的选择。瑶池现场另有可辨别的时光剪影，众仙能说话却不能触碰，侍女却接得住现代手机。[瑶池](../notes/segment-220.md) · [生还日](../notes/segment-225.md) · [诸神铸碑](../notes/segment-227.md) · [当代守碑](../notes/segment-232.md) |
| 沧南的十年及到期之后 | 维持原居民的期限与后来出生者的存活条件不同，到期时需要把原有人口、其间出现的新生命及已被留存的灵魂分别追踪。一年昏迷是此后主线跳时，终局重逢则须核查保存魂魄和培育肉身的因果。[十年到期](../notes/segment-065.md) · [一年](../notes/segment-068.md) · [重逢](../notes/segment-012.md) |
| 同一次行动中的不同抵达时刻 | 曹渊比队友在日本人圈多经历约两年。分线所呈现的时间差应以每个人实际抵达为起点，人物再次碰面时才有共同现场。[人圈时间差](../notes/segment-132.md) |
| 渔村局部循环与王面的后来干预 | 货币、食物和无法离开村子的经历先建立循环，老王面在距当代五十余年的节点拦下化鲸，后来承认未能救回假面。危险再从另一条路径出现，后来救魂也需要另找载体，回溯另有寿命代价。终卷见到的将来有其分支条件，可被后续选择打断。[循环](../notes/segment-186.md) · [化鲸](../notes/segment-195.md) · [假面](../notes/segment-210.md) · [回溯](../notes/segment-189.md) · [救魂](../notes/segment-315.md) · [终卷分支改变](../notes/segment-405.md) |
| 集训中的虚拟重构 | 白泽与唐明轩的遭遇在重构中可以随参与者选择变化，林七夜越过幻境边界后见到自称林七夜的孩子。原历史、教官取得的证据和本次演练的结果各应标明。[重构启动](../notes/segment-287.md) · [越界](../notes/segment-291.md) · [重构结果](../notes/segment-292.md) |
| 宇宙循环及其外侧 | 林七夜反复做梦以反向同化阿撒托斯，墙上刻字、病院信箱及灰层记忆让尝试能够跨轮累积。迦蓝和灵宝天尊在灰层保留记忆并回演旧关系，外力伸入梦境时永恒天庭守住地球。此前的王面干预、渔村循环、昆仑剪影都有各自的观测证据，引用时应注明作用范围。[墙上刻字](../notes/segment-418.md) · [信箱和灰层](../notes/segment-419.md) |
| 终局世界 | 新世界落在新生的第五宇宙。星币给过夜幕短暂回归，终局留存的人与记忆各有更长的因果链，最后以重逢、寻找与日常结束战争叙述。第2007章安卿鱼离别时请林七夜记住自己是谁，并表示他们会找到他。此后第2019章的跨层敲门与第2021章的归家可分别回查。[星币](../notes/segment-409.md) · [门前约定](../notes/segment-417.md) · [记忆留存](../notes/segment-010.md) · [新宇宙](../notes/segment-012.md) |
