# 全书文风与技法｜视角、断章与信息后揭

范围为冻结本地全文，正式段001–390。以下用可复查的场面说明写法及其读感。

| 写法 | 原文做法与读感 |
| --- | --- |
| 以主角第一人称为主，偶尔换观察位置 | 开篇主角从轮回中的感知入场，随即写父亲在产房外焦急，再交还主角视角。到天空城防御段，又短时进入敌将判断，从窗后红光读到盖次伏击，战后才解释遮掩气息的安排。[目录单元1，第22–24行](../source/张三丰异界游.txt#L22)、[目录单元658，第36009–36021行](../source/张三丰异界游.txt#L36009) |
| 章末丢出具体用途，次章很快验证 | 第二节停在主角收到猎鹰、想到一个主意。第三节开头就取水晶球试验，视觉反馈说明用途。第五节再由父亲低估、祖父看出军用价值，给试验加上人物反应。[目录单元2–3，第82–93行](../source/张三丰异界游.txt#L82)、[目录单元5，第229–236行](../source/张三丰异界游.txt#L229) |
| 用空间观感承担说明 | 迷雾与幽灵先限制视野，出雾后拉远到银色巨城，再落到“建筑门口下方凌空”的异常。体量给奇观，缺路的细节提示它依赖另一套交通方式。反过来，战斗面板式列数字若脱离动作与判断，容易拖慢推进。[目录单元539，第29214–29237行](../source/张三丰异界游.txt#L29214) |
| 让读者先看见异常，延迟交代因果 | 七君主现身前，神、圣两天使向主角神秘一笑，叙述者也不知道意图；后记见到婴儿眉心标记、听到其自报名号，才得到印记解释。井内分身的修炼同样事后交代，隔联解释了第一人称为何此前不明。[目录单元898，第49565–49567行](../source/张三丰异界游.txt#L49565)、[目录单元899，第49669–49675行](../source/张三丰异界游.txt#L49669)、[目录单元900，第49739–49750行](../source/张三丰异界游.txt#L49739) |

“贫道”的自称与现代口语频繁混用。对话既能用质疑和惊叹替设定提问，也会直接搬运大段战力、配额与工期，形成说明停顿。尾声把话权从昔日上位者转给父亲，改名争执本身就是收尾的笑点。冻结文本还含错号及个别重复、疑似插入，见[文本质量限制](../source-quality-review.md)。
