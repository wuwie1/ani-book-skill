# segment-185｜至宝耗空、备用者收尾与战果向军政资源转化

完整正式阅读；ordinal474–475，原470《邪神下场》、471《再次出征》；[1904917,1914520)，9169非空字符。三次[1904917,1909317)、[1909317,1913717)、[1913717,1914520)无截断至章末。B透镜。邪神此段真死、封印散，里牙缴械接管回证；邪眼征讨仅出发/途中，不能记攻克。私人段落不复制性细节。

## 反逃逸封印迫使动用至宝，也暴露使用者能源门槛

1. 邪神蓄大术时主角才发现台场许进不许出，顶晶力场封台。估其全向十四级以上是主角未见完整释放的预测，不能列为邪神已施十四级的战绩。逃不掉才祭七彩混天绫，非开场一直从容掌控。
2. 混天绫来自旧赌赢后师尊重炼，封三足金乌能吐炫疾天火；书内称能毁大多数神器/灵魂/法术。这是传承和加工积累的资源，不是眼前材料即时造神装。
3. 绫捆护壁而非肉身，天火实烧化盾，迫敌停蓄大术转全防。火仍要时间/灵力供，当前供能小、敌全力外吐魔力能暂顶。器本身很强和当前使用者能否坚持是两项。
4. 就在敌求饶时主角先耗尽，收绫落地；忘了现境界用至宝耗大是其自认失误，要后续液态灵力方可随意用。不能只截取“神界最强火”便记无限秒杀，亦不能把停手全解为宽恕。
5. 敌也耗空但正常恢复比他快，僵持不利；他嘴称自己恢复快是在周旋，内叙明确相反。原“原则绝不收残暴者”与稍后愿试真降的念头有张力，须保留人物言行变化，而非替其道德宣言消除矛盾。

## 库存备用者发挥作用还需最后一点启动能量

1. 怒龙与海怪仍在，但放海怪也要一丝灵力开玉瓶；主角延话争取恢复。这使备用不等随时零代价可调用，先前若再无一丝灵力仍有实际危险。
2. 敌承刚才求降为缓兵、出去将吃他，逼近时海怪被放出。其平时不惧低一阶海怪，此刻无力抗拒，被卷入口吞下；不是海怪正面跨阶打满状态六翼。主角主宝耗敌→低消耗备用者收尾，比单人一击压倒更贴实际因果。
3. 邪神精神印记消散、顶晶闪后成尘，这是死亡与封印终结的现场信号。主角还想取晶却落空，巢无宝，不能虚构取得封印巨晶/邪神宝库。获得不是必须每战掉落贵物；本次主要在解权/伙伴成长。
4. 海怪称能吸部分记忆/能力，全部消化几百年、部分一个月须勿扰。升阶只是一般情形的预期，眼下收瓶休眠；不能登记已进化六翼或立即有全套蛛精神术。强食物成为潜在能力资源，也暂时占用重要战斗伙伴。
5. 主角此前反对将弱者当食物，此处命海怪吞邪神是明显的惩罚性/敌我选择边界，不宜用“众生平等”单句概括其全部行为。食用强敌在文本被写为反惩回报，分析保留这与宣言的伦理张力。

## 胜利的认证机制与政治接管

1. 数日回里牙受欢迎，祭司自己因感应与强气息消失确认神已死，非仅主角宣传。信仰系统原提供统治，也提供旧权崩解的可信信号。
2. 忘忧宣布脱旧控制、建独立王国，世家早控/预知所以拥护；叙述明确长期恶习非一夜变，部分人只改拜更强者、图国家机器利益。支持建国不等价值观都已改造，不能以欢呼代替制度结果。
3. 182外派守军到里牙被诓入街道、数倍军居墙顶屋顶包，齐卡里立缴械。他保己与部属命兼靠新主，是现实强制和位置劣势，不是纯靠家长温劝自然心悦。上段“家族劝降”计划未删，但实际兑现方式以本段围城缴械为准。
4. 宴会世家与新降团长证明他们被纳入新权力接触面；忘忧不喜欢应酬也要作为主人履职，是维持联盟的治理劳动。未展示宪制、分税和远城常态行政，不把成立宣言说成所有制度已完善。

## 过去技术服务积累成当前支配力

1. 出征带主角旧部、齐卡里两万、五百世家精刺，兽先知/三皇子/九公主五百亲卫观摩不实际参战。先前免税任务换兽十万远征混乱仍是另一行动，不将此五百观摩等同大军已交割。
2. 隐蔽项链与永久破魔兵并非这十余天凭空全产；忘忧数年前抗邪眼时耗长时间精力造，神语封器是炼金术，足材可永久。旧防御投资保下族群，还让收宝世家感激服她，解释今日关系资本来源。
3. 该能力也引邪神窥伺，迫其想提前立忘忧继任；技能有收益也增被控制风险，不能只写“有技术所以所有人自动尊重且安全”。本段回证早前“两次大危机/世家服她”的部分机制，非读者须无证相信全能领袖。
4. 扑里卡什经调查真是忘忧棋子，本段才由猜变确认；她正式交给主角，他派倭岛探情报带惩罚意味。未解细节的173/180怀疑不能继续孤立写“具体者未知”，亦不可扩为所有暗夜部下全背叛或教廷已得机密。

## 战果向贸易与新领地扩张转化的限制

1. 兽一部分押主角给的东西/工匠回兽地，一部分送其物回博拉姿，表明贸易运输已启动；没有货值清单和抵达证，不算每一件合同全履约。
2. 四地资源区分：穴地粮最多能供兽五十万，暗夜粮自足略余/矿少，邪眼粮缺却地风火晶矿多、少水晶，混乱稀金属多。主角明说逐利又借解放受控者正名，两个动机并存，不能写纯公益或反过来否认真实受控者。
3. 矮长愿十万、叔祖想青龙，主角因长途体能/袭击驳回：普通人即有水粮到达率也仅三成估、抵达无力，矮不如兽、工匠不可耗。矿产价值没有取消路线成本，合适兵种物流决定分工。三成是他判断非已死七成人。
4. 邪眼约十五天路过半水路；暗夜数百小船原抢穴人，每条几十位，只领导坐、兵沿河走。便利不是大军全员船运，船所有权也有掠夺来源，贸易走廊的效率不能抹这层历史。

## 轻喜收尾也显示现阶段能力与装备权限

途中主角/忘忧合用空气枷锁和飞剑追叔祖，他以过去借的传送戒脱；忘忧定剑神只半秒，飞剑离远就赶不上，改瞬发雷才命中。属玩笑场景，不据此记叔祖真实重创战败；但短控/距离/借物在谁手是明确条件，不能任意把同一传送戒同时算双方即时可用。章末盖次能载人恢复到何水平未给量化，不因现身便说耗尽已全复。

## 净变化与未决

邪神死/封印消，海怪吞敌但闭关至少月；主角至宝耗能失算被备用补救。新国获公开支持/旧守军实缴械、齐卡里纳入出征，旧装备和人才关系资本回证。贸易在途，扑里被确认并调倭，邪眼战役启动，资源分工物流理由更清。邪眼控制解除、晶矿取得、混乱攻占、海怪晋级都未发生。
