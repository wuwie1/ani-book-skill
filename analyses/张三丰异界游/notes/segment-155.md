# segment-155｜审讯所得、物证控制与情报眼线

完整正式阅读；目录ordinal414–415，原410《拦路打劫》、411《安插眼线》；固定快照[1592063,1603711)，11058非空字符。分[1592063,1596563)、[1596563,1601063)、[1601063,1603711)无截断到章末。B透镜；审讯供述与实见行动分开，投诚未验证长期可靠。

## 从兵力威压取得可核查的人名

1. 主角借熊高位看见护卫习惯围保中人，识真实首领，逼摘面罩，认出十二枢机排第三的福罗塔。组织保护队形反成识别泄漏；不是主角预先知道所有身份再假装问。熊吼压马、克里能取魂使自杀也不能保密，构成肉体/死后双重威胁。
2. 福先推若兰、要证据，主角明说此次不用证据、荒僻无人教无法追责，以前送人者受苦灵魂示范逼供。后供叙事在强迫下取得，不能消除胁迫语境；后有组织关系、物品回收/录像等独立动作支持不同部分。主角利用敌暗杀的法律可否认性反施，不是公开公正审判。
3. 主角内心更直说放尼科最重要是祖母亲情/她军权、对狂信者长/龙族影响，希望至少保持中立；教皇用伯父无论谁死都伤两边关系为其推测。对比154道德高洁口径，这是多因解释的重心补充，不能宣称原作只按善恶赦敌。

## 供述揭幕后，但时间因果仍有缺口

1. 福供圣山神罚后教皇装病查自然教，尼科此时相见自责，补其早年卡特探友见年幼香香、因可爱和德鲁依不见数百年不报裁判所。自然教只有主角领地不受教管、可发展信徒，除主角便可重控、赶德鲁依、待香香寿终再灭。由此给152主角关于组织节点的解释添了供述证据；仍不证明“教一定最终成功”。
2. 教皇亲指挥、福外联兽人骗主角、祖母被瞒；借西思尔最后计划顺组联军。选若兰因外交统筹才、避免卡两皇子争帅，若兰以光明玉救命恩拒；教扣其父霍宰相、迫写信，才令其任帅。**父被扣**在这里从主角猜受控变为福具体供述，但不抹若兰实际高效组织侵略的自主策略和造成的伤亡。
3. 福说绑票是汉石原大主教出主意、挑目标，还计母而未敢动；两女被石原小犬突然近身拿下。150无名黑影与内奸线至此获得具体指认来源，非主角亲眼见抓捕，更不是可把所有石原族人直接证成参与者。主角灭门/泡圣水万年为愤怒威胁，未执行。
4. 福另称还有独立班子对付母亲/各亲，若自己失败且自然教公开才可能抓人；这是备用计划与可能条件，不是母已被抓。教皇圣战前曾秘密失踪、再现年轻且态度大胆，首令借他手杀主角，福据此猜神界保证。秘密去向、与神界具体联络、真正最初杀因均未知。
5. 主角对时序做关键反推：神罚第七天才收兽林信，而与兽谈判早已开始久，故杀他策划**在神罚前**。不能沿前一段“神罚后查自然”直接把全套杀因压成神罚报复；教皇为何此前就顾忌主角，连福也不知。保留这种后揭未解，比替原作填一个完整单因更准确。
6. 福还供海外信魔君早知、教数百年想统一群岛、海啸为魔君水禁咒、海军尽损陆军损半仍苦撑；主角推组联军也为削三帝，以便教维持压制。其附和是供述层支持，不等读者已见海外所有战况，实际数字须保口述出处。

## 为什么不杀：不是内幕越多越有用

1. 福为保命依次献旧罪、情妇私女、秘密库：主角拒绑无辜/不信教皇肯赎；库仅知圣山周围，范围太大、己神识当前不足遍找，消息不可直接执行便用处有限。土遁/戒/金莲能盗库也需准确位置，技术不自动解决情报精度。
2. 真正打动的是未来教皇针对主角的计划。祖母传讯被教有意放过，核心有用情报专瞒她，故既有高层亲缘渠道并不具备内部完全访问权限。福站教皇近身、专负责对付主角，信息位置才构成保命价值；区别“知道丑闻”与“可提供及时威胁预警”。
3. 主角不信福名誉誓、血书也能否认，不因同一世界有强誓就所有人皆可信。克里后来问为何不禁制/魂契，主角说教皇洞察可察任何手脚：外部控制越显，卧底越容易暴露，需换成组织内可归咎的约束。

## 主角编排的杀同伴、负伤和录像

1. 福指百余护卫属裁判所是监视己，只有蓝提自己人，主动要主角全杀。众护卫怒攻，蓝提护福斩同伴；福光盾/辅助与黄金高段蓝提暂抗，但围中受伤、难久支。主角此时诱蓝提持其背的霜剑，加清心咒短护，近剑神力量屠尽百余人；**主角未亲挥剑不等无参与**，是他选择工具和时机，死者“皆无辜血债”只是其泛称未逐人核实。
2. 蓝提杀后瞪主角，却在熊吼/药性下丢剑昏，内脏被侵，主角说短时/预防令休几月可好。清心咒只能延缓失性，不能免身体侵蚀，再次验证147魔剑成本。福关切透露蓝提实际其儿，亲子情既可合作又是可被利用的脆弱点。
3. 主角替其造回报故事：遇暗夜部队、众护卫战死、蓝提持神器击退、福护伤员归并带霜剑立功。实际敌袭/英雄因果是**伪造叙事**；真实伤与真神器作为可观察佐证，让假原因更可相信。主角称为安全返教牺牲神器，实把灾星送教而保眼线，是隐藏目的，不记无私赠宝。
4. 克里复制水晶录下音像，展示他们杀部属，再录福半日教皇/组织内幕供述。物证较血书更难否认，被用作若背叛送教便受罚的把柄。其所谓“忠诚”主要基于暴露成本与求生，不是信念认同；未来可背叛，主角承情报要仔细验证，至多损联络人。**这“至多”忽略联络人生命，是其风险口径而非分析者认可无损**。

## 战果回收与新动作

1. 怒龙残片、两瓶蜜、冰冠及公主装备实际回收，霜剑留福；155才兑现151“先毁关键可替部分、以后收残件”中的收回部分，修复未出现。神之领域戒也实获：尼科老衰不能骑马留敌营，临行交福急送还教皇，恰被截；不是主角亲闯营夺尼科或戒已被教皇回收。
2. 福与蓝提获放返教，如何遮失戒损物/是否成功蒙教皇尚未知，主角只信其善糊弄。尼科身体老衰、不能护神器的余波直接改变了转运链，让强戒进入可截获节点。
3. 主角暂缓石原报复待联军退，先欲拿占领区教会黑幕开刀，借米诺亚随从身份亲见揭黑，试改其信仰又使教难直接指自己。仅计划，米还未办/改信，三帝和退军未结。

## 章末净变化与反例

已取得近身枢机受胁眼线、录音像把柄、原赠物/残弩和领域戒；百余裁判护卫被福/蓝提在主角安排下屠尽，蓝提数月内伤，魔剑留教作回归功劳。旧人质幕后得福指教皇/石原/小犬，仍需保供述来源，最初教皇杀因反而因时间更早而未解。限制：卧底情报未验证、物证不保证绝对忠诚、禁制会暴露、夺库需要精确地点、送灾星可能后患、强制策反和亲子胁境不能包装纯经营善举。仅本段已读范围，不补石原灭门、修弩、戒使用或母遇袭结局。
