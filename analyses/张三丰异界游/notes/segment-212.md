# segment-212｜救援计划被真实情义改写、新神器熟练差与海权收益

完整正式阅读；ordinal529–530，原523《女神发威》、524《魔鬼的报复》；[2173481,2183774)，9879非空字符。显示[2173481,2177881)、[2177881,2182281)、[2182281,2183774)无截断至章末。B透镜。开头私密内容不复述，记录主角在场/行动原因即可。双天使已被雅救走、三魔仍活，联军舰队遭灭后主角将准备占倭，尚未正式占。

## 叙事回看补视角：不是所有战报都来自远程转述

1. 忘忧早发现朴，将主角心印拉到千米外云中，全程神识看战，再拉雅执行夺镜；210–211大量战场所知此段给实际观察位置。不能据此倒说主角当时在地面亲见每个牧死亡，也不全当二手战报。
2. 他们发现镜让朴独骚二天使不成互耗，主动插入夺镜以得宝/立首功，而非先前计划所有变数都已推中。战场形势需要调，主持者不是全知。
3. 雅能量仍略超熊、次于蚊，刚夺宝靠技巧不等本体常态六翼；实际出救前主角一次性补灵力到六翼，用完不能自己恢复该量。204丹有提升不代表共享所有人恒成最高档。

## 双天使的选择改变雅的行动，收益算计没有完全主导

1. 原定等两者半死/魂才救以最大感激，堂嘉帕皆宁死让公主走/求报仇，真关爱使雅感动不忍，要求改计划早救。不是表演只为收最大回报而所有同情皆假。
2. 主角同意支持，称非英雄却义士不该不公；对立者也有值得护的行动。这和208漠视岛民表态并存，分析保具体不强求全人类一致善恶。
3. 雅信主角方案不思考同意夺镜，是信任，不代表其智慧低；战争格依旧有战术智。两格智慧分配不等一个会打一个只会思而完全不能互用。

## 短突击分工回收出逃通道，敌的恢复很强但有针对性损耗

1. 三分身各打三魔：枪含空间裂缝迫朴移/伤百口，未中心核所以其魔疗能复大半身；逃一位开圈缺，外四小见三六翼冲不拦，雅带两天使穿。脱围靠击走一节点/外层不愿拼，不用把七全杀才能离。
2. 杖耀光掩空间刃让斯误霜剑硬挡崩花生口，旧神器损坏后他不懂修，这是实质长期资产损而非只肉体痛。之后棍法伤其私处属非露骨记录的羞辱性战斗，圣能未清使伤复慢；不复刻身体细节。
3. 盾反泽火破其非全开盾/圣炎棍砸头，表明专长原理（反回本力）还需对方当前防护条件。不是随便盾一举立秒任何状态。
4. 魔外伤难看可几年复、战力仍八成以上，不能看伤严重就立即判濒死。回生/抗性与伤口审美分开。

## 分身阵形与反射带来心理限招，敌却有保留术反应

1. 雅本应随救后撤却继续化三摆三才阵，三兵盾游，圈一伤一；魔凭瞬移/恢复续。主角认为没下杀可早杀是其判断，未实际逐个杀验证。
2. 斯大斗刃被盾返斩脚后都留招怕自中，压制来自实克制示范后的决策，不只总能量对比。七魔攻围却协调渐失，前“默契不可挑”不能独立作永远优势。
3. 魔退百米三角、合十四幽明炼魂狱近瞬发/烧一分钟，千米柱毁城成坑。每魔平存珍火不愿耗，被逼才合，敌也有存量、合作和高招，不是只会挨打骂。
4. 雅用新夺八咫异次空间躲后现/棍击，真会运神器。朴盗前一年/后几十年才学，敌据自己学习时长误估她尚不会，是知识熟练差形成的新优势，不是器一换手自动所有人都会。她具体学习过程未给，不能补瞬读全部法诀。
5. 神器自身规则避主位面覆盖与已读“发动需时可时停”相容，不把避十四术升级成任何控制都无效。

## 队内资源丢失改变政治秩序，怒气转向弱者

1. 斯泽羞愤怪朴笨、踢并分四大岛，朴失镜无制衡只得受，前同伴互敬本依威胁相持。丢一资源不仅战斗弱，还失议价/居地/尊严。
2. 朴用岛上百万联军可泄火转话，魔各去港追，非一时心软和睦。斯二最大、泽另二、朴小岛，属实际分占安排，主角说他们是手枪是其利用评估，并不代表其命令控制三者。

## 战略回报真正发生，但伤害与收益不是同一评价

1. 数日沿港屠/烧舰，陆有分散林活，海几全无生，教三帝海军近名亡不能接残军；别写所有联军百万一人不存，旧补救/兵量全没独统计。
2. 海防空/盗猖/贸恐慌，己三国有护舰商不怕，实际垄断大多东西远贸并涨价得利；时间窗口把此前保存/造舰转现实经济收益，不是只战争勋绩。
3. 二十年追不上是预测非已过二十年结果；涨价会使谁负担未展开，不把垄断自动写普惠繁荣。
4. 主角利用魔毁敌后拟收魔占岛，尚未下作战实收，霜剑/勾玉仍敌手，不能把新镜和所有三器并记到己方。
