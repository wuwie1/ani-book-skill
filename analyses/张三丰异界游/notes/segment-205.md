# segment-205｜藏宝定位不等宝物到账、稀缺材料的错位价值与人质谈判

完整正式阅读；ordinal515–516，原509《神秘小岛》、510《惊现海族》；[2103130,2112705)，9077非空字符。显示[2103130,2107530)、[2107530,2111930)、[2111930,2112705)无截断至章末。B透镜。宝藏已定位但移居人鱼处且多损坏，尚未收回；族长拒以全族冒救人风险，主角拟亲自露面尚未谈。涉及未成年人身体侵犯只非露骨记事实/拒绝/权力差，不复刻描述。

## 多种知识共同定位，异常仍没有立即解谜

1. 图最后由忘忧/若兰核、主角风水判阴聚却无阴而热，列练邪法/怪物耗/宝压多假说，不确定。若兰以热带解释遭区分，不能把主角任一猜当真相。
2. 图有神秘力/有人莫名死警，众因旧卡取过/强丽在而上；好奇、怕丢脸和资源收益压过谨慎，非客观已排所有风险。
3. 忘忧分前后左右护、若兰与主角熊中，海怪留海送熊；二十米熊穿两三米林如践地，后怕踩池缩，尺寸与环境保护需要调整，不是队伍仅靠等级自然无影响。
4. 岛兽只火/不畏强队，若兰指出不寻常；主角神识见火口躲探能却抓不住。侦知异常不是定位其本体或可获知全部，火山隐藏力量尚未揭。

## 图例与地貌互校，藏宝室空引出取证而非新战利

1. 见梯田状白石温泉，忘忧才认图曲线，此前图看得懂大方位不等细部全知；结合现场标记才找瀑后岩堵。
2. 开石进入百余米，宝室只朽箱/无魔波。主角先探无危险放进，之后才想到本该有魔器波动，是检索目标错位：查安全不等查目标库存。
3. 怒疑王骗，若兰提醒保命者或不骗/首次取人复来；主角据旧卡杀人灭口、船长/海路/管制大船否。这里对无漏网的肯定依旧王口供与判断，别把所有归途细节当本段亲见。
4. 石地非人鞋划、连钉全拔、取后还堵门三证，若兰查而不识；主角结合听过海族/登高看淡水河走向，推住岛，追河。学识不能直接看一痕就全知道，需要具体不合常理行为拼合。

## 新族的隐蔽技术与人质策略

1. 河中两生命肉眼不可见/水无纹，主角神识能感，承水隐比陆气隐难破。其用羞辱挑反应判不像训练刺客，是不可靠的行为推断层；后真见人鱼才实证，不把一次反应变普适识族规则。
2. 抓现一少女时发生非自愿身体触犯，后另被制服，爱/玫等继续不顾拒绝身体接触，忘忧才叫停。书内当笑闹，分析应保受害者哭拒与实力差，不能叫互相亲近或因女子对女子便无侵犯。
3. 两者魔导师/力举千斤仍敌爱一手/玫法神禁，说明相对力量与个人尊严是不同维度。不能从俘虏动不了推她们同意全部所为。
4. 不肯问答后忘忧放一留一，威晒死达诺娃逼请族长，口称无恶；海族可两栖却晒几小时会死，威胁有具体种族生存条件，不只是温和请客。
5. 罗娃要求别跟/抓到可杀，忘忧应按“若你能抓到”漏洞，立派主角水遁跟。承诺表面允许、实凭能力差绕，是本段信任风险与不平等谈判。不能总结成双方已互信合作。

## 财宝的使用价值因技术与生活目标不同而错配

1. 跟百米海深洞再上陆殿，壁画四翼主/六八十翼对火界兽有组织战争，人工痕迹明显；主角粗看震惊但无时间细阅，不能先给年代、阵营和战果。
2. 两百余人鱼住旧殿/破壁雕作地界，魔饰照光、杖当鱼棍不合长折断、宝壶作日器。数千物实见而损不少，主角估收回价值半失，非专业清单定价/已全收。
3. 钉都取解释金属稀缺/当地用途可能，与主角基于市场的高价值不同；文本未完整说明人鱼全部动机，不能分析自造贸易偏好数字。
4. 主角称“我的宝”源夺卡王旧图/索藏，不等岛物法定已归。欲因其盗宝糟蹋折卖身、先听不合即打，含资源正当化支配新族意图，不能用“先礼”标签掩质/跟踪/威武底盘。
5. 原拟收海族强水法助海军，是重要组织资源动机，尚无族同意；丽被奴环强控已经出现的情境也使“愿意合作”后续需核条件。

## 族长知险不救一人，敌对者有独立生存模型

1. 罗娃述姐妹只是没见人类想看，遭羞辱想冻教训又见强宠吓不敢，仍被抓。此补前半主角“可能偷袭报复”信息，不等对方已施杀法伤己。
2. 族长责女违规外出，指出既被看破不应再接近、先问跟踪/六翼可信，再痛苦拒救；他说族群全上不敌，保延续让达自负。不是无感不爱孩子，是优先族存与不信人类。
3. 其他族人愿救，说明族内不只单声，族长仍压回。其认为无人能跟却实际已入，信息劣势影响决策，但对六翼不可敌判断没错。
4. 主角评明智狡猾准备亲劝，尚未揭形/达成条件；不能提前说几句话收服两百人鱼/取回财。

## 净变化与待核

温泉标找到藏穴，却宝空，查三线后追河见两少女人鱼并质留达诺娃/放罗娃，引主角潜入两百余人鱼旧殿，财宝数千损坏/古战壁画初现。族长拒救全族冒险，主角待现谈。火山避探力、壁画源、产权/赔偿、达安全、海族同盟与藏宝最终价值都未定；史莱姆醒否此段未述，不能随时间自动补已成。
