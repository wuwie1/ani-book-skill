# segment-217｜天空之城现身，阵地系统与军种配合重写战力比较

完整正式阅读；ordinal539–540，原533《天空之城》、534《古城探密》；[2225451,2235804)，9879非空字符。显示[2225451,2229851)、[2229851,2234251)、[2234251,2235804)无截断至章末。B透镜；刚从藏兵洞见四十二人营房，未入内搜索，城市控制者/可用性与箭技是否存留未明。

## 解除表面障碍与找到真正目标是两回事

1. 雾影响方向与时间感，主角神识神目定位，丽斗气清百米保队不散；环境对弱探子致命，却被本队分工绕过。不能由探子未返直接推此处有超过六翼单体。
2. 幽灵外围不敢入光圈，物理免疫而怕魔法/尤其光；爱感暗敏锐，若兰香仍恐惧，知识或战力不自动消掉情绪。主角等先隐瞒为免惊，结果听到幽灵仍惊惧，保护信息亦有边界。
3. 丽一道光环清十几里雾与幽灵但未伤树，随后外雾涌补，没清全域。主角要求省力赶路，表明大范围强攻只是短暂通行，不能当生成原因已解或内部威胁已灭。
4. 原估需走五十多里到中心，实际三十多里出雾见花地巨城；旧侦查地图是近似而非全知。天空城高三千米、宽十余里，倒锥尖扎地，材料银白非金非石、空门台阶无街、无人久废，是当前观察；它能否恢复飞行尚未试。

## 历史提供估值模型，须保留来源层级

1. 主角/若兰/丽皆识思托尼亚的多名称，忘忧不认识而问；智慧神格并不替代本地历史。若兰据文献主讲五六千年前翼人亿口/强国、风神伯鲁丝、箭术风术炼金优势。
2. 全族五百余年造神庙成城，拖国力丢半土；建成作为高空战具数年夺回有余，体现长期投入与短期军事脆弱并存，不是大工程一开即收益。
3. 银材料钢数倍硬/十分一重、全城到房间层层阵计算复杂，众推风神设计/关键动力参与，是从结构能力推测，未检查动力得证。文献“几乎无敌”有其当时条件，不升级成对所有神族都无敌。
4. 丽亲经历失踪事件：己天使被围请城救，魔皇弟亲王精锐设伏，她接讯到时只尸、城不见；她未亲见最终失踪机制。忘忧猜与魔族有关虽合理，尚未说明现在谁据城。

## 本段真正的知识回报是把堡垒拆成协同系统

1. 外部白骨辨翼/石像鬼/吸血鬼/梦魔骑士/两魔龙，龙断骨焦黑；丽据破损不匀/高温判断雷非火，主角推城禁咒，忘忧粗算一翼十魔损失。都是遗迹证据上的推断，不是本段复演旧战。
2. 数万球柱分大小可放闪电，丽从翼人听最高十一级，但龙尸疑更高，承对方可能有隐瞒；不把盟友旧口述当精确完整武器参数。上部有柱/下部球突，尚未逐个操作测试。
3. 丽回述一次城以不足十五万对三十万王牌/几十魔龙，战七昼夜损三万、敌返不足十万。能量后期耗大、攻降伤增只是听说可能原因；不是已知能源永不枯。
4. 忘忧指出六翼配大军或可攻克，丽承旧指挥未到六翼、强魔因高傲和惧天使捡漏不出；战果依敌部署与政治风险，不只城体材料。主角追问七日为何天使不援，丽明确不参指挥/多在天修、听战间消息，原因仍未知，不能自作已证盟友故意陷害。
5. 藏兵洞两米、成千上万贯上下，提供直接穿城转场/扩大进攻面；伤员退治、补箭、强敌追入受邻近电球火力。单兵弓技未必超魔精锐，堡垒改变暴露时长、补给、安全退路和兵力投送。
6. 若兰估每洞十人几秒出射百箭再回，属于运用条件的计算示意，不是现场已打实数；香见铠甲密箭孔为历史效果旁证。空中通道适合翼人，不能不改造就假定无翼人类也同效。

## 主角从观光转为明确求取，但尚未入账

1. 主角因打法合胃口决定占城，爱推皇都神庙或有箭技档案，主角联想旧圣光魔弓铁骑只偷皮毛已强，拟己造对天使军。此时只有搜寻目的，不是秘籍已得、翻译教习和规模部队已完成。
2. 众选下洞捷径，主角带熊、忘忧带香、丽抱若兰、龙载爱，飞行与护弱分工继续。入洞需盖次缩熊、龙化人、丽强缩；丽不适且战力降一成，建筑空间本身构成强者限制。
3. 洞有晶石照明/无异味，支营房仍乱被、箭木杆箱体风化，说明废弃与材料寿命差；看见箭头不等全军库有效库存。四十二床布局推房可住四十二官兵，尚非已清全城人口编制。
4. 章末主角停门免灰，众初探兴奋。没有本段新敌登场或城已收服，不因标题“天空之城”提前归其资产。

## 净变化与待核

雾中安全通行并发现思托尼亚；通过文献、丽回述、尸骨/城体观察建立战力和资源价值判断。可复用原理是火力、掩护、周转与补给共同扩大单兵效率，但它以翼族机动、长期工程/神助、能源与敌未出高阶为条件。主角新增占城与求箭技意图，城主/失踪因果/能源/材料配方/档案完好都未证；强缩丽带来一成削弱已实际出现。
