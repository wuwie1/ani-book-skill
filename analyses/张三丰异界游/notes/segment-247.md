# segment-247｜安娜旧史补完、治魂仍需专能与倭岛接管的压迫条件

完整正式阅读；ordinal600–601，原593《准备回家》、594《再见亲人》；[2512760,2522084)，8798非空字符。显示[2512760,2517160)、[2517160,2521560)、[2521560,2522084)无截断至章末。B透镜；肉身毒除但魂毒待爱治疗，已从冥回骷髅岛并见爷祖母新城。末人口不到两千万/青壮近绝，长期治理后果未解。原作对倭族贬损/集体奴役仅作为叙述立场与压迫事实分析，不认可其群体本质论。

## 安娜来历补完，但信仰属性仍不能按外貌归类

1. 军官要死后抹其自我作性奴/尸作战具，她怒用皇血禁龙魂诅咒，肉血爆能杀其肉、魂逃转生；不是她无反击任宰。禁术代价魂坠冥，骨架也随来/光力保留是其亲历，不必因罕见造其他暗幕后神救。
2. 刺她的逆反/吸灵枪随骨来，可把异能转光、抽死气和杀取亡灵魔力使在冥修光。枪是父藏/自己送/被反刺/又回身的连续资产链，既信任背叛物证又解决长期能源瓶颈，不是神圣属性凭空无来源。
3. 军官名比特，主角联雅内报八翼大攻头目，安娜以八翼少不重名确信；读者有强同一性指向，但严格是双方合讯识别而非当面对质。主角谎称丽供为藏雅，后续检索不能照其公开话把卧底消息全归奴环读忆。
4. 雅只主角忘忧完全知/仙雅模糊见亲密，直联无第三，隐线分层说明补前“仙雅核心”不等她知雅全部身份。

## 去除载体毒不等治好灵魂，强能力也怕伤己方

1. 三膏天火烧久未尽，加火几分钟才清；龙自行十余分钟清背绿/补骨，外伤净化成功。眼残绿/魂痛仍在，区别外观修复与根治。
2. 主角天火会连魂烧不可用，需不伤魂本源光神力；爱有其质但回去才试，安娜不确信。216污染转生池/低魂承不住疗光的旧规则仍不同条件，不能用“光”一个词把所有疗法同化。
3. 龙百年服务已同意而治魂尚未完，后续真实履约需核；没有因病把期限改成无限奴役。

## 运输能力与产权争执同时影响返程

1. 骨不能缩，不赖克轮回开不了安娜体量大门，传门并非任何大小都通；她索坐标/斧后切两寸柄炼指套欲占整斧，称替法师减负是资源整合辩词，不能掩未经允许取用。
2. 主角绫夺还斧/责强者须守规，柄部分因不赖克让步留给她；先压再同意有权力环境，不叫原先全免费自愿赠。斧主人原轮回借给不赖克，用他人物改善通路仍存产权链。
3. 她以自材含十斤秘银/圣炎炼指套刃，用空间材/坐标划拉百米大门，众实际回骷髅岛。能力条件是材料神器特性+大体/技，不等她无器任意通界，主角仍未获传送阵技术。
4. 冥骑说明安娜曾劫其他小亡灵堡得财、被围袭多回，补其不只是神族伤害的纯被动受害者。主角说劫龙贪是评价，事实须写其具体行为，而非全龙类本性。

## 新同伴有自主边界，也会越界欺弱

1. 安娜回阳喜悦，愿免费载主角一程，仍对盖次不满并折腾到吐才停，后施光治；亲密/报恩不等自己不会加害伙伴。主角干预限玩而又用食馋不能吃骨龙报复，队内并非天然成熟平等。
2. 六佣交不赖克安排最好材金液，安排已下尚未见晋王，别把许诺当完成。

## 倭岛接管已得当面证，但统治性质不能粉饰

1. 爷祖母飞出新城迎，实际坐镇和城市已建，推进此前赴岛未明接管。马场上千棚/千工/数千纯马运来，热不适曾昼泼水死少、今减浇，产业迁移有气候适应与劳动投入。
2. 工人被叫倭奴、供食/不随时致命条件换顺从，零星反抗遭同胞告，爷用己方打退教军的假恩话术。其社会秩序源战争废墟/饥饿/奴役/强权，不从受压者求活推“天生奴性”。
3. 原文主角爷以民族化兽性/活该奴隶解释，分析明确标人物群体贬损立场，不接受为真实人性规律，更不能把它提炼成管理方法。组织效率与非法剥自由是不同评价账。
4. 用本地人刑讯反抗者、祖母目睹吐/怕肉，说明压迫不只外敌屠杀，也有新统治方接续暴力与招用；其声称本地酷刑更狠并不洗清授权者责任。
5. 爷称已占所有宜居地、控不到两千万/藏野少；主角比战前四千万少两千余万归教战残，青壮近绝/多老弱妇孺使人口还将降。来源为爷统计/主角比较，非逐户独立人口普查；不能由此给全族报应式合理化。

安娜骨/光源、比特仇敌链补完且有雅保密谎来源，膏载毒外清/魂毒待爱。空间大门经指套条件解决，众实返骷髅岛/爷新城，接管当面证与强制劳役/刑讯、人口崩损同时出现。三千骨龙采购/月拍货仍未对账，爱能否治魂/未来对比特/人口治理后果未知。
