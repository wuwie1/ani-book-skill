# segment-187｜群体解控重构战场，以及坐骑升级的被隐瞒成本

完整正式阅读；ordinal478–480，原474《华丽扑街》、475《捉对撕杀》、476《换个小黑》；[1925100,1934900)，9375非空字符。显示[1925100,1929500)、[1929500,1933900)、[1933900,1934900)，无截断至章末。B透镜；普通邪眼溃败、两龙制服/一龙解控签约、十二元素被杀，暴君逃且被追，尚未伏诛。

## 约战不是单靠藏一张强术，而是组织供能与地形拖延

1. 到齐敌军实仅五六十万，不是原百万：旧战未补、近期追杀和集结损失，等待又缺粮吃掉几万己方。既有库存与行军后勤真实削弱规模，不能把最后标题写为一术击败满百万。数量是主角现场估。
2. 忘忧临建数亩、数万符号阵，海量晶粉主要来自主角卡王室收藏和矿产；五百精法、两百德鲁伊、两百独眼巨、五百暗法供魔。高精神力负责快速排序、多人/阵省积能时间，十三阶术才可十几分钟完成。单个人类大魔导几天的差距不是只因“她聪明”，是财富、专业法师、人种能量与技巧同时到位。
3. 魔力总量据主角足十四阶却只放十三，是任务适配选择，不登记十四术实际施出。施法波动大不能藏，敌立攻要打断/散阵，不能说对手毫无察觉。
4. 苍龙角变龙给数万人加持，周围森林/迷雾让敌绕迷路，三路战士保护阵，兽人也守一侧；此前说其仅观摩不实际参战的计划此处变化，不当作永久事实。
5. 忘忧即成时主动撤林，免树影响法术，再释放能量波；控制地形有开启/回收时序，不是只种森林就能一直兼得所有效果。此前敌防刺密集，反适合大范围解控，说明同一防御调整会形成另一弱点。

## 醒世之光的跨体系复用有旧研究和当前阈值

1. 前世对精神控制神族吃亏后雅典娜研发群体解封，转世听邪眼又改进、旧入侵做过实验。之前没用因法师少、不能一网打尽；不是突然凭空临战创出必胜禁咒，也不是有知识就一直可施。
2. 波过大军倒地是解思想封印后昏迷，不是几十万被屠；醒后记忆回。此战救控目标与186少杀亚人的战术保持连接，不能以“扑街”标题误作全体阵亡。
3. 全法师包括忘忧施后丧战力，换取普通邪眼失兵且散/慢，被骑兵和大刺客追杀；法术成本转由仍完整的战斗兵承接，不等法师本人还能随意连禁咒。
4. 暴君精神强保两龙/火元素等核心，恐爪兽群多数本来由兽王统而非直接邪眼封；所以不是群体解控对所有层级无条件有效。节点结构不同，法术只能覆盖对应封印结构。

## 残余精锐按弱点分配，同时诱导暴君离开组合防护

1. 克里飞空用大傀儡控数百恐爪兽使自斗，地面兽够不到；上方大蚊刻意露气使暴君不敢反制。他转逃/派两龙阻主角熊、十二元素阻兽，是有决断的保存自己，不是完全不会安排。
2. 主角承故意露蚊把暴君与强宠拆开，蚊隐息跟踪。尚未回报追获，不把“不能逃出追踪”信心记为实捕。大蚊此前留克里看家与当前同行是场景人员安排已变化，不能机械延旧地下不适理由排除其本战出现。
3. 主角绫挡龙息、缠嘴翼、旋转摔昏；龙防高未骨折，转晕才失战。此处绫没开天火，使用模式与185耗空不同，不据一次束缚成功删掉天火高耗限制。
4. 爱莲娜叫熊装小诱抓，熊骤大/藤缚/重力/压翼困另一龙，显示她会主动学诱敌；但善良不等每种信息都掌握。兽王及恐爪群仍只说克里接近结束，不提前全数杀尽。
5. 兽族分散强战士靠近无护元素法师，三比蒙/两剑神/十余剑圣使其无法发挥完整火力，十二核实到。十三阶联术未展示，不能因能预测合阵就写实际曾轰军；克制环境和兵种是消灭高伤害者的条件。

## 小黑之死是主角预谋，不是黑龙一次偶发失手

1. 表面龙乱喷火烧死铁背狼王，爱莲娜悲伤自责，以为它没听躲远命令；后内叙明确主角授意盖次暗藤捆狼送龙嘴边，并用熊身遮她视线。此事实必须独立保留，不能总结成“战场坐骑不幸损失后获得升级”。
2. 她原来拒换且已让狼避战，主角以五级配不上新实力为由替她决定牺牲，之后谎称狼或想帮她。资源效率主轴在此有强反例：更强装备/宠物并不抵销伙伴情感、欺骗和未经同意剥夺。
3. 爱莲娜仍说龙受控身不由己可饶，不把她短暂怒打当永久残暴。主角把“补偿”转为选一龙，她拒杀狼那只选另一，只因不知道真实幕后，表面欣喜并非知情同意牺牲旧伴。
4. 主角夸盖次配合并安慰爱莲娜，是读者独知的操控关系；不得用全局成长收益帮其遮丑，亦不设计后文会揭穿/报复，尚无她得知真相证。

## 解封交易形成新骑士，但自由条件并不完全透明

1. 主角需先制服/静心深入意识海才可解暴君封，不能像暴君隔空控放；元神强不等任意远距释放一切俘虏。
2. 被晕龙愿用百年做人类坐骑换长期自由/归友，主角破封、她践诺，美迪亚女士实成爱莲娜坐骑/化人并要求不用小黑名。人格尊严/命名选择在交换后仍存在，不是完全无声坐骑资产。
3. 但杀暴君后同伴可自然醒的另一途径被爱莲娜说出，阻主角趁她求救再敲一回。第一约是否完整告知替代方案没写，不能把主角内称“划算”当无信息差公平交易的证据。
4. 爱莲娜精神力因赠力高，签黑龙判断并实际成功，是前次馈赠经战斗成长转成新权限；尚未展示双人空战/长期磨合，不能一次签约就说成熟龙骑战术全成。

## 净变化与未决

群解控使五六十万控制军倒、普通邪眼遭追，法师团全空；黑龙两只制服、一只美迪亚破封签爱莲娜，另一待暴君死自然醒。小黑实被主角/熊预谋送死，爱不知；十二火核到兽方、拟以粮换仍待交割。暴君正逃/蚊跟，恐爪群近尾，晶矿开采/铁器缴修/混乱供铁未入账。结构发现应同时写技术跨体系适配和操控他人选择的伦理代价，不能只以升级回报覆盖损害。
