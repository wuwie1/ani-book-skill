# segment-151｜投药产业链揭示、先换人后决斗

## 私密信息如何变成对手示警

1. 冰公主转述若兰反复说草原乌鸦夜飞、毒粪、“久病成良医”和盖次毛数清。主角据此判断她察觉五千翼人投药、药理与熊底牌，并有意借冰传讯；不是若兰当众坦白，更不是主角对其心理已全知。她此前留两女过夜的举动在此取得可追索的传话用途。
2. 爷问她是否装傻待解药反击，迫使主角补救治吞吐和原料限制，而非仅用“毒厉害”解释。爷又提醒教廷既知熊仍敢设围斗，应有对策；主角相信教只知女神灌力前旧熊，现熊翻倍、自己飞剑另备，可以出其不意。旧情报更新差被用作信心来源，具体胜负仍待验证。
3. 军情显示若兰把一半军向后调、霍军全走；主角推她知毒救不了、保存本国兼为自己留路。他不知道这些军确切去向，先前149的扩水道/南路命令仍在读者信息中。因此不可把全部调兵确定化为逃跑，也不能因他断“败局已定”便将战役提前结算。

## 投药的完整资源与组织链

1. 主角在王都听联军来袭即写信博拉姿准备，由巫师千余药方中挑选一种对马有特异作用的药；口鼻沾后原配七日死。急需大剂量、希望延迟发作，巫师连夜改方，未足量试验就送来。主角自报八成把握，承百万马、营延数百里，临制药是否有效没有十足把握，旧日胸有成竹并非实际已观察完结果。
2. 五千翼人在草场投放，地面数万军昼夜警戒遮护、底层抱怨却不知原因；直至昨天才撒遍敌养马草场。延迟窗口用于等全域覆盖，若早死则敌警戒保护余马，若剩三十万骑就难速胜。这里用药效时差对抗组织预警，需准备、保密、投送同时成立。
3. 普通牧师驱毒可治，解药方也不难，主角却据敌牧师数百不足千、每人日十余匹判断不足救百万马；原料更受地理分布限制、几味草原没有。大量毒料来自领地几乎全体精灵法师催生，内心补明**德鲁依才是主力**，否则连配药人手不足。对敌公开只说精灵是保护自然教身份，不能把两层口径当不同实际生产线。
4. 领地积累的巫师、德鲁依与翼人分别承担配方/生产/投送，天险防守替药效等待时间，形成跨专业组织工程。主角计划雷达继续巡查、不见敌马死光不出击；这是风险控制指令，尚未见执行记录或死光清点。德鲁依待吸收九级魂才公开对教抗衡也仍为未来门槛。
5. 原七日方与当前改延时方应区别。主角当前说距全发作还十余日，不能据最初“七日必亡”自行判时间错误，也不能写成撒药当天就扫空骑兵。目标是毁交通/战力，未见人的毒效，主角明说对人无害；这仍为其药性说明，非分析者做现实药理保证。

## 去器不是简单丢资源

1. 主角不愿违明日答复的誓名，爷宁舍名护命，体现组织信誉与核心人的存续可以冲突；决斗不是只有感情一条原因。冰宁不换自己妹妹也不交神器，主角则另有处置计划。
2. 他称怒龙过于显眼，使敌法师藏起来、各权贵觊觎，自己吸收甲虫能量后的飞剑可数千米取首，更适合藏底牌。这里是主角自评与新战术意图，不是已经再用飞剑验证所有远距必杀。
3. 最初说劈碎弩，随后明确仅毁弓臂/弦，关键部分可找替代修，待赢战收回可伪装“已坏”再袭。其恢复能力有条件——先拿回残件并修复；不是弩已重新入手。他把危险霜剑丢给敌方，爷确认一次使用十余分钟后仍浑身痛，147损体限制延续，非万能神兵无成本升级。
4. 新武器代旧器，同时利用社会认知的滞后引敌出头；不宜抽象成宝物随时可牺牲，怒龙关键部件仍被保留、后续回收并未发生。

## 交换闭环与教廷担保的悖论

1. 次晨若兰先要赢决斗才还火，主角坚持先换器人后斗；她再次向普通军官请示获点头。主角拒第二次发誓，以怨灵永久痛苦威胁；若兰因前日实际魂刑整夜不眠，此刻被迫让步。魂已被克里收入杖，不是日出即释放，恐惧有持续心理成本。
2. 双方采用牧师交换：通常俘虏、赎将谈判用教担保，虽教明显偏敌，主角仍赌其公开场合金字招牌与后续决斗需要使之不敢造假。**同一组织是幕后绑架者、台前中介**，信誉并非普遍道德清白，而是特定场合约束其失信代价。
3. 火公主实返，两女拥抱哭，150“明天救妹”在交换意义上兑现；两件武器也已送出，不再写成只提出条件。主角秘密以三昧真火炼断弓臂/弦只余表面相连，法师灌魔拉至一半即全断，崩伤两旁观者，一人断腿、一人腹穿将死。隐蔽破坏已验证，不只是构想。
4. 若兰未亲收器而误以为检查无碍，军官得报插话才知坏；她表面怒、眼含笑、敷衍追问，老者知不能退人遂不追究。主角公开以神器不愿助恶、自选主人搪塞，这是**刻意假说辞**，真实因果已由内心交代是炼断；账本不能把“神器自主毁身”当世界规则。
5. 若兰退远避爷上次大战余波，六人到城前千米：两个近马赫级、四强，其中冰大魔导师斯特拉里，余三爷识旧敌。实际出场比此前“两个普通凑数”仍需分参照层级：近马赫强并不等于顶层三怪。

## 妖剑旧史（尚未叙完）

爷与对方互认，妖剑能千米外听小声谈，威胁杀孙报复。爷述其一百五十余、旧采花杀人受多国过亿悬赏，化装潜逃使围捕失败；当年跟踪祖母圣女、爷、阿尔伯特及喀秋莎，轻视年轻人，忽略喀秋莎。四人诱至山崖，祖母微笑分神后联手伤腿堵路。**章末停在此处**，旧战如何获胜/他如何活命、现三高手完整底细均未读，不补后事。叙述中的性别侮辱和贵族相貌论是角色/作者口径，不是分析者事实判断。

## 章末净变化、承诺与反例

新增可核对链：药方→改缓发→德鲁依催生/配制→五千翼人投放/数万保密→待马病观察→拟骑兵追击；最后两步未兑现。双方公主均归，双器已交；怒龙试用断裂证明技术破坏，霜剑危险是否反噬敌方尚无结果。六敌现身、妖剑身份部分揭露，决斗仍未开。未来检查：马毒实际覆盖/死亡与解救吞吐、调军真实目的、隐藏熊能力是否足够、旧史结尾、神器回收修复。反例包括毒方试验不足、己保密也耗军心、对手识药、有条件恢复、酷刑强迫与表面信誉并存；不能据本段把原作经营归纳为无代价聪明。
