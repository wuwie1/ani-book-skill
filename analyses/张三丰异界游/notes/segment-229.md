# segment-229｜城防体系压制单体，微力干预破开协同

完整正式阅读；ordinal564–565，原558《金属战士》、559《大获全胜》；[2343451,2353032)，9191非空字符。显示[2343451,2347851)、[2347851,2352251)、[2352251,2353032)无截断至章末。B透镜；三金属将被打倒未死、疾风未倒，高森十四级大招仍蓄力未发，墙塔是否毁/城主应对未知。标题大获全胜不扩整城已服。

## 登陆受阻后，城方以兵种与设施接力

1. 塔数十黑线不破高森斗防但冲力使空中无支点者飞退，远火力作用含位移/阻进而非只算伤害。228他诱齐射侧移只能过首层，不能由此跳过多层防御。
2. 火金属帕克五米近踢被高森硬拳轰退嵌墙/足变，说明单体低一档；随后足自复不是不可破坏，恢复时间给同伴拦截用。此时只见现象，合金配方/能源仍未知。
3. 疾风箭插胸，掺秘银克暗、重心工艺标准，高森当场精确述尺寸重量识地精大师造并获射手确认，支持工艺来源，不等全城亚特蓝身份已独立承认。战士的铸造知识不因狂暴/弃锤消失。
4. 黑斧轮回/金骑杰斯/银弓疾风与帕克自报名，轮回像未报真名仅主角猜。四皆海怪档却配合可悍六翼；金属人说话/人格与恢复实证，不能仅因材质叫无意识机器。

## 输出窗口与属性协同，使较弱集体伤更强者

1. 高森先攻静骑避免其起速，四人箭牵/拳斧枪同落；箭故意在三强击破防后到眉，不是巧合抢中。诅咒体不惧头心致死却不等不受伤。
2. 自然力箭加秘银对他难受，单箭有限但累积可害，使改优先疾风；此是目标优先级基于伤害质和持续性，不只看表面哪招力大。
3. 疾风借杖偶散弹网限闪、塔线止冲再射防弱、帕克接击、轮回断身、杰斯跑满冲圣枪串控。不同火力层、地形、属性与时序合让高森连防来不及，不能算四个同档裸人对一的纯等级比。
4. 主角承多人外借塔但战前没约禁止、高森吃亏不冤；一面仍以废物辱敌，评价不当分析事实。忘忧说己奴只己能打是占有权口径，非保护同伴即自由平等。丽已对面潜隐未出，不能记她救高森。

## 再生与适应让交锋转长期僵持

1. 高森被贯枪仍自脱，恢复腰伤，近拳断马倒骑并打瘪，换掉最怕的持续光力；杰斯过后能复立持剑再战，打倒不等杀死。
2. 疾风发现头心非要害改肘膝，打断动作换同伴喘息，是对诅咒体的主动学习；高森双近战强仍被箭牵而无法速赢。
3. 双方可恢复、耗长外队等，不是主角无限闲等；胜利时间成本促其从观察转干预。三金属者身高大而跟不住矮灵活，近格局影响命中，不是只哪方金属硬。

## 隐形微干预比大输出更能改变组织结果

1. 主角一丝仅够杀鸡剑气斩飞箭，偏尺使原射高森肩箭打杰斯剑，防剑歪才高森拳中脸。小能量通过关键时序接口放大，并非气弱也能直接破同级护甲。
2. 后续几箭被导向同伴，疾风识有人而找不出，只好停箭；消除远程牵制后，高森可专压一个、挨其余换拳，先瘫杰斯再帕克再轮回，形成局部逐个解。应把主角暗改箭列为因果，不写高森独力公平四胜。
3. 轮回明知独力不行仍不愿弃友，坚持劈到己倒，敌方亦有同伴忠诚，不能扁成无灵物/自私无组织；其动机是叙述内明确。
4. 三被锤变形短时不能战，没有魂灭/死亡证；恢复能力仍在。城产材料/技师/维修流程未谈，不能把暂失战力等于永久损三上将。

## 合作优先与示威升级之间的张力成为选择

高森将放至少十四级大招，主角预期墙塔毁/疾风拆可能。忘忧警会妨交友，他允许，说不死人、易重建，需示实力才值得交友。227入前轻让/伤不杀原则在是否毁重大设施上被扩解释，主角把重建人工充足当损失小，不代表城主同意或总成本已知。此处尚未发，不能预写其成功被挡或城已毁。

## 净变化与待核

城多层火力和四将协作一度压高森，属性/控制与防御窗口比单体等差更关键；高森再生/对方金属自修使僵持，主角用微剑偏箭截协同，三将暂倒。地精大师箭工获确认但不等失城全部背景解；十四级蓄招未放/疾风仍在，主角以示威换合作的策略尚无外交结果。
