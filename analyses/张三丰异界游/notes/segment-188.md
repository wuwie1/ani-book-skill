# segment-188｜俘虏转生产、粮食换矿与地上强制财政的回声

完整正式阅读；ordinal481–482，原477《收获多多》及又一477《大陆风云》；原文重复节号保留，以ordinal/字符区分，不改快照。[1934900,1944425)，9147非空字符。显示[1934900,1939300)、[1939300,1943700)、[1943700,1944425)，无截断至章末。B透镜。情报部分为商队带回大陆消息/主角读密信和推测，与地下现场分层。

## 追捕利用持续防护的耗能，而不是正面层级碾压

1. 暴君欲投混乱找共同敌，但还没抵达成盟。大蚊隐身风刃切弱盾伤体，盾开强就不动，半日后放小再袭；威胁迫其持续大耗，要不死只能降。对方能识这是耗魔计，仍无速/侦察解法，败因不是不知道。
2. 没有对话拖谈/公开决斗，几记风刃加多处伤逼服。它几次拖延/求面见都遭逼行，说明俘虏服从仍非心悦。大蚊抓活而主角本意杀，部下有选择与偏好，战果不总按最初统帅想法产出。
3. 主角与先知单追因不怕控制，忘忧耗空留处理几十万清醒者的吃喝，死亡魔兽作粮暂缓；不能只记救人数量而漏安置与供养劳动，也不能说休息者没参与后续治理。

## 收俘收益压过复仇诉求，却有新的控制问题

1. 先知以狡猾可能反叛暗示杀，主角承其俘虏不能轻杀的身份顾虑，再听用途。先前先知因别一暴君伤侄恨这一只的族类迁怒仍存在，不据此给此俘补同案罪。
2. 暴君依次报残部/矿分布与魔兽挖快十倍/混乱情报/旧藏，主角故淡反应套更多，自承很感兴趣。十倍开采是暴君求生承诺，实际后文采矿采用雇佣，不登记该效率已实测。
3. 先知因铁器允诺转关注，后来实得斧锤而默认收俘。利益补偿缓盟友面子，但不代表对方真认可其道德理由或被害者意见得到代表。
4. 回城群众愤怒须己兵护，忘忧实收暴君为宠；危险能力进入己方控制而非被消灭。主角拟以后专抓高级魔兽是新用途构想，尚无新捕宠成果。此前“邪眼全部灭掉”应限定旧政权/部落军被瓦解，领袖活留。

## 战利必须鉴定，开矿必须安排粮与用工

1. 旧藏大量杂物/魔饰实寻到，质量不高交矮大师与精灵慢鉴；一些人制饰物说由混乱流出，是新线索非已定位古文明来源。把地下价低转地表价高仍需鉴定和运输，不能按堆体即报利润。
2. 暴君指引实发现十几个高产矿，相比旧领两矿，资源面增；主角称产量上去是将来潜力，不等本段所有矿已开始稳定出货。
3. 忘忧定雇解放奴及周围小族采，以粮换晶、暗夜警戒监督，缺粮地区愿投是其预期。暴君原提控兽挖矿没有成为展示的主要制度，不能把旧奴控制不变照搬为新经营事实；同时粮供与警戒有依赖，后续自由劳动条件仍须核。
4. 暗夜粮不够新增数十万人，只能领地运，主角粮满仓提供供给基础。拥有矿不等经营自足，跨地粮食盈余经商路输入才可支持劳力。
5. 矮用简炉回收敌铁、重铸重斧锤，兽人实际拿到。186预期缴铁→此段加工交付闭环，合兽体力规格不求精细。材料现场缴获省远调，但矮工时/技术仍是投入，不照主角“几把破铁器便宜”口气抹劳动。
6. 忘忧定条目交坚定追随的心腹管十几矿/几十万人/建中城，属实际委任/新地行政架构起步，城市未建完。忠诚有丰厚回报，仍无运行审计与防代理滥权机制展示。
7. 护货兽与商队回里牙，带所要物/大陆消息，前批“在途”此处补抵达；没有总货单利润，不编完成所有贸易合同和最终盈余。

## 地上军事胜利靠旧战后果、后勤与动员时间

1. 商队消息说石原在外男几全抓、五百多待大审；玄武被切后供/北四领协缉，尼古拉斯出征。对身份株连/家属威胁的反例继续保留，不以战胜就把血缘全部等同个体罪实。
2. 五万骑十五万马换马昼夜十五日、累死上万马，抢在敌预备役完全召回前到；速度有实物生命成本，非只靠名将称号。名五十万/常二十万/吃空饷精十二三万，以及前全国动员耗储都影响可用兵力。
3. 玄武上次马被夺未补，仅八万骑对上骑王败，后据城。尼不强攻，扫周边遣返预备，后本部十五万/近卫十万/青龙二十万接上，非单五万从头包打五十万。
4. 军官因大势倒转开四门，相关石原被捕，二狼倭岛募高手暂免、悬五十万且暗团寻。前面173支族/玄武未结此处主要军事结果补齐，但审判未完成、二狼仍没死。

## 废立与宗教认证尚在准备，不预支仪式

1. 卡王将被献俘、大汉即将帝国化、首帝选大王子非现王，是消息；加冕/献俘还未现场发生。主角认为大王子深心难控并非对方已反叛，爷为何选也尚未知。
2. 自然教将国教、香香拟国师/主持加冕，密信称自然女神将神迹助信徒，是政治宗教承诺。不能把“将”删掉写神迹已经落；也不能用主角傀儡王思路替代新帝实际治理选择。

## 教会以访问名义索税，声望与强制并行

1. 祖母带三十万精部访问堪帕斯，拒会成战争/敬神问题，接受又让军入腹。教廷仍顾另两帝观感不宜直接灭国，对手增近卫百五十万备撤；双方都有约束，不是教可以随时无成本灭所有国家。
2. 先前多战损高手/兵，削弱帝抗压，旧战争结果叠加到财政外交。两国使无消息，可能截杀或装傻是叙述猜，不能列确证教廷杀使。
3. 皇宫最低礼迎被祖母视慢待，劈城门楼致数百守兵死伤/官伤，以沙漏/列阵迫帝亲迎，带万军接半皇宫防。是实际暴力胁迫而非只靠谈判天赋，受害不因对方贵族拖税就自动正当。
4. 阿尔伯特密谈后祖母稍收，最终总三倍税即帝年税三成。主角猜他供教皇旧幕后所以放过，**谈话内容无人知、未证**；不能独立检索为祖母已证教皇杀子并彻底脱教。
5. 加税转嫁会把民众既有约七成收入负担逼近全收，是文中推算/压力解释，尚非已征百分百。财政收益有民变阈值。美格蓝先认欠与息仍不够，五十里礼迎/老帝哭诉在章末，最终纳额未读。

## 净变化与未决

暴君活降收宠，矿和藏实得、重铁实际供兽、心腹受命/新城建设，商队回。大陆玄武军事败/族人押审、二狼逃，新帝与国教仪式筹备；祖母堪帕斯实索三倍税/赴美格蓝未结。关键未知：矿产稳定出货/劳工制度、暴君长期可靠、混乱情报兑现、阿尔伯特密谈内容、加冕神迹/税后民生。不得以资源账增长消除控制能力收编、株连和暴力财政的反例。
