# segment-221｜器魂自修打开升级方向，城市经营仍有制造与保密瓶颈

完整正式阅读；ordinal548–549，原542《前因后果》、543《变态树妖》；[2266256,2275645)，8959非空字符。显示[2266256,2270656)、[2270656,2275056)、[2275056,2275645)无截断至章末。B透镜；塔解释旧战与当前能量，城市暂留，探险续行，末见空间来兽被树触手吞噬，尚未与香签植物契约。

## 旧战闭环由当事口供补齐，控制不是自由认同

1. 塔承不能离风神之心太远，否则力被吸回/魂脆弱，部分证若兰220困室猜测；其不是完全不能出球，但移动范围有限。高森塔相逢感慨身落奴位，主角先许外界机会再威胁毁本我炼兵，后许表现好给自由和好处，仍是胁迫关系，不得写因待遇好已摆脱屈辱。
2. 塔口供称自己杀族长/大司祭轻敌入室，被十长老用生命发动一次性摄魂封进神器。十尸整齐/魔尸门口因此获得因果解释，来源是幸存入侵者，不等所有细节外部独立核实。
3. 风神原留摄魂术让翼自行选魂：太强魂难控、太弱嫌配不上作品，解决制造者与使用者能力差的折中，却成为长老牺牲性防御。220称无认主/可夺控不等完全无反制；死亡代价与一次耗用不能忽略。
4. 城先以空间瞬移脱战耗魔，降插深林；附近双方随移者因空间扰动大多死，内幸存者继续战至两败俱灭。高森靠戒假死、塔成魂存，两人“活”建立在不同装置依赖。不是城被魔族安全开走后随意弃放。

## 能源原理与长时积累，将“器”改成可成长组织节点

1. 起初核心靠翼法师注魔，塔接时空了不能飞；转魔灵后数百年从原身体抽魔恢复六七成，曾足短飞。冒险者来被其杀并读魂，得魔败退消息，才放弃外飞以防大陆围剿。这是信息改变战略，不只是设备永远没能量。
2. 迷雾本是城市飞行云隐法，塔改用于落地保密；外围幽灵由战魂转化，吸体力/扰方向让来者累死，补足此前失踪原因。其死亡安保不是自然雾自动无心致死，塔有主动选择责任。
3. 风心与塔现一体，存能相当其力量；魔灵自修加城市吸高空雷，四千年存到八翼量/核心增幅可瞬十六级。由久时积累、环境输入、器增构成，不是只获一戒即无限能源。
4. 主角以旧蓄电池/现发电机比喻器魂可自行修炼，提出有魂神器可升级新领域；同时明确可能依风神特殊封印、需问风神，自己造不了风心层级，城市群须等。前半“尽情用”是兴奋夸说，不抹实际存量/充能时间。不能把仿造多城已开始或已解决核心当事实。
5. 一城不足对抗多少天使、重视样板更甚单器，显示资源价值含可学习潜力；但这里是原作人物的未来方向，不由分析扩写任何新书方案。

## 得城之后产生清理、修理、训练、保密的经营负担

1. 爱香想立刻开回展示，主角/忘忧/若兰要藏作秘密武器；然而原地不动也不行，破损需修、物清、大军熟环境训练。上万人调动受教监视，产权取得后才暴露运行成本与情报难题。
2. 若兰提出领地约三十万翼人，来源其早植探子做官、手工品产量/翼弓工厂等交叉推断；主角承数字准且官员少知。保密数字能被经济侧信息推知，权力强不等情报不泄，若兰旧对手经验成己方规划资源。
3. 上/下两层各挤住二十万，三十万全族可容，族性适合无街/飞通道。忘忧认为归祖城梦想可接受禁足，是她对意愿预测，未见与全族协商、同意和实际迁移。不得用“祖居”替代迁居自由事实。
4. 地远族不能安全赴此，最后定暂留原地，回领选隐地再开过去、利用雾护。实际只参观一天后离，迁城/迁族/封训/修理尚计划，当前可用城不等现已装备满员军团。

## 探险延续，知识从旧支线回流而仍容失败

1. 高森随队作肉盾以护弱，塔留核心，强部属功能并不相同。下一远点飞两日/搜一天只几七八级，主角归探子夸报是其解释，未证当年没有不同危险；再次显地图标签不保证珍稀收获。
2. 再一日夜见巨树，主干百米、云半腰。忘忧百万年树经验不符体量/应化形而未，表示旧知识有异常，非万能鉴定。香想美形作宠，主角先止近因为想起冥神骑士旧讲。
3. 回接早年瓦纳三战第三场冥骑赠史莱姆和战甲的支线：骑士经空间门遭巨树、伤失坐骑被水剑圣救。旧口述提供现风险线索，但主角猜同树/门由树制造钓异界，还未完全证明。体量罕见支持推测，不等逻辑上绝不可能第二棵。
4. 香凭女神祝福自信不受植物攻，忘忧以自然女神掌植物推可收；主角指出肉食异类未必听，能力规则出现待测边界，不预写一定有效。他同意保护香试，丽抱香、主角同行，其余弱者留外。
5. 高森主动求战既好强又不愿输丽，主角警步战难救，他仍坚持并误以主角绝对力量不比自己大。选择含信息不全、争面，并非奴约下只被动派遣。主角先轻功试他再御针剑，丽竞速，高森被甩开；终点“三个人类”依实际所见是主角/丽/香，不把高森自动记已同到。

## 树捕食现场证到哪一步

方圆几十里白骨杂异、来路几百里无兽，引主角预备绫；空间波动凭空落百吨鳄样兽，五十米坠不伤被估至少九级。触手反复生/断十再百、捆后十余秒不动、一分钟剩骨，证明树域内捕食及极强束缚/消化；不能据此定整个树翼阶、门一定由它自主开启或必免女神命令。未攻击主角队、未收宠、无新契约。
