# segment-159｜封锁救援、疲劳轮换与第二道防线

完整正式阅读；目录ordinal422–423，原418《血战无名丘（终）》、419《阻击继续》；固定快照[1635479,1645882)，9981非空字符。分[1635479,1639979)、[1639979,1644479)、[1644479,1645882)无截断到章末。B透镜；无名丘一次总攻结算已出，拦路岭第一波攻退但两帝未全降。

## 第一场并非从头到尾不存在险情

1. 卡罗不追溃军、插围丘敌后，狂龙五千仅两列放宽锋面，前疲由后替；所到暴雪停以免自己受控。对面冻结慢、薄阵才未被冲破，不能套成在所有健康密集骑阵中两列皆可。
2. 塔巴斯砍溃败第四梯队五万夫长与一师团长挂六首，逼第三/残四前进、前二死守。军官因家属可能受逃兵连坐督战，使敌没有迅速全溃，靠人命争重整时间。双旗不是只使自己更傻，也确实延缓崩溃；血腥制度效力与人命代价并存。
3. 狂龙本想杀退非全歼数倍敌，前夹未吃完、第三欲后夹，形势一度不利，若被围也可能严重损失；己方珍贵不能换。第三受溃四挡道/躲暴雪未补位的时间差，才给新空军封锁窗口。原作明说险情，不能用最后零死倒推所有步骤绝对安全。

## 飞龙从口头调动到可验证的战术交付

1. 百只巨型双足飞龙从林出，司认是兽人魔兽之森产，塔原以精灵森林飞龙尺寸误判；兽协作在敌眼中才公开部分。骑手背后各带精灵法师，百兽十队、每队十只头尾相连喷，毒团五六十米、十只线约四百余米，合几轮连成河到林十几里封锁，二十余分钟完成。
2. 毒不是直接向最多人群求击杀，而是喷空地隔梯队。飞行快、队形规范、地理宽度与第三未及时补位共同保证无缺口，体现提前训练/规划；何处何时整训未本段展示，不补具体演习日程。
3. 第三冲雾者逾千死，最深十米对宽五六十米不足穿；少数斗气高手可过却不足应付狂龙。个体能过不等组织救援可过。凝雾术由精灵加持，原“无聊游戏雾”转保存毒雾，司估三四日才散；原毒几分钟散被补延时，普通小法改造了大规模战场持续时间。
4. 司可勉开缺口，但百龙每只还能吐三十至五十次、当前不足三次，己团工程/战后油尽灯枯，缺口马上补。**资源恢复和补口吞吐**比能否单次施法更决定救援；三四日的具体预测未全度过，不当亲见完三天。
5. 塔两度吐血昏、由副手令原地休整，被围前二再冲丘求水路生。巨人棒慢/喘重真疲，最后逼近险造成伤，精灵召数千元素人替肉盾；四系相克故分四区，给轮换留组织设计。不能把巨人近战重新归无穷耐力，也不能让相克属性无条件混堆。

## 招降与第一场实际结算

1. 玫此时出场，以轻微群体恐惧加“投降不杀”令前二残部降。此前部队仍受血旗约束死战，心理崩溃/术与生路承诺一起才转降，不能说本来随时吼一声就都降。
2. 事后约五万俘，前二余者战死；溃第四约两万伤亡。后康川转述一天伤亡近八万另俘五万，应保统计口径差异、不把几个局部数硬相加造精确总数。己数百伤、**零死亡**为本场明确结算，不扩大到整个反汉战争。
3. 防盾/重甲护近战、射手法师在远离敌范围，暴雪使轻弓脆断/威力衰，数百伤主要半人马，给零死的机制理由；是否现实材料学普遍如此不由分析者背书。战果因地势/层次/气候/预备队合成，不只是“所有异族天生更强”。
4. 塔次日醒欲按双旗自裁，副官以古有半年战/还可援劝，塔自知普通军在窄地难过，最后因若兰恩和部属责任暂活，再求高手国内援、传若兰、求王子夹击。挂旗失败的文化规则并非写出即不可变；保人、继续战争与自我处置存在实际争论。
5. 塔据狂龙应不只万人、未见翼人推王子路上另有防线，这是他的推断，稍后得到实际新阵支持，非在空军出场前就准确知全部布置。知道劝降为玫后才认其为实际指挥对手，先前把每步均归主角的敌方口径得到补正；主角总筹与玫现场指挥并存。

## 通信、退途和拦路岭

1. 数百信使仅两三到王子，翼人侦察拦通信；但不是100%封绝，所以敌仍能调整，时间延误有战术后果。康川真元帅辅嫩皇子，早反对抢先但被不听；他反驳塔笨，认为伤亡与能林行部队说明对手强。
2. 康川先安慰可伐木渡河护王子、全军带不走，皇子重不被俘；主角军调水面万辆小船警戒，十余日就密巡，将他“河大封不全”的逃逸设想受新事实限制。小艇非战船、用作报警，附近森林材料和征用支持快速扩产；不把万艇等价万主舰。
3. 堪后撤时轻毒马实际成千上万日死，尼古拉斯跟五十里、不硬撞，河军协进。毒在第二军兑现延迟，迫敌急攻而不能慢试。距无名丘不到两百里、河林夹三百米山拦路岭，两千半人马挡，空间连续让另一次狭口拒止有条件成立。
4. 王子/康川一下投剩约五万骑与步，因马正在死、少股试射程无用，第一波后半人马后五百精灵法师直接高破坏群轰，数分钟前骑伤过半、余逃冲散步。**不同任务采用不同法术配置**：无名丘辅助多以延续多波，岭这里直接火力解急攻，不能把某一种辅助套路当全书唯一作战原则。
5. 章末只首波退，尚未王子被俘、康川成功渡河、塔自裁或水道永远清完。原军总数和去留仍待战后对账。

## 净变化和边界

已闭本场：百飞龙/凝雾隔援、元素人接疲巨、玫恐惧劝降，五万俘/己百伤零死；塔仍在求援，王子后撤被第二线首波击退、马继续死，河巡小艇压退路。前期兽礼/飞龙返汉、精灵专业和狂龙训练首次在此形成协调实际回报，但练队/部署所有过程尚未给全。

未决：岭最终战果/皇子出路、被俘五万待遇、塔双旗责任终处理、三帝谈判与教调查。反例：己巨人疲/被后夹险、敌军纪有实际效果、精灵元素相克需分区、毒封不是任何高手都不能过、王子活路是优先级不等全军活路。全书结论仍不支持。
