# segment-183｜恢复链、低阶连击与假分工创造的短窗口

完整正式阅读；ordinal470–471，原466《血战通道》、467《激战继续》；[1883982,1894566)，10130非空字符。分[1883982,1888382)、[1888382,1892782)、[1892782,1894566)无截断至章末。B透镜。本段杀蜘蛛将军一只，余三只和邪神仍待；不能把通道胜利登记为最终弑神。

## 先把战斗外人口排出，再利用敌方开放通路

1. 忘忧向囚犯公开否认蜘蛛神权后，以救命和服从建立当下指挥，放他们去释放其余囚者、带给养赴里牙，报其名获安置。人已被送出，但里牙实际安置/长期归属未写。救援不只是口号，行动包括释放、物资和接应地点。
2. 她已达调空目的，才承认杀旧祭和谋灭蜘蛛，早前假话并非因为真相不存在。俘虏老祭不知道具体封印位置，必须通过祭坛祈求邪神回应；名义职位没有完成继任仪式，也不等自动继承全部机密。
3. 邪神回应并把老祭血肉灵魂吞为开门能量，才显露四五十米高的山内洞。其对信徒的消耗是现场事件；主角称自己有把握却未证明这一步完全由他控制。找入口原来也难，敌方主动开放才节省搜索。
4. 入数十米后后路合拢、毒蛛遍壁，预先开魔壁免毒。没中毒有准备前因，不是地下毒气天然无效；退路被封也不能照章末乐观语气省略。

## 消耗战通过恢复能力重新分配成本

1. 开局小蛛弱，盖次先守等密集再十倍重力，让壁/顶蛛坠落，继石柱反复清场；利用聚集和环境提高一次施法收益。叙述用坠落动能作说明，作为书内解释记录，不据此推出普遍物理定律或所有地形等效。
2. 爱莲娜给体力恢复和大神圣恢复，盖次有大地天赋与法力之泉，三路恢复叠加；平时耗尽需月余，此刻估几日。低阶小范围重力/石柱可持续，是本队当前消耗结构下的判断，不能套到兽王咆哮或任何高阶术无限连放。
3. 大神圣恢复能回魔、斗气、神力，十级耗用而强效；通常只有苦修士会，牧师不当然会。自然法力之泉通常只回魔，盖次因自然女神神力才可兼回自身同系神力，仍不能回别系神力。这些条件解释跨体系支援的可用范围。
4. 两主角保留力量，让盖次/爱莲娜开路，回应敌方试探消耗的目的。恢复不是没有资源成本：加持本身要神力，后续敌阶增加仍逼团队升级出手。

## 新教法在目标克制下兑现，并非普遍秒杀

1. 182新教的凝聚光球实用：爱莲娜以米诺亚曾灌入的浑厚神力攻击暗蛛。约十级能量因属性克制对暗生物单杀可比十一级，八级蛛又先受石柱藤蔓伤，才被迅速杀死。不能把这结果写为普通爱莲娜光球无条件秒任何九级。
2. 十几里通道后上百九级蛛出现，仅盖次加爱莲娜不够，忘忧接手。低级敌阶段的高效率并没有消除更大规模/更高阶压力。人员分工随门槛改变，不是首次方案永远不变。

## 三段连击：改变作用顺序比单次堆能量更省

1. 忘忧先用自创元素之怒三光环提升威力五成以上，代价是持续控制、需要极强精神力，玫儿克里也难用。旁人看到术并不表示立即可学，知识差距背后有生理/精神承载条件。
2. 腹部先受压缩腐蚀球，虽暗抗使弱化减小，仍令拳头大小局部脆弱；再以压缩旋转冰刺沿同点钻孔；最后压缩爆炎入体才爆。不是一个火球直接无视甲壳，而是弱化→贯通→内部伤害。
3. 盖次石柱让蛛体起伏露腹，是连击可用的外部条件。大体型、高腹、较慢动作有利追踪；不能把对这种蜘蛛奏效扩为对所有高速或无内部器官敌人同效。
4. 操控术让术转轨追慢于自身的目标，锁定术让冰跟腐蚀、火跟冰，解释数百米外三个术同点。六翼级精神力才可学超魔是忘忧解释，不因威娜全系天赋就能当场复制。
5. 九级左右耗能造成接近死亡的九级下位蛛伤害、数十只倒地，是现场兑现。叙述称比十一级更可怕属效率比较，不把法术正式登记为新十一级。高速手势使双手酸麻，魔力仍有消耗、要抓空隙休息；“小技巧”的自谦不能抹掉技巧高门槛和操作成本。

## 对将军不用同招硬推：感知密谈配合诱导

1. 四只将军三四十米高/数千年互食淘汰、强度近盖次，通道虽扩大也只有一只在前。敌方质量与地形宽度共同限制接敌数，不能把四个同时围攻的胜果加在队伍身上。
2. 主角公开命忘忧打大、盖次/爱莲娜打小，暗里神识密谈却安排协同；爱莲娜也未及时明白。公开分工是欺敌信息，不是盖次擅自违令偶然立功。
3. 忘忧只能瞬发九级，十级冰封需要准备；威娜十级炽炎准备更慢，忘忧等她就绪再放。配合必须同步施法节拍，不是两法随意齐发。
4. 炽炎先持续烧头部，蜘蛛轻视十级攻击且被重力减速，等其烧毕同部位冰封，冷热变化让局部甲裂。这里是书内有实际效果的技术组合，不能化成现实材料学证明。单个十级术未能致命，连击需要时间/位置/对手反应条件。
5. 它追忘忧近盖次，藤蔓只能限爪一两秒，刚好阻防；近距离咆哮弹命中裂处入体爆，第一将军死亡。旁述明确若甲完整仅伤、若爪能挡则伤极微，给出本段关键反事实：胜利不来自盖次原本一击强过敌人全部防御，而是短时创造不可防的弱点。
6. 主角与忘忧击掌庆祝、邪神怒被骗，展示共同经验与信息协调的回报；怒沉默不等已气死，叙述最后也撤回其幻想，三将军继续来。不能把敌方遭欺骗就推其不会适应。

## 净变化、边界和后续承诺

囚者释放并携给养去里牙，老祭被邪神祭献死，队伍进洞退路合。恢复组合支持小术清兵，爱莲娜新攻法与忘忧连击实际有效；威娜从单供魔到共同施十级术，第一将军被四者分工打死。主角主要以指挥/神识协调保存自身力量，当前还未和邪神本体交战。剩三将军、通道终点、支援神力可持续多久与对手是否改招仍未知。可抽象的候选是按目标防御链分段处理并配合短控制窗口，但前提是精确同点、目标慢/甲可破、强精神力与可用队友，不能只提取三个法术名字当普适配方。
