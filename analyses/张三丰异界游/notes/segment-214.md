# segment-214｜战利分配、贸易周转与保留敌方组织的扩张边界

完整正式阅读；ordinal533–534，原527《回归领地》、528《大陆局势》；[2194261,2204673)，10010非空字符。显示[2194261,2198661)、[2198661,2203061)、[2203061,2204673)无截断至章末。B透镜；领地会商刚开始，祖母最后问如何杀三魔，解释与实占倭岛尚未展示。

## 战利品按使用条件分配，潜能不等现成全能

1. 镜给雅、霜剑归主角、勾玉给忘忧，三器取得和去向现在明确。霜剑受冷落几被玫喂史莱姆，主角因名字/美观留下；剑鸣和联系使他怀疑天然器魂，不是本段已完成器魂鉴定。普通人工入魂与天然成魂分开，天然形成条件未知。昊天现无魂、师只能三成及有魂可能五成，是回述/估计；未来养魂杀强神仍是设想。
2. 勾玉强化与忘忧的女性使用条件、圣气性质相合，因此不是一律按亲疏或谁抢到谁拿；镜继续支持雅潜伏，非公开给所有部属共享。
3. 史莱姆醒来，金色透明、可变巨熊到饰物，形变不改变重量，变大密度低/防御下降；可化玫衣。丽全力刺枪入数寸即受阻是实际试验，十三禁咒盾/近六翼只是由此作的初判，未做所有伤害类型或全战力测试。
4. 不能飞、无魔法远攻、不能说话，变龙不自动拥有龙的全部机能。形态更准确/智能提高不抵消这些限制。主角拟向矮人交换贵金属喂养，旧九天玄铁刀亦只是条件性奖励；不是已取得新矿或已再次升级。
5. 玫誓闭关炼黑日二层，已有三邪魂材料，但本段没有练成。神器、材料、试验、未来上限四层分别记账。

## 运输枢纽把一次出征变成反复收益

1. 地下物资持续运，公开经营无需沿旧秘密通道逻辑，全国粮集中下运，地下/兽王附近交易并回收矿，再经大陆网络分销；资源优势来自通路、集散和地区需求差，不只是武力直接变金币。
2. 瓦七的边境兽人贸易仍有空间，兽境大、相距数月，两边市场不重叠；主角强并不等所有既有商路都被清空。
3. 返领时商货中转已给博拉姿居民收入较前多三分之一的叙述，欢迎有财富和平的具体归因。这是叙述者的总体口径，不把每户实测/统一净利润当已证。利益分配让领民主动支持，运输收入成为统治声望的一条回路。
4. 航行约一月/总离半年多沿原口径记录，不为消除与前述旅行时间差自行改日历。

## 家族权位与行政人才不直接服从军功大小

1. 尼古拉斯胜后仍返蓝闪旧任，只得钱宅；玄武由皇叔亲王统边，爷卸任前支持皇帝。主角不平并担心皇叔为患，是其政治判断，非反叛已经发生。父称无力改，军功和实际任命权分离。
2. 爷把家主交父，携祖母秘密到博拉姿，拟同商倭岛开辟和养老；人已到但未启程接管。家族主位继承与主角实际经营网络并不同步。
3. 欧阳奋在霍福被免官，全家经卡西亚护送到此，皇帝既应付教廷又顾主角。主角拟让其任大汉宰相：已有数十年政绩口碑、龙支持，加上只有独女被认为不易形成新世家，降低旧世家反对。只是提名可行性分析，尚无皇命/其他家族同意。也不能把父亲无能的抱怨当客观完整人物评价。
4. 卡特东西由尼与银狐驻防，沿海经济/贸易/制造/军权由主角博拉姿旧班底控制，芙倪雅代掌印信、虽无正式名分已实际行政；紫三姐妹以政治能力和原身份辅助，叙述明确与民心安定相关。权力授权、专业能力、地方认受性三者共同把战果变组织。

## 教廷重创，却有暂不打死它的战略理由

1. 西三帝近两年投入近百万军、钱粮税债，未得土地而得少量掠物奴隶，成为亏损原因；不将掠夺本身当无害经营。教廷既受人才损失又是三帝最大债主，军事失败转为财政/联盟危机。
2. 五枢、马其纳、东尼和守护精锐/高级牧损失，伤的不只是兵数，也是全大陆学院集人才的再生产系统；原定反攻被说流产是当前战略形势判断，不保证永久不能恢复。
3. 教皇倒病真假不明，祖母已退，仙雅依等级代理。她带比蒙谈判形成威慑，然后了解困境、免掉三帝全部欠教廷款，换取其继续表态支持。武力压场加实际财政让步才平息，不是温言单独说服。
4. 仙雅随后游历恢复声誉；主角说明这是己方商议：若彻底打垮教廷恐招更高天界直接介入，现阶段容它半弱。四六翼未必构成最大威胁，背后的大人物仍是行动上限。不能从此认定主角已能无代价消灭所有神族。
5. 西方经济恶化导致每日上千移民，边境官收贿令禁渡失效，给东边建设劳力；受益依赖治理漏洞与对方困境，非完全自愿平等发展模式。
6. 香香本段教会被称上百万信众，与先前千万口径存在数量差，未给统计范围，保留而不暗中统一。她忙传教、千卫护行，公共威仪与亲密相处差异是角色位置变化；忘忧仍需主角公开尊崇以协调内宅，智慧不等关系自动无摩擦。

## 信息分级保护战果，也限制外界对因果的理解

1. 宴会只说不重要经历，倭事对外围不讲；核心会议才宣布占岛。教廷仍以为魔鬼占岛，情报时间差形成接管机会。
2. 祖母原怀疑三魔未清，提出若确死可帮占领：从魔鬼手夺地不归教廷，并可名为报圣战之仇。跨势力身份在这里被用作合法性资源，不等她已无教廷亲情。爷喊杀教皇被她瞪，家族共同阵营仍有情感边界。
3. 霜剑作为已知魔头持物是强证据，非单纯主角口头报功；缺口又引出雅救天使。主角将雅真身份限三人知，连玫/爱/香亦不知，向祖母讲的是掩饰版本。必须把会中说明标当场话术，不能倒写成全部真实行动因果。
4. 祖母警告杀六翼可能触天界追责，主角以天使已逃/无损失缓解；这是他对报复的辩解，非敌方已作免责承诺。章末祖母追问如何杀魔，尚未得到回答。

## 净变化与未决

三器归属确认，史莱姆实际进化并有单次防御试验；玫二层、矮人金属交换未兑现。地下交通已持续形成商贸和居民收益。芙倪雅行政/紫三地方安定有当前运行事实；欧阳奋任相、爷祖母接倭尚在议。仙雅以免债保教联盟，己方主动保留弱教以规避更高介入，构成扩张上限。香教百万/千万数字差、史莱姆综合等级/霜剑天然魂、天界后续报复均留未知。
