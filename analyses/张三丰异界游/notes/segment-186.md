# segment-186｜刺杀方案实测成功后的暴露与敌方适应

完整正式阅读；ordinal476–477，原472《首战告捷》、473《相约决战》；[1914520,1925100)，10130非空字符。分[1914520,1918920)、[1918920,1923320)、[1923320,1925100)无截断至章末。B透镜；A19末。首巢与追杀已胜/十几万获救，大决战尚未发生，铁器缴获是预期。

## 敌方组织与控制成本先界定可打节点

1. 邪眼数千、奴隶百万，暴君本体近大蚊/海怪，另控两成年黑龙、恐爪王及两千兽、十二九下烈火元素等，综合不能只比领袖单体。十二元素可阵施十三以上为听说/风险预测，尚未实际发出。
2. 黑龙大长老强过暴君、不怕控，仍几救不成因人海；黑龙族许救或杀两龙有奖，是外部利益接口，未发生领取。克制控制不等自动能穿全部军队。
3. 第一次封印思想耗精神多，后持续指挥只少量，解释小群邪眼控众；初施与持续指挥都有距离限制，后者数千米、超出奴隶呆立。这使脆弱控制者不得不近战场，既是指挥优势也是可刺弱点。
4. “本体战力弱”只指与控制军相比，不等没有触手魔法/社会结构。敌按强弱选奴，把弱小老幼当食物，主角被控者优先救而非全阵屠，目标选择回应这一伤害。

## 小巢试验验证知识—装备—组织链

1. 选十四五邪眼/近两千奴兽村落，让数百暗夜叫骂射箭即退；只五百怒矮+爱莲娜/苍龙角正面，免大军吓跑目标。是有意控制试验规模，不代表整支远征军只有502人。
2. 敌出阵按近兽、近战亚人、后远程和邪眼，初有组织；冲锋各速度不同才乱。叙述者预期乱兵被出阵纠正，不能把对手从头写成无组织。
3. 苍龙角加多辅助/清醒之光，爱莲娜加精神屏蔽，十几小邪眼实际不能控一人；“当前小邪眼”边界重要，对暴君是否同效仍待。矮甲对其劣骨石武器优势，也不能外推敌所有部队。
4. 矮守而不追杀亚人，藤拌减速，爱莲娜杀兽后回来，留时间给刺客。她爆发后成长到可比马赫/卡罗为当前叙述；不等时时保持184瞬调全部赠力的极限。愿多参战是其自主成长选择，怕杀人和能打兽同时成立。
5. 每邪眼三四刺客预分位，隐链近身、永久破魔毒匕首同时破盾切体，邪眼死→控制断→奴倒待醒回记忆。旧技术投资+专业人员+正面防心控/拖延形成闭环，不只是某一件项链单独赢战争。
6. 主角称圆满，实际只证明当前小邪眼挡不住，并非证明暴君也识不破；后文立刻提供信息扩散这个代价。

## 胜利也向敌方上报参数，迫使换方案

1. 金字塔隶属邪眼有精神联系，遇袭数分钟消息传千里；死前上报精装矮/暗夜刺客。所谓偷歼并没阻止通信，不能把全歼尸体当完全保密。
2. 暴君虽不知矮来历，知强敌便下令全集中，撤空村落；己方见空才侦察获方向，不是早已知道其全部应对。主角改派刺团追行军慢的邪眼，止于腹地，因未确定暴君能否破隐。
3. 杀数百、救十几万约敌十分一是本段累计战果。获救者多数愿跟，愿回家的不强留、承诺战后护送，自己走者给干粮；自由选择与物资支援已经展示，护送尚未完成。此举也修暗夜旧掠夺声誉，不能默认旧受害小族立刻全忘过去。
4. 十来日到暴君领，对方洒微光碎末数百米/密哨验脚印，飞越也易露；项链隐藏本人不遮接触环境的痕迹。主角不舍叔祖冒险，刺术“废一半”非所有技术彻底失效。便宜本地材料可针对贵器效果，是本段重要反例。

## 议和把双方利益与概念差异摆出来

1. 百万兵粮消迫暴君议和，不只被强者名声吓服。邪眼用控制暗夜作翻译，后暴君亲以精神链遥谈，通信能力继续在政治场使用。
2. 忘忧说正义，来使不理解，准备辩词失效；主角转为朋友部下受害、再以其弱肉强食逻辑反问。对共同价值的假设未必存在，不能写智慧神格保证任何谈判话术成功。
3. 对方愿送晶/放矮暗并不再抓，己方要求全晶矿、奴为矿工与邪眼归军，又以商路安全/未来威胁解释不能留。救人之外明确索土地/生产/兵权，议和不是对方毫无让步而纯拒正义。
4. 暴君拒再失自由，虽自身奴人仍珍己自由；这动机不为其行为免责，也使其不只是无目的恶。主角承优待降将，未真收暴君；两方不成才约战。

## 临时决战承诺依赖既有信任，也积累统帅责任

1. 主角临时给十天集结、先两天到开阔岩地，随行部下此前不知。先知/矮长关人数风险，苍龙角猜另招，叔祖用过去骑熊不对等决斗历史作信任依据。不能把无人公然反对等同人人知方案或风险被事实消除。
2. 矮长指出微光/密奴围体可挡刺，主角允不再靠刺但保密战法；此时招式仍未知。军令执行有上下级/宾客机密边界，保密既能防泄也使部属承担不完全知情风险，未来评价要看实战。
3. 五万敌先头到，邪眼周围奴密围/顶风元素，分同类统一编制解决速度差；装备多铁器甲，明显强于初外围。对手同时在反刺和编组上适应，不能把首巢战术原样套百万决战。
4. 主角估初见看门兵/现精锐解释差异，属于推断未敌档核实。铁器虽破损，可修后供兽，令其想到省从领地调货；**尚未缴获**，不是已履行给混乱远征铁器的承诺。

## 净变化及下批观察点

小巢方案成功、追击获十几万人解控，攻击已暴露，敌全集中并用环境痕迹/屏障和同类编组反制。解放者有去留选择，供应声誉和军力都有潜在收益；暴君议和失败，十天决战约定/双方先头到。未知新战法、百万对决结果、暴君及强宠处置、晶矿生产与铁器供给。后续应特别核“正式不靠刺”如何兑现、是否保护被控者，以及战利何时真正入账，不能以标题首胜提前算统一邪眼。
