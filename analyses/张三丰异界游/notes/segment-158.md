# segment-158｜无名丘的补短板、轮换与对手错误边界

完整正式阅读；目录ordinal420–421，原416《血战无名丘》、417《血战无名丘（续）》；固定快照[1624865,1635479)，10228非空字符。分[1624865,1629365)、[1629365,1633865)、[1633865,1635479)无截断到章末。B透镜；狂龙已破林缘五万部队，联军总指挥与全战场结局未读。

## 兵力与远射不能脱离携行/补充

1. 塔巴斯次日几十里岸卸二十万，其中十五万骑；帝国接若兰讯急调的新马未中毒。157主力马损并不意味着敌从此无马可补，水路运输实际已把这种替代资源送到拦截下游。
2. 三千半人马沿岸射初登陆密集目标近万伤亡、再对追骑边跑边射造成近万五伤亡，后者是否含前数不明确，不擅自合总数。敌很快散阵但追/不追都受扰，仍试图消耗其箭。
3. 每半人马仅携百箭，再多跑不过轻骑；箭尽也已被追至丘附近，故一千归丘、两千入森林。不是射程优势就无负重/疲劳/补给约束。后来两千补箭再出与狂龙配合，构成真正轮换再供，不把首次离场误作逃跑退出战役。
4. 塔巴斯合围，岸上一次最多投五万、又用小艇从河面分批牵火，军事选择受地形可接近量限制。己一千八百守丘：五百巨外圈、一千半人马高处、三百精灵浮上，立体排列使射界/护盾/补法能互用。

## 精神力、魔力和命令纪律分别发挥作用

1. 司克特见十几元素精灵，判断其主人有大师魔力，但精神增幅少，能十一法应不超过三。这个“十几大师”要按魔量/瞬法与精神控制不同维度记录，不写成每人均会顶级大禁咒；精灵族数百上千同级为他所闻，不是作者清点名册。
2. 一精灵瞬冰冻河面/小船数百人，司说明元素伙伴助大师瞬八级，不等此人已法神。魔法种族/契约外挂改变人类名阶的参照范围。
3. 塔巴斯因若兰救命重用而怕其被俘受报复，挂双血旗；传统一旗可降/败杖百、双旗不容抗者生且己败千夫长以上自裁，令进攻军不能退。此处勇猛既有信念也有处决威胁，屠城含平民规则不可抹为单纯励志旗帜。
4. 他愿以多耗尽少，司判断大师杀量有限/五十万足耗。后续巨人实际数百弹超他估百余但最终确熄火，说明错误在参数而非“资源有上限”原理完全失效，不能把对手写成从未想到续航。

## 低阶法术为高价载体补短板

1. 巨力增力一倍余、狂风助弹/逆阻敌，巨石射程约一千五百米，敏捷使频率再倍余。不是法师轮番放最高伤，而把低阶辅助作用于巨人本已有爆弹，兼给敌减速，放大已有载体效率。
2. 高地/狂风令半人马千米抛射，不求准确而覆盖密阵；“超远程”适用于此地形/风场/大目标，不能更新成平地单骑常规射程。巨石元素爆炸清几十米、半人马补漏，仍有敌从火隙挤近，非火网完全无缝。
3. 精灵只几十风系长供，其他暂留，后来几十冰法加入低伤暴雪。夏季单衣/冷风令敌手足迟钝、范围十几里连林缘预备队受影响；控制效果与季节衣着共同成立，并非暴雪在任何装备任何气候都压一半战力。
4. 岸边小艇“上岸封贵/死传后”的承诺使数百人冒死，精灵瞬冰冻轻松制止。贵族晋升制度成为兵源动员资源，也让士兵被当分散火力的消耗品，敌方组织不只靠军官爱将之情运作。

## 从远攻到近战：载体条件改变，旧缺点没有被凭空抹掉

1. 半小时巨人各数百弹后停，敌认为远程兵近身弱、五万便可取，司仍提醒可能后手。巨人给自身留少量盾力、拔早埋的四五米吨重狼牙棒，精灵再叠七八色盾，近十米挥扫范围高过人骑可及位置；把战斗从射程窗口转为近身覆盖。
2. 巨人动作笨拙本为旧弱，但敌密集无闪避空间、寒风手脚慢、长重棒扫大片，使“能否打到”条件改变；近身高手又可用另一只护壁大手拍/抓。不是仅买武器就自动将任意笨兵变高手，也非本段证明巨人在稀疏机动/快剑对手前再无弱点。
3. 司克特归因矮人工艺/材料与财力，认为巨棒打造质量代价天价，反显领地生产网络/支付力支撑改造。这里具体制造归矮人是其推断，不能补未经本段见到的车间工序或成本金额。157先说巨人自己想要狼牙棒，不能只保敌“全是龙设计”而抹族群偏好。
4. 塔巴斯改投武器/弓射耗体力，不是见新招即呆死；他的消耗逻辑还在，却在背后新阵介入前来不及检验。己精灵甚至对巨人抓捏惨状呕吐，军内价值/感受并非完全相同；描写杀伤可怖不能只记爽点回报。

## 援兵不是全新凭空出现：经营增员和预备队失配

1. 塔早料森林有狂龙，摆五万看守，不能说他完全没防援。实际五千非旧两千：叙述回溯狂战士随主角后食宿待遇改善、人口/训练与精良装备使更多可收地行龙，卡罗带全军、玫允。人数增是经营资源与合格骑手/驯兽条件积累，非突然凭一句召唤翻倍。
2. 五千冲阵，卡罗杀高级军官，补箭两千半人马在其后安全射；冻僵的五万迅溃。并非五千对任何健康五万都同速胜，暴雪先削、射手跟进与斩指挥链共同解释。
3. 消息和狂龙几乎同到塔眼前，情报反馈延迟使其无法以“早知有援”充分调整；他误差在兵数/天气影响/破阵速度，而非不知道狂龙名声。章末尚没塔自裁、俘虏、五十万尽损，不给下一段补结局。
