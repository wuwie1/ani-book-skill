# segment-228｜亡灵生产链显形，合作优先也受下属行事影响

完整正式阅读；ordinal562–563，原556《失落之城》、557《城头激战》；[2335064,2343451)，8057非空字符。显示[2335064,2339464)、[2339464,2343451)无截断至章末。B透镜；主角隐观并暂许高森有限反击，末高森已空中闪法弹欲登城，真正登陆/城防下一招/胜败未出。

## 由物流追生产，逐步证多节点而非一次看透全城

1. 随矿车几十里到粗炼场，几十椭圆炉/四火骷髅法师加热，十余冥思轮替，矮小技工指挥时机；浮炉倾铁入沙模、清渣/换矿/换班流程不到半时，一炉千斤是主角估。现场证明分工、轮换与法术用于物料操作，不是主角自造的新方法。
2. 骷髅法师本应学徒/初级，这里可炼一炉被估高法/魔导档，千余数量与旧认识冲突。全区数万法师仍外推，不能把未见点都算完。
3. 粗胚沿途别队汇流，证至少别的冶炼来源，不再只有第一矿场猜测；百余里昼夜运输不用牲口/吃住工资，依死亡天幕补能。主角誉最好劳力是成本视角，不应忽略建立/控魂/工具/烟燃料等未盘成本。
4. 精炼场几十里、强档法师重炼，铸大甲兵/奇零件，后骷髅磨锉慢、每件估几月所以堆积占地广。生产链有实际瓶颈，不是永不疲倦就所有工序高效。
5. 小骨技管不出力而指挥交流，主角由弱骨/铸造智慧排矮而认地精，联想芙初遇寻找亚特蓝。活地精少魔难自变亡灵，假说被埋城人遇法师变亡灵挖出建城；本段明承推测待证，勿把标题“失落之城”当已证身份。

## 城体观察让旧人偶模型失效，但机理未揭

1. 随成品物流千里见城直径逾五十里、墙五十高三十厚，数千三米金属甲战士；旧人偶价贵/零件易坏/耗魔晶会破产，故主角推改进型而非正常已知。
2. 关节自然/步齐、重装轻行支持强机动/统一指挥，不是已测真实总力量。五百米主塔/四三百米烟塔、满炼金塔实验室、物流繁忙无商店娱乐民居，城市似巨厂是观察比喻，不等全体无任何社会生活已调查完。
3. 新两米金属杖者随后火弹实证可施法，城防几分钟统一转战、普通骷髅撤近建筑避，是组织应急而不只有高级兵器。神识间交错说明高层通信响应，具体几位巫妖未知。

## 合作取向基于关系网络与潜在联盟成本

1. 忘忧汇合先比法与道，承自己精神力更强却元神侦得更早，道术感知不与纯精神量成同一尺。玉女+五行珠防高与雅战高不同，两格独立竞争仍在，不写智慧无欲无好胜。
2. 主角想收至少交友，忘忧建议打服并指出其旧三害行为与仁义矛盾。双方话论东方/西方性格是人物概括，不当普遍文化事实。
3. 主角说明自己救地精/领地工匠关系不宜反得罪疑同族，感恩可能换合作，朋友非必部属；又顾巫妖属冥/脸面，未来或联合抗天使。冥神绝不为小巫妖追责是其判断，非对方正式保证。
4. 猜矿主因旧城为报魔仇，忘忧欲借魔侵神族幕后消息诱转敌向；仍策略设想，身份/仇恨/联盟未实际谈。合作优先有利害与既有关系原因，不能单称主角突然无私慈善。

## 下属遵令方式产生新风险，仍有有限行动权

1. 高森跳地巨响引骷追但不还，至城门放极强气是通知同伴，也全城可知。形式服从“弱不打”却破隐察，是执行手段和总目标错配；不是他已蓄意叛约。
2. 主角忘忧暂不出救，欲让其吃苦并看城能力，故己方可控升级为测试，但风险也给骷髅和设施。不能说始终纯只看不介入。
3. 千杖人偶八九级火弹汇焦近十三禁咒为估，高森同冥火仍要防闪，属性相同只较耐不等免伤；余震推远足证群火可伤六翼。
4. 高森没立即报复，先问已可伤能否还，主角只许轻破/伤不杀；命令边界在真威胁出现时更新，不能用前面不许动概括全部。
5. 其千斗气弹打杖者，普通大偶以武器甲体护住，毁装后自身未大碍，护射分工克散射。攻击结果不是杖者被灭或己方白耗全无损。
6. 高森改高跳诱齐射、空中侧移闪，再俯冲趁施法间隙；他会观察节奏和省斗气，不宜因叙述跳蚤/白痴笑称写成绝无战术。末明城防尚有别法，不补登墙成功。
