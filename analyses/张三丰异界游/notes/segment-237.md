# segment-237｜铁甲突破依赖组合，补给和专业克制救回被牵制舰队

完整正式阅读；ordinal580–581，原574《激烈海战》、575《突现援军》；[2418728,2428010)，8908非空字符。显示[2418728,2423128)、[2423128,2427528)、[2427528,2428010)无截断至章末。B透镜；爱/黑龙已援到、十万普通弹送到分发，七新谋打海军经验，整体海战仍未结。

## 四铁甲的优势不是单件神兵，可被拆分牵制

1. 四舰菱形突敌阵，用厚魔固铁/撞角+三十五节对木舰十几节，拖克坛先破几十法合盾才能高速撞。每舰五十精灵魔导/契灵供动力，动力/破盾/材料/指挥同时在才有突效，不是铁皮自己永不减速。
2. 舷炮近敌密集火，特制海战弹加强木体燃伤，记功能不复刻构造；余毒使落水敌无逃路，己已有餐中解药预备，说明后勤对己风险有处置却不抹平民/海洋毒害的未验。
3. 敌几次围堵慢船失败后改不管四舰、全攻其余木舰。己炮弹和动力魔有限，威吓敌退未成，七省弹只打中大型，退出敌阵挡交界保护友，击七主力迫其后撤保法师。技术优势能局部击破，不自动整体击败两千舰。
4. 敌魔风令己普通船难退，持续纠缠两日等尼科，战略是牵制等增援而非无理由固执；己舰长战后只剩三四成能，人数魔量名义二百精灵不低两千人法亦失时间态优势。

## 人才忠诚有后续培养与个人选择，不能只溯最初俘虏

1. 尼科两翼到场/金属消失拆船钉，把已带天改体推测推进到有翼回来并出大预言实际；具体池过程仍未亲见，不能把236猜全部细节即定。
2. 拖与其七八十年旧交仍明确站主角：自述早拒教米锁拉共事受打压、不得投其他势力贫困，最初伤主父后被高手围/怕死受迫，后实验室材料/蜜/雷角/精灵王和礼遇促知遇效命。初胁迫与后主动忠诚可先后并存，不能只据一种抹另一种。
3. 尼承曾主角救放恩却为家族教廷不退，血亲/恩惠不是永同盟充分条件。拖魔量占优、尼预言精巧互威致命，彼此谨慎陷僵，无本段一方胜死。
4. 两强战余波伤两边舰、彼此避空战区，拖被缠后己四铁甲失破盾人，敌主力敢前，精确拆开原突阵链；强者离场不是“其他强资源”可无损代替。

## 缺一支专业部队让保护战转成人命换时间

1. 人鱼近全成年先为联合其他海族而出、老弱留港，七原许而今后悔；他们有己族外联任务，不始终作为200固定工具待命。外联是否成功未读。
2. 没拖破盾，撞舰会耗速度被登；退又暴露友军，七只能二百精灵护壁承两千敌法。动力同时消耗盾能，是资源多用之间的竞争。
3. 水鬼配水肺约一小时/己有解毒，仍不能真沉大主力，船底专听哨发现、敌法低雷易杀。七用十几批几千人命诱敌费魔争半日，是残酷消耗战，不把地精小工具描万能特战或无损智计。
4. 叙把多人命换几低法称赚是己阵成本口径，分析保伤亡和权力不平等；保护全舰有战略压力，不消除下潜者实际死亡。

## 空中援军用属性克制与补给解除局部死锁

1. 护壁刚破黑龙/爱赶到，黑龙硬挡十级左右法无伤，再破盾毁两主力/杀聚逃法，余千法集逃，近法不敌魔抗/飞速；对本次等级法有效不推广所有魔法无限免疫。
2. 黑龙快于法师飞和舰速，先毁载法平台使高价值法师离舰，改变敌法兵与舰的耦合。不只是击沉吨位，也恢复七行动窗口。
3. 爱从上海飞两日夜带十万普通炮弹，半路适配问题由密集阵/弧投弥补，估能沉五百是七计划未发完证实；供应、空间戒运输和传令速度成为战斗决定条件。
4. 七言几差永别/早知不会被弃，援到有真实危机和时间压力，不能用最终前瞻把水鬼牺牲写多余。爱服指挥而非取代七战场判断。

## 打击瓶颈从工匠改为熟练海军，但新推尚未兑

主角经爱转猜新舰由天界工匠造，仅假说无现场证。七意识工匠有备难再同法清，己海优势不显；主角提示再多好舰无有经验海军也无用，七明白而将行动尚未详。不能把职业军人灭杀/经验断层结果提前填入，也不说237已查证天界工匠全部来源。

## 净变化与待核

四铁甲首突奏效但受炮弹/魔量/其余木舰与拖受缠约束，尼科已带翼回而对拖僵；水鬼大伤亡换半日，黑龙与爱/十万弹实援到解除毁舰迫近。新舰工匠来源仍猜、人鱼外联仍未归，七改瞄海军经验的打击尚计划，主战胜负与伤亡总量待读。
