# segment-190｜供给控制的矿区、共同体动员与秘密产业的地缘弱点

完整正式阅读；ordinal485–486，原480《混乱黑幕》、481《不素之客》；[1952972,1963656)，10258非空字符。显示[1952972,1957372)、[1957372,1961772)、[1961772,1963656)无截断至章末。B透镜。十三主城实际拿下、洞口派兵；六翼天使末尾显身，交涉/战斗尚未开始。标题疑字原样保留。

## 稀金属数量经专业判断，但价值不等可自由劳动

1. 小镇主城十天送水粮收矿；矮大师鉴密银品质高、年一两约人族十分一/银不下一吨、开百年尚三分二。前两为专业估计、比例推算，不等现接手后已年产到账。百余此类镇的情报来自俘虏，专业采矿可提效也是估。
2. 多来源矿民按矿量换粮水，无鞭也工作，外界无城防/千军护则易死，没人逃；主角称模式还算不错，却事实无自由选择。不能把“无人拦逃”当实际自由市场，环境危险与资源垄断同样约束。
3. 供应让主城控制周镇，也让进攻者需防饿死。占镇后不乱截补，照原车队路线派送，是主角接管时真实保生产/救命动作；不能以战争背景自动省略非战斗者生计。

## 伏获车队既得战果，也得到进入社会网络的中介

1. 镇民少外出/不识路，无法按最初设想直奔主城；等数日车队两千/数百车抵，因惯防兽不派斥候，入伏。敌个体斗气强、牛头头领近父，不等有对正规军伏击的侦察习惯。
2. 六千兽伏，三皇子以剑神/体型制剑圣，敌死几百余降。数量、突袭、等级三项共同解释，并非一见民族旗便所有人零伤归附。
3. 里巴特被拐/角斗虐待、杀过兄弟，仍信兽神，见先知认同并投三皇亲卫。共同体身份承认和摆脱旧羞辱比纯物利更强，是招募的具体动机，不把高威信写成不需个人历史的万能符。
4. 俘述十三城主互识/皆人类、各一千甲护，城市冶炼与奴隶/角斗产业、贵族保密游客。此时主角先推教廷幕后，还未控城主问证；不要把推论的时间点往前移。

## 策反依赖可见担保，失控混战并非预排剧本

1. 先知、忘忧、矮长雷锤与主角逐报身份，城内各族能认自己的领袖/圣器。主角控沿途异族高手避免预警，里拉被四围才知，虽慌仍迅速分布远近战两万，敌并非毫无训练。
2. 控诉由里巴特具体遭遇/伤痕与先知保护誓支持，唤同遭者怒；不是只喊正义就自然开城。里巴特已归兽方，主角先请先知转令，尊指挥所有权不越过。
3. 先知因动情闪电击红甲，己兵误当总攻/城上反，主角忘忧都未料。是意外引发而效果有利，不能补成统帅预定的完美同步策反。
4. 千余米精准雷破甲留活，后叙一处“红甲死后”与后文爱莲娜救活/审问冲突，保留为叙述用词异常，以明确俘后救活问证为本段当前结局；不删原文。
5. 城中三千余人类被围、多杀仅百余俘，先知/忘忧及时制止才留口供。不能说攻城完全无血或所有被杀者逐个审明罪；共同体愤怒也有大规模报复的失控风险。

## 情报采集方法决定能拿到什么与代价

1. 三游客贵族易吓招，只知朋友推/教担保、被催眠进“神奇空间”，不知道位置。秘密以分层知识/催眠运输实现，消费者不了解路线，限制从他们套核心情报。近期重税让多数返避税，解释现客少，财政线反向改变地下消费。
2. 城主拒答，克里不用大傀儡而缓侵意识保记忆；区别在大傀儡封/毁一切意识记忆只剩动作，不可问知识。强精神力仍须精细强度/时间，不是任意一扫就无损读心。
3. 控成后永久失自我成木偶，这不是普通询问或无害测谎。用此确认秘密带来人格毁损的伦理成本，B透镜不应因为产出情报就只称高效。

## 后幕被口供证实，秘密同时保护产业和约束调兵

1. 数百年前枢机发现古道/稀矿，口在霍福内腹近教界千里，教皇舍不得分利，借神迹建大教堂掩口/催朝圣小镇。神权合法建地、入口保密、异族劳力解决不能大量派兵的条件，形成隐蔽经营链。
2. 几百年由鞭奴高死亡转矿换粮以保产，不等转良心；现密银年两斤/精金三两、偶神金及金银，人力强制和生命损耗是供给底层。祖母昔赠神金来自此却不知产业内幕，不能以家属身份推所有教高层全知。
3. 教皇与负责枢机独知、其他高层蒙，城主能供的信息应按叙述给范围；未有独立文档核所有历史。主角猜幕后此时由受控直接管理者口供支持，证据强于先前身份联想但有强制来源。
4. 教曾联暗夜穴居攻邪眼，穿死亡带先损四成再败无法返，全军覆，因不能曝光霍福哑忍；地下三方此前眼中的混乱与教廷隐秘相连。主角本次空间补给优势也须对照三百余死/伤病，不能把敌惨就写己无代价。
5. 地缘保密使教上面最近兵远、入霍福需时间，主角拟炸洞杀援。这是风险评估/计划，未发生洞中歼教军；不是证据表明教廷永远不可能增援。章末六翼突显正提醒常规大军距离不涵全部强者通路。

## 从占领到多城接管，节点不同采用不同组织手段

1. 两路：两千牛头/巨魔与一比蒙守窄唯一上口，余扫十二城。窄口便兵种搭配，但“挡十万人”仍信心估，未实战。出兵已发生，是否封尽所有消息未证。
2. 三天一城，既降人现身支持+领袖担保+旧剥削激怒，各族内反，十二城都取，叙述“几乎没动己一兵一卒”说主力少战，不等城内无杀/族群报复成本。十三独立城尚有共享教廷后台，189所谓无关联为当时表面结构，不能当最终解释。
3. 最后大城安抚审问后会盟，院外白光六翼显现。实际占领/旧产业掌握与顶级敌反应接续，不能本批全占就断言地下已绝对稳固后方。来者身份、目的、战法未知。

## 净变化与异常

矿区价值获专业估、车队与里巴特带来中介，里拉意外动员夺下，口供证教秘密矿产业/通霍福口，十三城已占、派守洞。入口隐私和原压迫让跨族组织优势放大，但奴工供给控制、永久脑控/报复杀戮与误触总攻均反例。原题不素保留；红甲一处“死”后确实救活审问，留异常；下一段从六翼来客实问开始，不填其结局。
