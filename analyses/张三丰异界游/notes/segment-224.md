# segment-224｜低阶群体远程合力、控心阈值与偶发治疗收猴

完整正式阅读；ordinal554–555，原548《幻象猴子》、549《喜得金猴》；[2296257,2305694)，8939非空字符。显示[2296257,2300657)、[2300657,2305057)、[2305057,2305694)无截断至章末。B透镜；金猴随忘忧归队，尚未实施百夫长配猴、封能项链或整族军用训练。

## 弱能量也能制造高损失，战斗力须含信息作用

1. 外无鸟声，神识只觉微能杀不死鸡，入后队不知觉分百米，各向空气以为跟着前人。主角忘忧才认幻术非阵，神目/元神并非首次就免骗；先感活物不等视觉声音气味全真。
2. 忘忧专门精神震荡清周围幻能，才见千米前小红猴并听食闻果，表明多感官误导；若兰依据霍福一低调法师及败者记载识幻猴，地方经历补通才认知，原记载曾让更高法师打空。
3. 丽说几乎无战力没用，主角用百夫长配猴使敌砍空/己命中阐明组织应用。若兰一敌十、忘忧隐军无敌均假想效果，未进行军队样测，不当已成战果。
4. 高森提出平日抢杀纵火滥用，忘忧答可造压制项链/封条查、只战时解，是管理方案而非已制造制度成功杜绝。低阶特能在扩散后会有治理问题，不能只记军用收益。

## 抓样试验引群体抵抗，敌协同有规模与节点

1. 众主动接近欲抓，数百猴先退、跑慢后王指挥精神攻；应保先后，不写猴无因袭人。初以为等耗尽，后来远猴响应叫声接入使攻击愈强，判断失误来自把眼前群当封闭总量。
2. 数十万猴百里远供，精神冲击强过邪眼由主角估；高人能挡片刻不等长期免疫，若兰受漏能便几晕，丽保护不能完全屏精神。
3. 主角大天龙吟控威仅震晕近端猴，切掉接收远供/发声节点，整片攻击散；声术与精神协同界面相克，不必逐只杀几十万，也不证明所有群体都同一中心易断。
4. 主角提抓王，忘忧说王数百上千麻烦，改勾玉影响心智；普通约五级但大量协同是独立变量，神器不等跨过一切精神阈值。

## 选择皇级是组织杠杆，但同名王皇不跨物种同阶

1. 主角神识定位极强点，忘忧丹后魔量近盖次、远探仍不及他，需要他导航；知识全面与探测精度不同。
2. 本段举盖次普通→海怪精英→六翼熊王→八翼熊皇，与元素精灵皇仅六翼、蜂皇八级对照，皇是种内形态非通用等级；可统低属所以价值超单体。不得把称皇就直接算八翼。
3. 金毛蓝眼猴皇在千群/十余王中，接近路幻山幻龙早有准备便可破，首次暗中欺与已识骗局时效果不同。皇本九级/身防弱，但可集中群能不受已知同等脑限，是主角尚疑原理，不代填无限借力。

## 神器控心失败迫使改变暴露条件

1. 勾玉已催，金猴只攻主角不攻忘忧；并非美女天然免疫，而是她勾玉仅足保自己不被攻，无法压战时借全群的强精神，即使借爱神力也难。
2. 主角绫扛箭十二禁咒起逐渐矛/柱，消耗逼近极限，忘忧让他离，自己留。主角地底看护而攻击止，群援不再维持；先撤触发者才降敌阈值，换局而非无脑强加神器。
3. 息战后送果/分紫晶蜜糖，金猴贪糖抢臣民又袭威娜，威娜反击数记九法使其重伤。忘忧急制止但不及全拦，收威娜防猴群报复，借爱治金猴，再给糖即得亲近随行。主角笑一打一路救，忘忧明说非预谋，不能总结她设计伤治双簧。
4. 金猴弱身承不住九级法，与群精神巨大并存；针对不同承载层决定一击伤，不是前面数十万供能都不存在。

## 收到目标之外，内部契约与恐惧仍有成本

1. 金猴愿跟糖走，是否签正式宠契本段未说，勿补。它似向臣民下令但命令内容/全群未来服从尚未核，不能直接记几十万猴已转运纳军。
2. 忘忧临时把威娜收体违前不收承诺，主角提醒可能闹，放出后安抚；紧急安全需要和契约生活约定冲突，权力并不因善意就无争。
3. 威娜令金猴作坐骑/此后压榨，猴见其恐惧、听回述受伤再哭，说明亲近忘忧与害怕另一成员可共存；收编不是整体无忧友爱。群中女孩子喜欢新宠也不能抹伤后恐惧。
4. 威娜向众自夸自己伟大/主角累赘是其重述版本，正式因果仍含主角导航、扛攻与退出，忘忧控/交糖/治伤、威娜偶发伤害各功能，不能采用单方功劳叙事。

## 净变化与待核

幻术解释迷路/隐感，多点远程借力解释低阶群体威胁，近节点震晕切断一波攻。金猴取得来自勾玉先保己、撤主角降战态、送糖、偶发重伤再治的组合，非神器一催即服。配猴军/项链与全群控制未落实；精神远借上限/坐骑压榨后果/是否正式签约未知。
