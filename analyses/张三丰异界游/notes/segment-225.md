# segment-225｜替换中的舰队变消耗筹码，破造舰人才链与潜伏晋升

完整正式阅读；ordinal556–557，原550《海战争雄》、551《海兽来袭》；[2305694,2316203)，10099非空字符。显示[2305694,2310094)、[2310094,2314494)、[2314494,2316203)无截断至章末。B透镜；场景切外部海战/船场，末明主角仍在森林尚未第一时间获消息。屠杀只记录因果和规模，不复刻伤害细节。

## 新资源先做适配讨论，缺兵不等已有满编城市

1. 拟探索完开天空城收全猴，留最强一支护城、其余分军；隐藏真建筑制造撞障、假翼兵混真、群精神打六翼是构想，战力至少倍是估，尚无部署实战。
2. 若兰指出领地翼战士不足两万/不及古翼、发挥不到一成，给三十万全族口数添加兵员质数限制，不能拿总人口当军数。
3. 提搬紫晶蜂代空兵/养蜜，蜂皇令带蜜不攻则蜜流出成漏洞；上下分蜂/翼猴加雷柱、内置矮防登陆皆方案，蜂皇尚未收、矮驻未进。采用旧城失败教训设计反登陆，但不冒称新军已形成。

## 海盗计划本段由拟议进入战果，代价有可计算前提

1. 外景述海盗袭商船村镇，三帝为护民商/颜面连皇室舰也组联舰。海盗舰更多更好、指挥协同，击沉三帝八主力；其战斗并非免费，己五沉七伤，对方先五沉五伤后再三沉。
2. 三帝从风格疑七公主，叙述后确为她。215邀她未答的未知现在后揭为已指挥，不能删旧时未知或虚造中间信件同意过程。她用即将淘汰旧舰换对手稀少舰，原三国新魔阵舰正在生产且不少已装备，是主角解释可接受消耗的关键。
3. 碰舰狠不单因疯狂/狂化：己船替换成本低、敌产能将被毁且少，甚至二换一也愿。价值比较取决库存、后续补充和战略窗口，而非抽象损伤比越小越好。新魔阵舰不等十年大巨舰已成批。
4. 三帝抗议无证无力遭不理，伪装提供推责空间却非人人信无关；受害商村不都是敌军，经营收益伴对平民劫掠。

## 对手工业动员真实有效，随后被精准破坏再生产

1. 教廷出匠钱物支持三帝造舰。霍福宾卡场五万匠、年三主力十余中，世代林达因战略稀缺升爵；危机抬资源组织者位置不是凭空个人变强。
2. 林达报两年半留安全裕度、极限一年半，皇要十月六舰并全家刑罚，给征民间全船场/钱材人权。其吞贵族作坊、加工资、研究工序、一月完成两艘原需半年收尾，说明敌可改流程动员，不能写完全被动无能。
3. 这两艘为既有工程收尾，不是从零一月造两主力；目标六舰未达。皇又被明说健康恢复，未借此编新治疗内幕。
4. 下水仪式军官/五千卫多数发狂杀身边与观礼者、工匠纵火并专杀老技工主管，海兽再毁船/厂/杀人，官民不区。尸亡五万匠数千兵仅不足一成逃，记录为此场叙述口径；不净化成只切军工机械。
5. 林达最绝望是核心经验人才死：厂可重建、材可买，有钱亦无法即重造技术队伍。继发各大场同遭、霍福产能降六成以上、三帝主力造点近毁；“十年培养”是叙述恢复判断，不是未来十年已完整验证封锁。
6. 船场烧/战舰沉/工序组织毁/经验人死是不同层，主要打人使重建慢，不能只用破建筑总结经营打击。林达装死幸存，不见其最终被皇处刑，不补结果。

## 教廷适应并保下船厂，局部胜负又被用于内部准入

1. 教国岸短场集中、守精锐、得他国警讯后增高手，七不派海盗硬撞。海兽单次遇仙雅，比蒙/三雅/牧军迎战，海兽个体虽强但分散上陆无配合且离水弱，被集中逐个打；非所有强兽天然胜国家组织。
2. 清醒之光先遍人阻发狂，显示防方学到控心手段而适应；教损两三万精锐、多是原驻，仙雅嫡系受重点保损轻。海兽损半后退、工匠几无伤，船厂轻损，是当前实际防守成果，不写同三帝一律摧毁。
3. 仙雅葬死者斥龙青天/称惩处，教高层才完全接受她，乃兽战、神罚、代政等多年功劳累计，加人才缺的机会窗；不是一次表演即凭美名入决策层。
4. 紧后主角回述教国袭本为送功，选她巡驻故意、雅能保。先前看袭选时不佳的表面解释被后揭修正；真正因果采用送功潜入，不保“偶撞她出巡”作最终事实。
5. 主角连七公主也不给仙雅身份，命找巡场时袭并鸡犬不留，七以为要杀她。联盟指挥信息分层，己方一员承担不知情杀友表象风险，不能说全体共知演戏。死海兽被说易补炮灰、死驻军也是实际人命，不能被潜伏收益抹掉。
6. 福罗塔已有内部执行层情报但不参与决策；仙雅进核心可参谋划，升级的是信息取得位置/时效而非又一个普通线人。主角当前尚未即获捷报，远征与情报反馈有延迟。

## 净变化与待核

七公主海盗指挥/替换舰耗战及毁大船场已实际运行，215未兑现在部分闭环；海兽与控心破坏被展示，不把人鱼角色未明细节补全。三帝工业经验链受重创，教借清醒光/集中兵防住，防守不能简单归运气。仙雅斥主角表象后揭为送功入核心，信息资产升级；后续具体决策情报未见。城市蜂猴矮配置仍计划、未迁未训。
