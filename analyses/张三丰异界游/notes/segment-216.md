# segment-216｜异界经验辨毒、保留蜂群取蜜与被俘者的有限融入

完整正式阅读；ordinal537–538，原531《毒池之迷》、532《恐怖之森》；[2215011,2225451)，9958非空字符。显示[2215011,2219411)、[2219411,2223811)、[2223811,2225451)无截断至章末。B透镜；末尾刚决定进入恐怖之森，雾内强者/物品与战果未知。

## 毒素的战略价值来自知识重分类，不等已污染转生池

1. 丽对若兰讲自己初六翼随十二翼耶和德讨伐深渊毒龙皇旧事：敌略强十翼，借毒海地利让强军无功返。六翼沾水需急救、八翼受削弱，隔水护壁战破则暴露，说明环境和种属适应可逆转纯等级差；这是她亲历回述，不是本段现场测试所有等级。
2. 她靠重伤海兽立功后尚能挣出受救，同伴未回，转而专修以防再死，补足其长期不问政的动机。转生需灵魂，毒中诅咒染魂；污染者入池使效率减半多，低于六翼魂消、八翼退成四/二，主神最后令灭所有染魂者。数值与命令均来自丽回忆，不能把每个天使都判同样知情。
3. 主角听“污魂/污池”立刻想到用雅卧底接近天界投毒；这是战略用途设想，尚未运进天界或实施。雅身份仍未对丽公开。他心里猜耶和德与耶和华关系无证，不合并两名字。
4. 师兄给的紫金葫芦原为玄阴水等液体保效容器，主角不会制造且一直闲置；现在能装毒并保效，十余分钟吸干数里/百米深湖。跨体系优势来自既有器物与新知识匹配，不是随需无条件制造。容量称不大与实际湖规模并列保留相对口径。
5. 抽水使依赖毒水的数十蜥状怪主动攻击，己方是先改变栖地者，不能把后续杀兽全写无因遇袭。毒已收、怪尸入数戒、七卵取得是实际战利；卵将来养成/对转生池应用均未知。

## 相同对手上，不同能力给出不同结果

1. 忘忧三段连击只出半米坑/轻伤，六系复合球从伤口入内爆才有效；九中位皮厚魔抗使旧好用手段不自动通吃。香木矛效果有限，爱少数光弹却因光神力克暗有效，不能由此一战反推爱全面高过忘忧或香无价值。
2. 主角针入脑放火高效，丽抱若兰一手连发数十斗气刃迅杀余兽，她主动解释因旧同伴死于此而泄愤。知识贡献之外她仍有独立情绪与行动选择，非纯战斗工具。
3. 搜尸搜湖无出处线索，忘忧采灵魂读记忆才补信息：旧天使败退施空间术被毒龙皇杀，法术变异把毒水怪群移来。机制来自怪魂记忆再经忘忧转述，具体旧天使等级由主角估八翼佼佼/甚至十，不要定级。未发现其尸/装备，不能登记成所得。

## 道德争辩使丽的立场松动，但暴力控制并未消失

1. 主角忘忧惋惜没捞天使尸材/装备，丽斥亵渎；主角以各族同为生物反神族高贵，却同时用群体贬称/概括全族恶，不把其发言当中立伦理定论。
2. 众警戒她聚能，主角有奴环可令身体不进攻，她思想仍未被限。身体约束与思想自由明确分开，不能从未发生袭击反推她已同意被俘。
3. 主角重提四千年前魔侵为神族排异策划：先用教廷战后独大作结果推因，丽指出投入/牺牲也可解释并索证；主角再称三追杀天使向垂死他炫耀泄密。账本应保其叙述来源而非仅“谁获利谁策划”推断。丽平日修炼不参会，说明她不知道不等全体无此计划。
4. 她坚持任何敌人尸也应尊重，主角举千余年前自然信众数百万血朝圣路/白骨教堂；若兰称总部壁画浮雕与现教堂可查为旁证。此处为人物陈述与可查物指向，并非本段实去核验。香的仇恨让丽羞惧无词，是价值冲击，不等她已宣布脱离族群。
5. 主角回想米诺亚死，承认自己催逼太急或有责，决定缓策反而止争；这是对旧行为的后读自省，不覆写米死事实，更非此法已保证不再悲剧。随后若兰修复气氛，夜歌舞她主动叫好，显示关系局部改善。

## 资源经营不止拿到物品，还包括保护再生条件与按需分配

1. 十余天七八危点多是毒蛾/蚂蝗/十余万树妖，危险对旧探子高却不合本队新标准；最强树王九中位香不肯选。信息收益有筛选落空，非每个标记必出神器。
2. 深林紫晶蜂因元素/花卉环境不同而更强、巢占山/采几百里；主角推蜜更好。能火灭却不烧，因为再采需留活群，不把一次胜利转永久毁产。
3. 忘忧先拿几蜂试声术，找震昏不死频率；护壁挡近攻→雷鸣爆震分片震晕→丽控强蜂王→众取蜜，是试验/保护/控制/采收分工。拿近一小半、留口粮后撤，所得几千斤、皇蜜十余斤。保留有经济动机，不等蜂群自愿交换或已证明可无限再生。
4. 普蜜比旧蜂王蜜强是比较观察，皇蜜魔波浓被判断能加速冥思；忘忧取得皇蜜，主角道术与此元素关系小/强到边际收益低，故依适配分配，非所有最贵物只归他。众随后喝蜜勤修，具体修为增量未量化。
5. 忘忧仍给丽百余斤普蜜作战利，虽然对其高阶提升不大，表达按贡献承认成员。丽由自认宠物而开始重认关系，这是文本内感动；仍在强制俘虏条件下，“平等友好”是叙述/其当前体验，不可抹除奴环与旧侵犯。

## 新危点留下分歧，尚无内情

恐怖之森常年百里白雾、入者几十不返，雾止林界不外散。若兰猜智慧生物遮护，丽/忘忧感负能但无强个体，主角提出宝物遮蔽或强到避探两可能。香植物感应被隔而建议放弃；忘忧认为遮蔽自己也能做不等强，决定进去，丽以负能必恶赞成。后者属价值判断不是尚未见者罪证，主角“除耶和华不怕”亦自信而非全等级胜绩。章末盖次刚向内，任何雾主、宝物、战斗结局未知。

## 净变化与待核

毒湖来历由丽经历与怪魂回忆拼接，毒水/尸/七卵已收，污染转生池仍设想。旧手段受魔抗限制，光克暗/复合入伤/精确穿脑分别解决；丽主动分享救人又争道德，只有局部融入。蜂群保活取半与按需分配形成较完整采集回报，后续复采/修炼增幅未证。探险多点落空后抵白雾森林，内部未知。
