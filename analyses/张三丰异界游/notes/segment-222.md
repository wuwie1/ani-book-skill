# segment-222｜植物拒征的规则、护弱牵制与旧敌互救

完整正式阅读；ordinal550–551，原544《拯救熊猫》、545《阴险的树妖》；[2275645,2285976)，9821非空字符。显示[2275645,2280045)、[2280045,2284445)、[2284445,2285976)无截断至章末。B透镜；树尚未制服/香尚未签宠约，主角末已回来以绫护住丽高森，但其土遁接近后做了什么本段未交代。

## 旧能力承诺被具体规则限住，并非失效或万能

1. 香感树无恶意/打招呼，己方在捕域无遭攻击，主角推女神气息保，后来树亲口承看神语者不吃，补足祝福保护的证据。树同时警谁干涉捕食吃谁，保护不是无限替同伴攻击背书。
2. 树解释自然女神也给植物拒绝条件：实力超过神语者太多可拒点化。他自称强过神木战士是其自估，拒征权和他说可同意须分别记；不能把“能收植物”一律强征成现成能力。
3. 主角先说跟香能旅行，树以开位面观景捕食满足反驳，移动收益不适该目标；常用招募诱因失败，有自主偏好不等一定能被相同话术说服。
4. 主角转成不服即毁以夺宠，理由含香看上/不容拒，与女神许其拒权冲突。树吃异兽/主角救熊有现场风险，却不使强制收宠自然获得正当性。

## 救援的动机、时间和范围使单体强者陷入被动

1. 巨型黑白熊一家三口以光暗鱼盾苦撑，幼体先倒使盾崩，成年为护孩子而防御，不是其实际攻击能力低。主角认似旧乡熊猫/接拖克坛旧说，投缘决定救，不为先算资源收益。
2. 距远自己赶不及，以绫先帐篷护三熊，再到剑气清百米触手；距离决定先投器后人到的次序，非千钧时凭空早到。三熊感激尚不是契约宠。
3. 树欲重点抓熊，主角不能放手尽招，破空间能聚几剑来自旧在雅处学研究，具体知识解关键环节，但只阻移不结束源源攻势。切勿总结跨体系知识必一招终局。
4. 主角承按硬拼累死亦未必救全、绝招有重大保密关系而犹豫；力量多不等所有可用。丽带圣炎来、称怕被看懦，主角谢；高森主动来好战，二者协助不是明确奴令下才行动。

## 被救者也能改战局，多元能力需按条件估值

1. 双成年离盾改进攻，黑白两球各耗少、相撞爆强且可遥控曲行，爪黑腐白炎或混爆，清大部分触手；主角推无幼累或可自出，仍是假设不抹前面真实濒死。
2. 四强者护幼已安全，主角才离开直取树干，把约束解除换主动。战斗力是保护对象/目标共同决定，不能只比等级。熊是否普通本界物种、来历为何尚未详。
3. 高森的低级冥火也能烧触手，丽圣炎亦可，分别有效不证明树本体能一瞬烧死或所有火法同强。

## 对手会保留招法，主角试探犯错后换路径

1. 上升数百米以为越触手界，遭大叶高速突袭；第二叶较慢引怀疑，转向跟踪，被剑气碰后爆炸，碎片重硬带毒。主角离千米仍靠绫扛，威力十三级只是对初叶估计，不给所有叶统一定级。
2. 树先示巨叶后近干才生密小枝/万叶齐发，使主角准备不足。巨大叶不便近打/可能误树，主角利用其限制接近；树改小叶覆盖打破这项应对，是交互适应而非敌每招都愚。
3. 主角用心心相印退到忘忧旁，不肯承失利只许五分钟，土遁改贴干小角接近；“五分钟结束”仍承诺，本段没给制服结果，不能提前填兑现。
4. 己方技避让本人安全却把攻势转给留场伙伴，主角退出有团队外部成本；后续绫返护只证回来，未交代中途究竟如何。

## 队友关系在共同危险中改变，价值不统一才有选择

1. 树怒把万叶集向空中丽，她可闪却会让刚放招回气的高森受，故硬挡耗空后被压地。当前友情行为依实时位置/回气需求，不是她永远只能正面硬接。
2. 高森见旧敌为己挡而感动，先养气后撑圈换她歇；她恢复再挡，两人互换争时间，却总消耗快过恢复，轮换不等永动。
3. 最后高森用再生肉身护她，疼仍在、腐血化入叶，恢复被说经前刑更快，这是诅咒机制回报但不能以升级回报替酷刑正当化。只此实证对本批叶攻恢复，不能推广烧灰亦不死。
4. 丽称不弃暂时战友是天使荣耀，高森说不欠女人/鸟人是矮尊严，仍互骂且争必要时可弃战友。行动趋同而信条不同，不必先共同理念才协作，也不等旧族仇从此全消。
5. 主角返绫护两人后以暧昧笑话打断，章末危险有局部遮断，树总体仍攻击中。相互救命是被俘强者自发的关系增量，不写为主人已完全思想改造成功。

## 净变化与待核

祝福保不干涉者/植物可拒征两规则清楚，先救三熊后以强制收树开战。熊双属性攻击、丽与高森主动援护解除幼体牵制；树追踪爆毒叶与小叶覆盖反击，主角一度退场转土遁，团队为此几耗尽。旧敌在战友关系中轮换和肉身互救，绫返护暂解濒危。树本体状况/是否将被收、五分钟承诺、熊来历与契约均未兑。
