# segment-218｜尸骨指路与分配持续，旧敌高森醒来但决斗未决

完整正式阅读；ordinal541–542，原535《城内景象》、536《怒之典章》；[2235804,2246181)，9923非空字符。显示[2235804,2240204)、[2240204,2244604)、[2244604,2246181)无截断至章末。B透镜；高森与丽只到气势/声势交锋，尚未拳枪决胜，不能预记胜负或归降。

## 遗迹调查把战斗知识与物证连成可行动判断

1. 普营神识无宝，众不入免风化扬尘；第三营见翼尸握断弓/拳握箭、胸骨折，忘忧推近身未及射，主角据技击推向上直拳，若兰据体高/不可飞问矮小拳斗者，丽提出狂暴矮人。多专业各补一条件，尸骨不是直接自动显示凶手名字。
2. 丽解释狂暴矮人同源上古矮王血、喜战分出入魔、力量斗气/双防强，恶境演化快敏、又保铸造而有好装。虽开头说不喜铸造，后仍精通不等完全丧失技艺。普通剑圣、顶近六翼是她战场知识口径。
3. 他们用拳可不顾伤抓飞者围杀，天使曾明禁近战；不会飞在狭洞反不成劣，近距地形改军种优势。眼怕突强光、无盔头弱、伤重仍攻击，构成对策建议，尚未现场对高森逐项验证。
4. 若兰问数量，丽不关心总数只见曾出上万；大陆十剑圣与其万人对比强调跨位面标准差，但不能登记族总口。
5. 大厅百翼/四矮骨使丽疑损失反常，若兰提矮上城先过雷火带伤，忘忧见断臂肩焦/身边十余断颈作局部支持。不是原先所有四矮都满状态，更非翼人忽然单兵全面提升。以伤势条件修正战力推演是本段低推断要点。

## 城内未知路线不靠全知，靠守备密度和验证回路

1. 洞口同形无标、翼上下竖井无梯，丽亦不知方向；三智同提跟死人，理由是重要区守重/死多。沿战尸聚集多次向上后，见密尸堵口，才转入特定洞。此法有基于本战分布的前提，非所有遗迹必可靠。
2. 从四十二床普通营、十一床、三人、单人房，结合大厅缩小/通道变少推精锐与官住、靠近中心；属于布局和待遇推断，未见铭牌逐级证实。
3. 首祭厅华美雕像器具/壁画却无实用记录，兽皮风化；主角不因气派就强称得秘籍。雕像镶墙他不愿毁原貌而放下，与前述占物冲动并存，不能扁成一律拆尽，也不能据此洗去全程洗劫。
4. 沿侧门/每三房一厅猜祭区环路会有核心接口，同时留记号防绕圈。找路是试探与失败防护，走久也自疑，并非知道全图。最终出现三百米巨殿，证路线取得进展但未证明已到控制核心。

## 物件有审美/交易/功能多种价值，分配是持续工作

1. 房中三五级魔法首饰对强队增幅有限，却因翼式工艺有审美新奇；花生风宝石来自腐杖。主角据首饰/材等级推女中高法师，自己承不熟翼人，不能反推墓主准确身份履历。
2. 隔空取物避尘，后续数百首饰/宝石及一把不错弓实际收取；这些不是此前求顶级箭技秘籍的兑现，二者价值类型应分。
3. 忘忧分给每人，含丽与黑龙，叙述明知分不公后果。相比只战后一次赏赐，探索路上持续参与和分配维持团队协作；仍未改变丽奴环、黑龙所属等法律/强制关系。
4. 主角以女人如鸭描述众兴奋是叙述者性别化嘲讽，不要把全部女性必然浅薄作为机制结论；若兰/忘忧/丽此前正以专业判断推动路线。

## 核心前的旧仇让被俘者主动争战

1. 巨殿堆上万白骨、数百狂暴矮，金属般硬韧墙被斗气打米深凹而结构未坏，显示旧战强烈。危险来自风神足下隐门的完整肉身矮人，非殿上每具骨都已变僵尸。先前“可能亡灵”仍需后验，当前高森为何久活尚未解释。
2. 丽认高森为怒之典章/狂暴矮人王，称唯一正面抗她战士。旧事先说三日击败他与七长老四死三重伤，经主角等识其保留后承己同样手脚断、仅一翼完、无力自疗，靠同伴救，是两败俱伤。需用补述修正首个胜利口径，不能独立摘成丽完胜八人。
3. 丽说当年高森初入六翼门槛、七长老亦强，她有神器否则输；主角强调四千年前丽不及现在。旧八打一平局不直接等于今高森一人可胜现丽；久睡得力与今日差距未测。
4. 丽主动把若兰交主角、取奥格瑞根龙枪，要求别人别抢；主角愿旁观因硬骨难啃并欲看能力。战斗任务由她旧仇/胜负愿望推动，非全是主人控制。
5. 丽进大殿恢复体型，解除狭洞缩身的不适/一成损失条件；两气势撞散全殿骨甲显示双方强，但不等已命中伤。高森醒称积力为死兄弟报仇，说明对抗动机是旧损/亲情而非纯随机宝守。
6. 声吼在封闭殿放大，己方耳鸣若兰几晕，主角先护壁再道法稳神并骂；弱者即使被强者带队仍受外溢伤，保护需行动成本。不能把己方修为高自动推广全员免疫。

## 净变化与待核

路线由尸密度/伤势/布局持续试探而推进；数百装饰首饰与弓为实际所得，记录风化/首祭厅无实用收获是反例，箭技尚无。高森现身/苏醒，丽自请决斗，其旧完胜说已修正为两败俱伤。高森久活机制、现实力/是否亡灵、隐门守物、城核心与箭技、当前决斗结果全待读。
