# 文风与技法｜让读者知道一件旁人还不知道的事

| 写法 | 当场看见什么 | 为什么能撑起下一段 |
| --- | --- | --- |
| 两个视角共享一个问题 | 地面和宇航员都只能说自己看到了龙棺。插进同学聚会，一辆车就能戳穿旁人对叶凡近况的判断。 | 小谜当场有解，让读者知道事情确有可能被纠正；更远的信号仍无人能读。现代器物、饭桌动作与洪荒尺度交替，开篇无需长篇解释世界观。[两个尺度的目击](../notes/segment-001.md) · [人数与异变](../notes/segment-002.md) |
| 知道真相的人不在叙述中心 | 炉外韩长老听见海响，按自己的经验以为稀世丹药将成；炉内叶凡正在解封吃药。响声和气味的变化都允许两套解释。 | 用读者已知的答案造悬念。要等的是老人还会把自己错到哪里，以及开盖那一刻谁站起来。倒计时来自他自己的配方。[药与寻人印记](../notes/segment-028.md) · [闻香与开盖](../notes/segment-029.md) |
| 让宏大的景象伤及画面边缘 | 海上升明月、苦海种金莲，画面中央只是衣角破了、头发断了。场边修士碰上散出的月华却化为血雾。 | 把诗意异相分成两个观看距离，强弱差不需再由境界表代说。这个落差也让后来叶凡能顶住明月、但尚挨不住全力一击的程度可感。[异相交锋](../notes/segment-040.md) · [圣体受试](../notes/segment-049.md) |
| 断章停在足以改变判断的一拍 | 殿内白骨下有姓名和临终疑问，死门通向另一重关；域门横渡成功般开启，却在虚空中裂开；华云飞的琴声人人可闻，另一次自语只有暗中的叶凡听见。 | 新段须处理前段刚改变的处境。姓名能从古籍反查，裂开的路逼人抱紧身边人，自语使看琴者的好感与知情者的疑虑分岔。[殿壁](../notes/segment-041.md) · [域门破裂](../notes/segment-048.md) · [隔着火听见的话](../notes/segment-056.md) |
| 用一件寻常物收住数百章的线 | 二老的日记和住过的房、妖皇匣里的野花、姬紫月埋下的衣服，都比抽象的一生更容易指认。 | 物件有来历和经手人，能证明某人等过、找过、哀悼过。它没有权力继续替死者发言，读者能从这种克制里觉出时间。[衣冠冢](../notes/segment-056.md) · [旧屋](../notes/segment-326.md) · [野花](../notes/segment-479.md) |
| 同一动作换一个人做 | 圣皇残念给叶凡九个帝字，叶凡等曈曈自己求学，也以相近的动作授字。三百年后，老来救人的强者醒来第一件事是受普通人照拂。 | 读者认得动作，就能辨出主动权已经换手。一处足够短的回声，可以省去师徒恩义的自我说明。[赠字](../notes/segment-254.md) · [给孩子授字](../notes/segment-256.md) · [白夜祖孙](../notes/segment-552.md) |
| 在极长时间里留一条可回认的细节 | 铜棺初见是远方图像，后有少数人能听见的经声。末段再闻帝符，与人一同开棺，旧物先于解释重新出现。 | 用途改变得比名字慢。等到从猜“里面葬了谁”变成问“古人给仙域留下了什么”，读者还能沿同一件物证走回开头。[图像](../notes/segment-001.md) · [经声](../notes/segment-007.md) · [内棺所见](../notes/segment-623.md) |

**语言和节奏。** 宇宙大战常让人带着称号和夸张异相出场，开阔战场；返乡和告别则把镜头放回能站几个人的一间房、一座坟。神城估石、黑皇插话、段德争物也会把紧张场面拉回人的贪心和机警。转换有效的一刻，是一个小动作还会改变局面；弱处是观众解释同一惊讶多次、战斗反复升高却仍停在原问题。底本的文字复载还会人为放大重复感，须和作者有意的节奏分开。[无号篇与第145章重叙](../notes/segment-048.md) · [会门口的讨债](../notes/segment-283.md) · [守坟](../notes/segment-291.md) · [回到房中](../notes/segment-326.md)

**叙述可信度。** 人物用“见仙”“死了”“长着同一张脸”说出的经常只是当场能给的判断。文字随后可能换证人、回到器物，甚至由作者更正一个出场人的名字。读这类段落时，应分别记下谁说过、后来谁见到、哪里才有足以排除另一种解释的事件。[血与执念显影](../notes/segment-479.md) · [无始之影](../notes/segment-537.md) · [携镜人的更正](../notes/segment-546.md) · [无始亲身在场](../notes/segment-623.md)
