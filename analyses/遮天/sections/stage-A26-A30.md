# A26–A30｜从接过一个孩子到争得众人一席

太阳圣皇残念被送回故土后赠九字与扶桑枝，叶凡从海眼出来，获知古教被灭，从姜伯手中接过曈曈。孩子要先有哀悼的时间，自己开口求学后才有调治、刻字与开轮海。庞博说明北斗分途是为了有人照应两家父母，也把离别变成双方都能承担的决定。安妙依则亲选去西漠，叶凡能给的是后援，往后如何修行由她来定。[曈曈求学](../notes/segment-256.md) · [庞博说明留守](../notes/segment-264.md) · [安妙依西行](../notes/segment-272.md)
