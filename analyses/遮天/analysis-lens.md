# 《遮天》怎样让“有路可走”变得重要

正式观察方向于 2026-11-24 随全文范围一并确认。下列判断起自八组定位预读。编号与快照行号可在[预读坐标表](source/preview-windows.json)中复核。

## 同一部书，三种读法

| 观察方向 | 两处以上可查的证据 | 检验它的反例 |
| --- | --- | --- |
| **谁给叶凡开路，他又能带谁过去**（主线） | 第412章，叶凡已入四极，却压不住作用在道基上的先天纹络。姜太虚耗自己的血帮他，他甚至想叫停。第1597章，叶凡知道入主旧圣体躯壳会危及自身，仍想去迎战。第1822章，昔日天兵渐老，叶凡重开他们的神源封印，等诸人同去。 | 第935章，叶凡终于回到地球，许琼却告诉他，父母在三年前相继去世。能抵达一个地方，仍可能赶不上一段人生。 |
| **古史能否由后来的人亲自验证**（伏笔） | 第1章先有远方图像，继而是近地宇航员目击。第25章别人听不见棺音，叶凡借菩提子听清，却不懂经义。第1821章则由叶凡亲手开内棺，请女帝共同核对小世界与仙域的关系。 | 第392章神王醒转与彩云死别，情绪回报来自两件事只差半日。给读者更多古史资料也无法补偿这段时间。 |
| **一个看似已破的关口，还会向谁收代价**（规则） | 第412章四极已入、道图仍压。第420章风族诊出生命本源受伤，原本乐观的投资者改口。第1587章至尊成仙失败，弱小生灵的寿命成为强者续命的物资。 | 第1章仅靠反复目击就能让读者往下读，主角当时还没有出场。早期悬疑另有独立价值。 |

## 章里具体看什么

1. **谁原来只能旁观，谁现在有权行动？** 看一件事从远观、传闻、触碰到能验证、能运用的具体变化。结局须写清哪些人共同打开了仙域。
2. **规则在动作之后还留下什么？** 分清人物已经做到的事、旁观者的解读与下一章仍有效的代价。以第420章为例，诊断写的是当时可见的伤与预期寿限。
3. **同行要付谁的时间？** 追查给予援手的人、作出选择的人、因此受益的人。许琼自己另有生活，神王有自己的故人，老去的部众需要提前封存；三者做了不同的选择。
4. **读者期待的答案何时换了问题？** 棺中葬着谁的猜想，后来会被打开内棺时所见的世界改写。保留读者当时可能得到的信息，再与远段的证据连接。

如果省掉姜太虚流出的血，冲关会变成一次个人突破；若省掉父母早逝，重返地球很容易被读成成功赶到。若抹去封存和多人开门，终局也就难以解释天兵为什么还能来。这是选取主线的理由。遇到纯粹靠技艺、解谜或人际喜剧交付的阶段，各按该段实际效果记录。

笔记保存章末处境、设定如何改变选择、一次读者回报及其边界。人物在关系总表里追踪。时间顺序、跨段伏笔与世界规则分别保留证据。若中后段反复出现足以改变主线理解的证据，先在未决账标出相反材料。
