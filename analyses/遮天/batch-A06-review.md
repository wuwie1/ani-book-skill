# A06｜庇护的价钱，从谁的口中说出来

| 场面 | 改变下一步的条件 |
| --- | --- |
| 老疯子在夕阳下哭，随后破开山体寻找域门 | 太玄诸强急于从他身上参悟长生，叶凡先见到的是一个仍记得死者的幸存者。域门崩碎后，叶凡抱住老人活下去，也把他背回拙峰。无号篇与第145章重叙同一场琴会，姬皓月只在会上试他一次。[夕阳和青石](notes/segment-047.md) · [破门和琴会](notes/segment-048.md) |
| 叶凡放出铜殿消息，和紫月分别又重逢 | 初次分别，他送她母气精粹。小村重逢，他用神泉为她疗伤。孔雀王放他离开时，他仍替她求情；不久后为逃过围杀，又轮到她教他家传秘术。分别的时点让读者看清了几次相助中哪些有选择。[离开太玄](notes/segment-049.md) · [水塘边](notes/segment-050.md) · [万里护送](notes/segment-051.md) |
| 姬家要把救命债还清，同时要收回经文 | 管家先是给源的经手人，后来却成了取命的人。叶凡杀他脱困，把经文可能传遍全城的代价摊在宿老面前。孔雀王出面使追兵退让，也使叶凡的长相从此为天下人所知。[索经](notes/segment-052.md) · [名声的代价](notes/segment-053.md) |
| 火域从处死地变成炼器处 | 菩提子辟火，紫火炼母气，突入更深处又要青莲定住轮海。叶凡每次只能多做一件事；刚成的鼎甚至祭三次就难以支撑。等他能压死境界更高的名宿，紫月已经在火域外亲手替他埋了旧衣。[瓶未烧毁](notes/segment-054.md) · [三次祭鼎](notes/segment-055.md) · [衣冠冢](notes/segment-056.md) |

华云飞的琴曾让众人连同百鸟都安静下来。批末叶凡见查麻衣人死处的老人向他施礼，又听到他谈取人本源。先前确有其事的礼貌因这个新证据生出另一层意思，私下传音的细节仍然空着。
