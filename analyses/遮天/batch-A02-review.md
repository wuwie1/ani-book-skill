# A02｜废体凭什么留下，仙苗凭什么能走

第24–54章。棺中死因得以查清，活着走出禁地并没有让同窗得到同样的余生。六处洞天挑人时，见过圣体的老人反而先给叶凡判定前路。批尾，庞博失去身体的控制，叶凡独自追到了火山口旁的古殿。

| 让人物改选的关口 | 事实与结构作用 |
| --- | --- |
| 棺中指控 | 刘云志凭位置、力气与旧怨指认叶凡，李小曼交代自己为何不能替人作证，柳依依愿意信他。直到检查遗体找到鳄，读者才得到可以排除一种死因的东西。关系可以决定人愿不愿作证，尸体才能回答眼前的问题。[棺中](notes/segment-007.md) |
| 离开禁地 | 果实、泉水与短暂停留，在不同人身上留下极不均匀的效果。当事人能比较容貌和体力，却识不出体质。薇薇能见仙宫又负责领人出去，两种信息差落在同一个人身上。[摘果](notes/segment-008.md) · [老去](notes/segment-009.md) · [择徒](notes/segment-010.md) |
| 给叶凡一个位置 | 庞博愿拿自己的入门资格换叶凡同行，叶凡只愿作客。吴清风既给玉牌听课，也肯亲自试。庞博服七瓶药已吃不消，正好能把余下五十九瓶交给眼下只进不出的朋友。这几个人的帮助各解决了一项实在的限制。[入门](notes/segment-011.md) · [听课](notes/segment-012.md) · [开海](notes/segment-013.md) |
| 成功为何要保密 | 金光外显，庞博能够独立证实；保持秘密的叶凡也放弃了请求门派倾力资助的可能。韩长老在蛇尸上取材、打量两人，具体演了一遍他会如何看待服过神药的活人。[秘经](notes/segment-014.md) · [采药](notes/segment-015.md) · [失散](notes/segment-016.md) |

**责任第一次对调。** 入门时庞博把叶凡带进洞天，废墟里叶凡跟着失控的庞博深入险境。两人的本领还不足以更改对方的处境，愿意追过去已经能改变小说下一段写什么。把两人写成永远互相扶助也会遗漏他们因引蛇而使别的同行者受害的后果。[段16](notes/segment-016.md)

**交接。** 火山内浮沉的古殿解释闷响从哪里传来。绿光从叶凡体内逃出、进入庞博，是后面判断其身份和意愿的起点。
