# A28 批次复核

- 267–269 叶凡守妖殿界出门迎王家，齐麟曾寻友又开阵台，为紫天都线回接旧交。引敌留南岭最初是为故友分压，同时为蛮军北上提供时间。王成天又摧毁已迁走的荒村，原址损失无法抹去；四路合围由部落自身动员并留下守山之力。
- 269–271 率西路与单人灭王家的坊间浓缩有别。苍龙、白虎、族长、圣兵操持者及神源液封存的战祖各有作用，叶凡赴急冲阵与用残锤、炸神源只是多个决定环节之一。双方死伤极重，蛮族主动封退路，叶凡传讯引诸仇家追余部，主线不可把复仇扩大战净化成护孤。
- 272–273 安妙依昔年借涅槃救叶凡，此番怕道途断在情念，选择亲去西漠。叶凡由交手求旧人归返，到暂交后援、由她西行。寻涂飞也有能力边界，见疑似冻躯无力救，老妪无应并有化道迹象，尚不能坐实两人状态。
- 274–275 真唵化斗音、圣皇帝字及元神合道都有前期来历，三人用十八字与圣炉磨去祖王字迹。蛮族随后带苍龙回护叶凡，姬家兄妹送带伤李黑水，叶凡以圣血、不死药及道悟偿还赌石旧援，具体推进到半月后可自行修行。
- 275–276 真旧战画面与假疯帝证道说并用，只使古族迟疑。借圣壳与借不到帝兵反映个人计划与群体安全的界线，紫山三人也有各自算盘。证据仅到高台人影，真正的大帝威慑待续。
