# A18｜有人能救与终于赶到

覆盖 segment-167–176，第477–502章，含第482章同事件异题复载。主证据见 CLAIM-0167 至 CLAIM-0176。

- **姜太虚的恩越过其本人。** 王神医辨出叶凡伤已愈，因神王于祖先有恩而公开维持伤讯。叶凡同样把找正本的地点告知曾授步法的老疯子，后者选择同行。见 segment-167–168。
- **护送者有行动上限。** 老疯子护住小囡囡与同伴，但敌手仍敢趁队伍分开试探。他能修正去错方向的棋盘，也要九天参悟无始留下的入口残纹，登山遇阻还需另行推演。见 segment-170–174。
- **前人留下的路可以再走。** 天璇残步引出行诀，老疯子开棺、无始阵榜挡煞与各人实际参悟共同成立。石地星图是返乡线索，尚未被用来返乡。见 segment-174–175。
- **行诀的近段回报。** segment-171 中叶凡赶到救孩子而自身遇伏，还有赖老疯子跨山干预。segment-176 中老疯子已经离开，叶凡凭新习行诀后发先至，自己挡住杀剑。随后买凶牵制对手，扩大争斗风险，证明给同伴开路与制衡强敌是两种效果。
- **前传条件。** segment-175 圣体共鸣使叶凡能看见各秘境的极限修法并短时借旧躯；异物仍能把他逐出。不得由短时控制推出永久携走或全力可用。八百神岛以后谁买凶暂无实证，两神朝命令只说明存在多方委托。
