# A38｜援手只替人争时间，路最终要自己走

从题署第1057章《惊艳》至第1086章《摇光裂》。覆盖目录 1068–1097，Unicode `[4344619,4462505)`，共 102,166 非空字符。第1071章末把中棍者写成浑拓，随后第1072章直写昆宙身死、浑拓继续调停，笔记保留这个底本差异。
