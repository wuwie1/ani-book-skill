# A60 诸友争得百年

- 叶凡替棋局中的同伴破围，旧盟也赐与天庭时间。宁飞由簪中残念护天后而殒，天后自弃续命之血求同葬；道具召出的天皇形象和魔罐化出的女帝旧体均须与真身分读。[段587](notes/segment-587.md) [段589](notes/segment-589.md)
- 川英百年镇地府，黑皇在天庭离散后代叶凡作主。合杀坐骑后可以再散，禁区后人等百年约满却以战部死伤逼天庭集中；黑皇拒让囡囡应敌，因为可能的未来中她再也没回来。[段590](notes/segment-590.md) [段592](notes/segment-592.md) [段593](notes/segment-593.md)
- 叶凡自行毁魂灯，源封坐标却照时启动。孩子在百年后被实际接出，叶凡也短暂回家，在小紫扑进怀里之后又去应劫。鼎归还储存赤血，精神在万年景象中耗用、排金血与重体同写，衰老有具体成因。[段594](notes/segment-594.md)
- 川英拒饮血，自赴地府挡冥皇。叶凡跨八九双劫，诛沧澜，再经九日煎熬和诸至尊截杀，终靠烙印、藏兵、命泉和时间补到大成，首次上门问川英之死。第三关的仙台只有龙身探入，大成与真正成帝当分别记账。[段595](notes/segment-595.md) [段596](notes/segment-596.md)
