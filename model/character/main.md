# 网文人物写作参考

从这章遇到的写作问题选人。每张卡都写了原作中发生的事，附有出处、一个换了人物和处境的原创场景，以及一段可直接填写的提示词。《遮天》按中文章名里的章号标注，链接指向起点国际公开试读。卡中涉及对应篇章的剧透。

## 按故事需要选人

| 这章想解决什么 | 人物卡 | 动笔前先想清楚 |
| --- | --- | --- |
| 想让一个聪明人讨喜，既能劝住场面，也容得下主角反驳 | [王也](王也.md) · 《一人之下》 | 他本可省掉哪桩麻烦？什么人一受委屈，他就舍不得走了？ |
| 高潮已经打得够久，局势还缺一次会让读者心疼的转折 | [于禁](于禁.md) · 《镇魂街》 | 谁许过什么诺？当他再也护不住人，谁接得下他的责任？ |
| 一队人只会商量正事，想让同伴惹人发笑，又把故事往前推 | [黑皇](黑皇.md) · 《遮天》 | 他这次想占哪样便宜？谁有本事让他把这笔便宜挣回来？ |
| 主角要过一道靠自己还够不到的门槛，需要一位值得惦记的前辈 | [姜太虚](姜太虚.md) · 《遮天》 | 前辈能教会什么？到了什么关头，学生也有东西能给老师？ |
| 想写普通人的奋斗，让读者在关键时刻相信这件事就该他来 | [迈特凯](迈特凯.md) · 《火影忍者》 | 哪次失败改变了练法？等到兑现时，究竟谁用得上这门笨功夫？ |

王也和黑皇都能写出幽默。主角快被大道理压得喘不过气时，王也式的人可以一句日常话把选择还给他。一路赶得太顺时，黑皇式的同伴会为自己争一点好处，给全队惹出下一件正事。于禁和姜太虚都肯为别人付账。写于禁，先想他离开后谁顶上那个空位。写姜太虚，先想前辈离场几章后，读者还能在哪个动作里认出他的教导。

## 给生成提示词准备什么

| 要给的信息 | 写到什么程度就够用 |
| --- | --- |
| 本书的场合 | 给出题材、当前视角、本章开头的困局和结尾必须保住的结果。写「散场前，替补得拿到一次独唱机会」会比「这章要燃」更好用。 |
| 人物自己的日子 | 他靠什么生活，散场后原想去做什么，有什么小毛病。给他一件主角缺席时也值得去做的事。 |
| 一段具体关系 | 主角欠他什么，他又曾看错主角哪一点。对谁能开玩笑，对谁会把话咽回去？ |
| 本事和限度 | 给一个旁人能看见的本事，一件这个本事办不到的事，以及他出手会失去的东西。 |
| 前因和后果 | 前文出现过的一个人、一件物品或一句约定。这场过后，写明谁多了一种选择，或哪件事再也回不到原样。 |

### 从零设计一个人物

手里只有题材和喜欢的人物时，可以从这几句开始。

```text
我的小说写【题材或一句话故事】，我希望读者对新人物产生【喜欢、心疼、想看他出场等具体感受】。
参考【人物卡文件名】中我最喜欢的【一个动作或选择】，设计一个属于本书的人物。
给我他平时的营生、自己想要的东西、最拿手和最容易失手的事，以及他与主角互相需要又容易闹僵的原因。
写一个旁人一眼能认出的习惯。用三个短场景让我看见他初次露面、让朋友失望、后来作出艰难选择的样子。
身份、关系和后果都从我的故事里长出来。还没定的设定写成可换的选项。
```

### 把已有角色写进本章

选好卡后，可以直接用卡末的专用提示词。若已有章纲，也可以把下面这段和章纲一起交给 Codex。

```text
阅读人物卡【文件名】。我的小说写【题材与世界规则】，本章从【谁】的视角展开。
主角想【目标】，眼下被【困局】拦住，章末要保留【既定结果】。
原创配角以【身份】为生，自己想【私愿】，与主角有过【一件往事】。
前文能用的伏笔是【细节】，这次他最多肯付【代价】。
请借用卡里能解决本章问题的那个做法，用本书的人名、本事、关系和说话习惯重新设计。
先用三句写出他为什么来、做了什么、让谁改变了决定，再写最有戏的一段。
如果缺一项关键信息，先给一个贴合章纲的暂定选项，并标明我可以换掉哪里。
```

## 后续增加人物或任务

新增时告诉 Codex「加《作品》的某人。我最喜欢他在某场戏里的某个选择，想用来解决我书里的某个问题」。若只记得一幕，描述谁在场、发生了什么也可以。沿用一人一份 `人物名.md`，在上表按用途加一行。同名角色可在文件名附作品名。

已有角色遇到新用途，直接把新任务补到原卡。例如「给黑皇这张卡补一个用法，我想写两个老搭档吵完架重新上路」。补上适用场合、原创场景和这次要给的提示词，原有用法仍可单独查阅。
