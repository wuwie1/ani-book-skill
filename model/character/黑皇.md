# 黑皇

辰东小说《遮天》里的大黑狗。适合当长途冒险里的常驻同伴。它每回出场都真心想要点什么，偏偏也真有两手，队友见它来能同时松一口气、捂一下钱袋。

## 回看哪两场

- 在石寨，叶凡怀疑这只来历不明的大黑狗可能危害人畜。黑皇听懂了他的试探，当即为自己的名声不平，转眼又在晚宴上埋头吃肉。张五爷却说它待自己很友善。三个人对同一条狗各有看法，读者已能体会它的派头，也知道石寨的人为什么肯留它吃饭。[起点国际试读，第239章《黑皇》](https://www.webnovel.com/book/遮天_22558870000847902/第二百三十九章-黑皇_96889836522197724)
- 对阵段德时，黑皇用事先布下的道纹控制雷电，还有心思讨要财物，扬言要收对方做「人宠」。段德气恼，涂飞在旁起哄，险些也挨一下，叶凡则已备好退路。同一句大话给了三个人三种动作，交手还在往前走。[起点国际试读，第306章《天劫》](https://www.webnovel.com/book/遮天_22558870000847902/第三百零六章-天劫_96889888065819356)

## 笑点怎样带着情节走

黑皇把自己看得很高，旁人也确实有求于它。它认真争面子、争好处的那一刻，读者同时看得见一位摆架子的强者和一条馋狗。原本严肃的寻宝、斗法因此有了几种味道。叶凡可以陪它算计，段德会记仇，张五爷的一顿饭又给它留了点亲近人的温度。

写这种同伴，最好先定好一笔具体的交易。让他想赚一份好处，拿真本事把局做成，再给对手或队友一次顺着他的话反将一军的机会。笑完要有人得了线索、欠下人情或改了行程。要是删掉俏皮台词，大家仍会因为他惹出的事忙上半章，这段喜剧就有了根。

## 塑造前要定的事

- 他最眼馋什么，肯为此耍什么小聪明？给欲望一个固定方向，换场合时才能变出新花样。
- 队友为何还愿带着他？定一门关键时真用得上的手艺，再定一个他看重到愿意吃亏的人。
- 谁能当场拆穿他，谁会顺杆往上爬？这回占便宜的后果由谁收拾？偶尔让他自己认账，下回读者才还肯跟他玩。

## 原创场景示例

五个人得赶下一班船去接人，盘缠只够三张票。听说随船奏乐能免票，旧货商立刻把四个伙伴报成乐班，一人发一面铺里卖不掉的锣。船东听他们齐齐敲过一下，爽快地给了五张免票，随即递来三张喜帖。「巧了，三家都点了曲子，班主先挑？」伙伴们立刻尊他一声老师傅，把他推到了头里。他在仪仗行待过，倒还真能带四个外行合上一段。等主角赶在下个码头接到人，他正拿自己的货款请隔壁舱的唢呐手救第二场。回程那天，最先抢着问他还免不免票的，恰是锣敲得最差的那个。

```text
给【队伍当前任务】写一场同行喜剧。原创配角很想占【具体便宜】，真本事是【一门手艺】。
让他一本正经提出一个对自己有利的办法。队友【甲】拆穿算盘，对手或队友【乙】索性答应，
再顺着他自己开出的条件要他履约。让他认一次账，也让他的本事为主角办成一件正事。
从最先识破他的那个人的视角写一段。笑点落在反应和动作上，结尾留下一个会影响下章的新麻烦。
角色身份、争的东西和玩笑都从我的世界【设定】里取。
```
