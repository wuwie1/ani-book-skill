# 王也

《一人之下》里，武当出身的王也是个明知道管闲事会耽误自己、还是忍不住伸手的聪明人。他看得比旁人多，也有自己认准的道理。真到劝不动一个人的时候，他又肯让路。

## 回看哪几场

- 罗天大醮上，萧霄在比试中遭反噬，王也和诸葛青下场，同冯宝宝一起救人。轮到这两位术士交手，王也用风后奇门压住诸葛青。诸葛青弄不明白败因，执意求解，反伤了自己。王也有本事赢下比试，诸葛青怎样消化这场败仗，却要由诸葛青自己来。[动画第二季第9集《奇门显像》](https://www.bilibili.com/bangumi/play/ep115916) · [第10集《风后奇门》](https://www.bilibili.com/bangumi/play/ep115917)
- 对张楚岚时，场上竟比起吃馒头。王也借这顿饭劝他放下对真相的追索，张楚岚仍想走下去，王也认输。一场本该分高下的比试，最后让观众看清了两人的分歧，也保住了两人的体面。[动画第二季第11集《清静经》](https://www.bilibili.com/bangumi/play/ep115918)
- 赛后，觊觎风后奇门的人盯上了王也的家人。经诸葛青提议，王也求助于张楚岚等人。那个上次还在给别人指路的人，轮到自己的难题，也得开口求人。[腾讯视频 WeTV 第三季第1集及剧情简介](https://wetv.vip/zh-cn/play/v7mtpin095ax30l/x0045m6mlll-一人之下_第3季_01)

## 天分、正义感和幽默怎样长在一个人身上

王也最耐看的地方，是他和主角可以各有各的道理。王也看得见继续追查的代价，张楚岚却是那个必须带着疑问过日子的人。写原创时，可以让配角准确判断一件事会怎么收场，却猜错这件事对主角值多少。他劝得真，主角拒绝得也真，两个人就都站住了。

他的松弛也要有来处。把两个高手放在馒头面前，读者先能笑，接着仍会听他们怎么选。写这类人的幽默，可以让他在众人端起架子时留意一件实在的小事，顺手拿自己开涮。等旁人真要吃亏，他肯把自己的清静搭进去，那句玩笑才有分量。

## 塑造前要定的事

- 给他的聪明找一种可见的凭据，例如一处别人天天经过、偏偏没人留意的异常。再定一个他容易看错的人心。
- 给他一条和主角可能相冲的原则。他愿意为谁出面，肯丢哪份好处，又会在哪一步停手，让当事人自己说话？
- 找一个敢拆他台、事后又能帮他的人。独处时的散漫、跟此人斗嘴时的狼狈、对弱者说话时的分寸，可以各有一点差别。

## 原创场景示例

商会查失货，掌柜作证，说亲耳听过半夜的报时钟，才看见学徒进库。修钟的闻秋本来已经摸到了门闩，又转回来，把用布包着的钟锤搁在桌上。「它在我家躺三天了。要真响了，修钟钱劳驾结给那位鬼。」满屋都笑了。掌柜把原要交她修的两只怀表揣回了兜里。闻秋将空凳往学徒那边推了推。证词有漏洞她听得出来，可那晚进库的缘由，还得他自己决定说不说。

