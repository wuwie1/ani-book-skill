# 迈特凯

岸本齐史漫画《火影忍者》的人物参考。借他写普通人的奋斗，最值得学的是那些人人都看得懂的小约定。凯连输掉猜拳都肯兑现自己说过的话。许多章以后，他说自己要站在众人前面，读者已经知道这人说话算数。

## 回看哪几场

- **别人眼里的小事，他真肯做。** 凯把卡卡西当成长期对手，连猜拳也算较量，输了就倒立绕村。好笑的是两人对这场胜负认真的程度相差太远，可凯认下的那笔账自己会去还。漫画第179—180话写这件小事，第668话则回到他小时候曾落选忍校、跟着父亲迈特戴修行的经历。[《火影忍者》官网迈特凯人物专栏](https://naruto-official.com/en/news/01_1673)
- **认真也能分给别人。** 小李重伤后，手术有风险，放弃又意味着忍者生涯可能就此结束。凯了解这个学生为了留下来练过什么，愿陪他承担选择的后果。小李随后自己接受手术。把「无法使用忍术和幻术」写成角色的长期限制，对应的是小李的经历。凯在这里已经是能带学生的老师了。[《火影忍者》官网李洛克人物专栏](https://naruto-official.com/en/news/01_1652)
- **战场上才见这些日子攒下了什么。** 面对六道之力的斑，第七门仍不足以伤敌，凯明知代价仍开第八门。他想起父亲当年怎样护住自己，如今轮到他给同伴争取机会。他重创斑，后来由鸣人保住性命，战斗还要靠其他人继续。[官网迈特凯专栏，第667、668、672话](https://naruto-official.com/en/news/01_1673) · [官网动画二十周年回顾，决战篇](https://naruto-official.com/en/news/01_1355)

## 怎样把努力写成读者相信的本事

给他一个看得见的起点，也让旁人对他的认真有不同反应。对手觉得猜拳输了就去加练有点过火，经历过失败的学生却能从这份执拗里得到安慰。同一种性格既能带来笑声，也能让另一个人敢再试一次。

连载里可以留下三份证据。先让读者看他在哪一步老是失败，隔一段看他怎样调整练法，再让练过的那一步恰好解了眼前的难。他可以只争来几分钟，或只把一个人送到终点。这份贡献越具体，越用不着临场给他添一种新天赋。

## 塑造前要定的事

- 他差在哪一步，当时拿什么作比较？定一条他自己能掌控的练习约定，再找个人能指出他是不是练偏了。
- 练习在生活里挤掉了什么？给他一次休息、一次练错和一个调整，也给朋友一个能真心笑他的时刻。
- 他最终想替谁把哪一段扛过去？沿用早已练熟的技能，写一个有限的成果，以及用完这份本事后还存在的短板。

## 原创场景示例

县城棋赛的替补解说员一紧张就结巴。每天收摊，他对着灶房报一盘残局，让妹妹隔着门摆。她听错一步，就在他那张棋谱上按一粒饭。头一周，稿纸晾在窗边，天天有麻雀来啄。他才发现，自己一着急就漏说棋子原来在哪儿。从那以后，每一步都先报来处，再报落点。决赛那天画面断了，只剩广播，他照旧讲完了最后七步。门房大爷还开着收音机，隔着玻璃朝他举起小棋盘，最后将军的那匹马一步都没摆错。他乐了，轮到报自己的名字，又卡了一下。
