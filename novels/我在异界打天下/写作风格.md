# 我在异界打天下｜写法合同

2026-11-23。前三章按校园、王府、军需递进。写法服务于东方山海玄幻爽文的行动、人物反应和当场回报。

参考分工：《张三丰异界游》的分析只支持长篇架构；《我在精神病院学斩神》的已登记抽样支持以下通用技法：眼前问题开场、行动驱动信息交付、紧张与日常反差、关系承接情绪、局部兑现后引出新目标。不复制原句、独特比喻、人物组合或标志性场面。来源范围见 创作记录/参考机制使用说明.md。

## 执行优先级

人物与世界硬事实 → 本章必达事件和结束状态 → 读者体验合同 → 本章写法例外 → 本合同。写法不能把普通学生变成老练强者，首章的悬念来自他突然失去明天的生活，出生救治在第2章起首完成。叙事采用第三人称，以陆昊的感知、欲望和选择贴近读者；必要的成人视角须通过明确场景切换进入。

## 正向执行规则

按东方山海玄幻爽文处理强弱反差。低阶驮兽骤然收蹄，先让车夫从蹄下爬出去，读者自然知道这一下有多险。到临川再把回报放大，写龙马肯把命押给这个少年，围势一破，它自己杀回去。遇到身世揭晓，让人物先有本能反应，再给他开口说话的余地。

| ID | 实际写法 | 审校时看什么 |
| --- | --- | --- |
| STYLE-01 | 开篇直接给出眼前麻烦和一个具体尝试。先让读者看懂他想要什么，再补理解行动所需的设定。 | 开头能说清即时目标，角色已在做事；无需先读世界说明书。 |
| STYLE-02 | 一章完成一个主事件。每个节奏段改变行动条件、信息、关系或风险；已有结论随后用于行动。 | 删除该段会不会损失新变化？没有变化就合并，不靠重复体感填字数。 |
| STYLE-03 | 主角至少作出一个影响结果的选择。优势落成可见的小成果，再换取行动空间。 | 结果不能全由成人代办；也不能把成人专业操作冒算成婴儿的战绩。 |
| STYLE-04 | 允许短促、具体、有偏见的心理反应，接着推动下一步选择。 | 保留“想做什么—身体/现实不允许”的反差；删掉反复解释同一情绪的旁白。 |
| STYLE-05 | 幽默来自年龄错位、家人熟悉彼此、嘴上逞强与实际处境。先把危险写实，脱险后再松一口气。 | 一次有效误解或一句接话即可；不设笑话配额，不在濒死动作中插网络段子。 |
| STYLE-06 | 对话有各自目的和声音：陆昊直白好胜；母亲温和但有界限；祖母简短利落；父亲动作可靠、家常略笨；哥哥认真得可爱。 | 遮住姓名仍能区别人物；他们不排队赞美主角或复述作者结论。 |
| STYLE-07 | 选能改变行动的细节：绷紧的手指、撤开的阵片、停止抖动的火苗。句段长短随压力变化。 | 读者能定位动作和因果；不用连续的白光、轰鸣、颤栗和“仿佛”代替过程。 |
| STYLE-08 | 本章兑现一个回报，再把下一章的具体欲望、机会或阻力交出来。前三章不连续只做铺垫。 | 本章净变化可验证，章末让人想看“他下一步怎么做”，而非再等一次尚未落下的手。 |
| STYLE-09 | 温情落在解决需求和承担责任的动作上，给读者自行感受的余地。 | 家人会照料、制止或让出位置；结尾不补“他终于明白亲情”的总结。 |
| STYLE-10 | 专名随使用进入；战斗与器物问题先交代位置、手段、限制和后果。 | 不借快节奏跳过关键因果，不靠术语堆叠表现厉害。 |

## 反模板化规则：只登记修正动作

| ID | 正向修正动作 | 权限 |
| --- | --- | --- |
| AAI-01 | 用一次可见行动及后果支持能力、聪明或温情判断。 | 保留事实的局部表达修订。 |
| AAI-02 | 按人物身份、目的和风险偏好区分对白与反应。 | 保留人物关系，不改知情范围。 |
| AAI-03 | 删去已被动作证明的重复解释；不同章节按自己的责任收尾。 | 不删有效心理活动、回报或钩子。 |
| AAI-04 | 保持阶位、权限、物件来源与揭示窗口；发现冲突返回设定或章纲。 | 不通过表达润色新增修为、前世经历或神明身份。 |

以上表格中的正文都是要执行的动作。风险描述不得导入 languageRules 后被编译成“must keep”。禁止一刀切地取消心理活动；身体反应与短心理均以是否产生新信息为判断依据。

## 本轮开篇验收

第一章先让杨硕为自己的名字争一次，再让他在车祸时本能地拉住齐源。醒来后的婴啼由杨硕听见，镜头留在他身上。第二章起首兑现救治，七岁时完成暖药炉小修、赢得器坊见习。第三章复现军晶缺陷，库内封存，已出库的一箱牵出下章。通常目标2600字，允许2300—3000字；不能为凑数把同一次犹豫拆成三场。

现场细节以真实人物反应检验。高三生会担心妈妈在等自己，十二岁陆昊受哥哥夸奖会想在封存令上也留下自己的指印。让读者看见他在乎什么。
