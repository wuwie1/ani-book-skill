# 我在异界打天下｜写法合同

- 状态：用户确认。2026-11-24 作者先要求大纲不变、故事抓人；读过首章试写后，再要求叙事向《我在精神病院学斩神》靠，同辈冲突参考《遮天》前三十章，不局限于课堂。读过第三版后再定：讲稿之争太小，换掉；主角要有魅力、能力强，参考《遮天》的叶凡；齐源是略嚣张的富二代，追赖紫晴，赖紫晴暗恋主角，故事由此展开。再定：杨硕是十八岁的大一下学期学生，这样表白不突兀。
- 来源：作者偏好；[参考机制](创作记录/参考机制使用说明.md)登记的斩神叙事办法、遮天冲突推进办法和主角立法。取的是怎么讲，不搬原句、桥段和专名。
- 适用范围：全书。单章例外写在该章计划里。

这是番茄男频的东方山海玄幻爽文。读起来轻快、好笑、有人味：先让旁人看走眼，再让他们看明白；该气的地方让读者跟着气，该停的地方一句都不多说。

## 执行优先级

人物与世界硬事实 → 本章必达事件和结束状态 → 四条读者合同 → 叙事办法 → 本章例外 → 其余写法。第三人称，以陆昊的行动线为主，可以切到旁观者、家人和对面的人，每次切换都要多给读者一件事或改掉一个判断。杨硕前世是个出挑的大一学生，有主意、镇得住场、手脚快，这些带得过来；修为、军务、器物和当地的规矩都从头学，不写成无所不知的老手。齐源这一世的视角，卷七揭名前不进入。

## 四条读者合同

每章都要做到，缺一条按失守处理。

| ID | 要交到读者手里的东西 | 审校时看什么 |
| --- | --- | --- |
| HOOK-01 | 开头三百字内给读者一样放不下的东西：一桩摆上桌面的麻烦，或一件说不通的小事。背景随行动补。 | 单看开头三百字，读者有没有一个想问的问题。 |
| HOOK-02 | 每章一次有尺子的兑现。先让读者看见寻常人做到哪一步，再让他越过去，由一个有资格判断的人当场给反应。 | 读者能否说出他比谁强、强在哪。不排队惊叹。 |
| HOOK-03 | 每章有一个带脸的人挡在他和目标之间，这个人有站得住的理由，说的多半是真话。旁人要表态，各有各的缘故。 | 遮住名字，能否说出这个人为什么不让步，谁站了哪边、为什么。 |
| HOOK-04 | 章末停在一件没落地的事上。 | 最后两百字里有没有读者明天想知道的事。 |

## 叙事办法

| ID | 怎么讲 | 审校时看什么 |
| --- | --- | --- |
| NAR-01 | 先从旁人眼里看他。最要紧的一次亮相，由不认识他或小看他的人起头，拿一件说不通的小事吊着，再由一样实物把看法翻过来。名字可以晚到。 | 旁人前后的判断变没变，是看见了东西才变，还是听人夸了才变。 |
| NAR-02 | 换视角要给新东西：一份他不知道的照看，一个正在逼近的麻烦，或对面的人怎么盘算。 | 删掉这一段，读者是否少知道一件事。 |
| NAR-03 | 对白短，各说各的事，带吐槽和自己拆台。主角心里贫，嘴上硬。旁观者和朋友负责好笑，险情里不插笑点。 | 连着三句都在解释，就改成一问一答或删掉。 |
| NAR-04 | 结果在前，原因在后。先让读者看见一个动作或一样东西，过一场再交代来历和谁为它花了什么。 | 来历交代时，前头那一眼的意思有没有变。 |
| NAR-05 | 一样东西跟着人换场子，每换一处意思变一次。 | 这样东西有没有改变谁的下一步。 |
| NAR-06 | 最要紧的那句话、那个画面出来就停。 | 最后一个具体画面之后还剩多少字。 |

## 正向写法

| ID | 实际写法 | 审校时看什么 |
| --- | --- | --- |
| STYLE-01 | 先行动，后设定。专名随使用进入；验货、交割这类流程单场不超过六百字，只留因果。 | 读者无需先读世界说明书。 |
| STYLE-02 | 一章一个主事件，每段改变行动条件、信息、关系或风险。 | 删掉该段会不会损失变化。 |
| STYLE-03 | 主角有分量，也有脾气。他遇事先看全场再开口，几句话让各人有事可做；被小看不急着解释，不抢不属于自己的东西，不让对手当众下不来台。他也好胜、嘴硬、会记仇，对身边人的心思迟钝，困在孩子的身体里尤其憋屈。这口气要变成下一步的办法。 | 他出面以后局面变没变，是做了事才变，还是旁人夸了才变。被冤枉、被小看时，读者知道他气什么、想赢什么。 |
| STYLE-04 | 金手指看得见、掂得出。书里的人可以把它看小，读者不能看不见。 | 神识每次起作用都落在一个可见的结果上。 |
| STYLE-05 | 最险、最重的一段给足篇幅：车祸、失手、对峙、回不去的家。 | 高潮段不比铺垫短。 |
| STYLE-06 | 各人说话不一样：陆昊直白好胜，母亲温和有界限，祖母利落，父亲家常略笨，哥哥认真得可爱，对手客气、爱把决定说成惯例。 | 遮住姓名仍能区别人物。 |
| STYLE-07 | 温情落在照料和承担的动作上，花了什么要看得见。 | 结尾不补“他终于明白”式总结。 |

## 反模板化：只登记修正动作

| ID | 正向修正动作 | 权限 |
| --- | --- | --- |
| AAI-01 | 用一次可见行动及后果支持能力、聪明或温情判断。 | 保留事实的局部表达修订。 |
| AAI-02 | 删去已被动作证明的重复解释；各章按自己的责任收尾。 | 不删有效心理活动、回报或钩子。 |
| AAI-03 | 保持阶位、权限、物件来源与揭示窗口；发现冲突返回设定或章纲。 | 不通过润色新增修为、前世经历或神明身份。 |

以上都是要执行的动作。导入其他系统时不得把风险描述编译成“must keep”。

## 开篇三章验收

第一章从校门口送花的人起笔，旁人先看见一个三句话让堵死的校门通开、一句话让富二代挪车的学生，再看见被表白的女生信封上折着他才有的那个角。齐源当众说他早就知道，两人争到公交车上，她说明天亲手把信给他，然后车被撞。第二章先把回不去写足，再让七岁的他接住一盏泼出去的水。第三章他当着军府的人说一批验过的货不能发，章末有一箱已经走了。通常2600字，允许2300—3000字；第一章例外，约3700字。

齐源也穿越一事是全书伏笔，卷七才揭开。此前不给读者任何提前的镜头或暗示。
