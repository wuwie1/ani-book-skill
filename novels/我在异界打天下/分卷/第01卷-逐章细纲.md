# 第一卷《王府有个陆小爷》｜阶段大纲与逐章目标

陆昊想让父亲交给他一处能自己做主、也由他负责善后的地方。十二岁查军晶时，他最得意的是比别人先看见毛病。到十四岁去临川，他最拿得出手的成绩，是自己离开以后，那座渡场照样有人开船、领工钱、修坏掉的东西。

## 阶段大纲

| 阶段 | 章次 | 陆昊要解决的事 | 这一段结束时 |
| --- | --- | --- | --- |
| 一、王府里能做的一件事 | 01—03 | 从高三班里的署名争执到车祸后成为婴儿，七岁争一个工位，十二岁让人相信一块军晶有问题。 | 同批军晶停用封存，他获准随行追查，已经发走的那份却还在别人手里。 |
| 二、找到用灯的人 | 04—10 | 顺着货单亲自找到领料人，先让石梁哨停用可疑晶料，再补担架过弯急用的灯，追查坏料从哪一手混进来。 | 夜巡平安交班，一本称量副记把查案的人带向回澜渡。 |
| 三、好样是给谁看的 | 11—19 | 拆穿用好样掩盖坏货的把戏。在渡口出了事以后，陆昊还得在追人和救人之间选一次。 | 受伤船工活着回来。独立匠人验出旧晶翻新，案子从供货疏失转为有人蓄意换货。 |
| 四、把关防的灯换回来 | 20—29 | 钱、人手和好晶都有限，兄弟要边查案边恢复巡路。 | 军士恢复轮换，匠人学会自行验货。杜魁一伙也看见了他们公开的验法。 |
| 五、看错一次之后 | 30—39 | 误判使陆昊右臂受伤。他得交代损失，找出自己为何看错，再把办法交给别人试。 | 匠人独立识破假象。韩敬山因外账和物证被捕，陆昊凭实测拿回受限的现场岗位。 |
| 六、让这一船人货都回来 | 40—48 | 在回澜渡护住撤离通道和正常军需，同时截住杜魁。 | 军需交到哨兵手上，军晶案结清。陆昊伤后恢复，第一次可以回家吃一顿不用汇报公务的饭。 |
| 七、给他一处渡场 | 49—60 | 用两年间的试做证明，自己也能管好一处有人天天指望它开门的地方。 | 小渡场能自行运转，十四岁的陆昊取得一年临川试治令。 |

## 逐章大纲

下表写的是每章计划抵达的位置。前三章沿用[开篇执行计划](第01卷-开篇细纲.md)，第4章从第3章运单上那份已出库的货接起。

### 一、王府里能做的一件事（01—03）

| 章 | 陆昊的目标 | 章末做成了什么 |
| --- | --- | --- |
| 01 明天我自己讲 | 高三生杨硕要齐源当面澄清讲义署名，两人同车去取原稿。 | 公交出事时他拉住齐源，对方攥紧了他的袖口。再想叫母亲，发出的却是婴啼。章尾只随杨硕醒在淮北王府。 |
| 02 小爷只修一处 | 王府新生儿自己接上一小口气，祖母与母亲完成救治。转至七岁，陆昊想稳住暖药炉，换一个能常进器坊的位置。 | 他收回“晶料坏了”的判断，请陶守诚等炉子热起来再验。陶修好受热卡滞的连接片，药工终于能离开炉边，陆昊获准每旬来器坊见习一次。 |
| 03 合格的坏料 | 十二岁第一次参加正式军需核验，要试清短测合格的晶料能不能撑过夜巡。 | 短测无异。同一灯座先用好晶，再换待验晶，久用回火时陶守诚断供。复换先前的好晶，灯焰一直稳定。陆景珩封样、暂扣整批待验，把停用令交给随行护卫。运单上已经发走一箱。 |

### 二、找到用灯的人（04—10）

| 章 | 陆昊的目标 | 章末做成了什么 |
| --- | --- | --- |
| 04 这箱灯归谁 | 当天赶到南渡仓，在值夜前找到已领晶料的人。 | 十三岁的程见秋认出空篓旁是石梁哨的药筐。领船石长庚查过交接时刻，脚夫才证实货已转哨。随队驿骑拿世子预签的停用令先行，当日入夜前赶到。陆昊跟护卫走一日陆路。 |
| 05 灯灭以后 | 次日抵达石梁哨，看清停用令让巡兵怎样过了第一夜。 | 暗弯处还摆着替岗军士坐过的矮凳。一名兵刚换下，人还哑着嗓子。陆昊随换班的人抬空担架走一次，转过弯去，才发现前后两个人谁也腾不出手提灯。 |
| 06 留一盏给担架 | 在第二夜值班前，让真担架也过得了暗弯。 | 陆昊舍掉照亮全路的打算，把能找到的好晶留给弯道，和军士挪开一盏晃眼的油灯。哨官亲自换班，给执灯的位置补上人。真担架平稳过去，昨夜喊哑的巡兵终于能回屋睡觉。 |
| 07 灯座底下的字 | 找出哪几座灯装过那份坏料，免得剩余几段夜路也得全靠人守。 | 旧底座上的刻号和领用人记下的换灯顺序对上。陶守诚逐件复核，圈出同箱数块坏晶，另一批经检恢复使用。陆昊带回空箱追它从哪来。 |
| 08 两张都是真的单 | 弄清明明有合格凭单，坏料为什么还能进哨。 | 韩敬山交出合格抽样单，守哨人交出实领单，两张都真，中间换箱的一程却没人签见。陆峥暂停韩新增采购和付款，交由别人保障眼前供货。 |
| 09 周有年补的那一笔 | 查明是谁补了时刻，那人又究竟见过什么。 | 记簿吏周有年承认补签。陆昊随查案人走一遍门房和卸货坡，轮值证明换箱时周在另一处。周说出了自己手里另有称量副记。 |
| 10 少了半车的分量 | 让周能安全开口，把那份副记与货实对上。 | 王府另行安置周及家人。副记同空箱皮重一核，号称原车退回的货足足轻了半车。石长庚认出二次过手的泊位，船定下次日去回澜渡。 |

### 三、好样是给谁看的（11—19）

| 章 | 陆昊的目标 | 章末做成了什么 |
| --- | --- | --- |
| 11 少装一箱 | 既把查货工具运到，又让船上每个人都有回路。 | 他想多带一箱器具，程见秋请他站到备用船的位置看看还能坐几个人。他亲手卸下工具箱，石长庚才同意带人开船。 |
| 12 押货人的好样 | 面对杜魁递来的好晶，找回真正有争议的那批货。 | 程见秋拿出两次吃水记录，只能看出整船变轻。石长庚对上上一泊的装卸簿，搬工指认曾按吩咐挪走的舱位，才圈定争议箱。祁烈留下这几箱，正常货获准离岸。 |
| 13 无船靠过的岸 | 验一验杜魁所说的原路退货。 | 领船人证实那天没靠过此处。陆昊沿车辙找到干棚，一头受惊的低阶驮兽朝车夫扬蹄。他急着把它逼开，灵压竟让兽蹄僵在半途。车夫趁机抽身，等他收力才牵住仍在挣动的兽，说出在旧灰窑换脚力的经过。 |
| 14 给船工留条路 | 核验期间让普通货主领走自己的货，也让争议箱有处独放。 | 他按记号认出一批农具，货主赶上归船。卸空的棚位腾给争议箱，刚归位时吊货处突发骚乱，坡下还有搬工。 |
| 15 滚下来的货箱 | 在自己的护运位置护住坡下的人。 | 他用练过的短时定风争来一瞬，把滚箱带向空垛，搬工避开。趁乱夺工具的人被护卫制服，杜魁借混乱逃走，一名船工伤在外侧船上。 |
| 16 先接那个人 | 放下追杜魁的念头，把受伤船工带回来。 | 第11章留下的备用船用上了。石长庚掌船，程见秋指出能靠近的浅流，陆昊帮稳住救索，伤者活着上岸。 |
| 17 船回来再数人 | 送伤者进医署，把争议货、样品和同行人一并交清。 | 伤者想起舱中一块总垫不平的底板，指给护卫看。里面藏有回用晶残块，另行封样。陆昊核完名册，最后一个船工也有了下落。 |
| 18 有裂的和没裂的 | 让另一个从没见过原货的人也能辨出坏晶。 | 陶守诚与独立匠人拆验，发现填缝回烘的旧晶混在新货里，抽检好样也确实出自原批。查案人据此正式追捕杜魁，并搜查中转私栈。 |
| 19 留白的那个人 | 把已经证实的换料与仍须查清的授意分开，如实交代周的过失。 | 周把劝他统一口径的传话交给护卫，亲手圈出补签处。私栈搜出结算副本，韩敬山被停职收印、受控核账。石梁哨来信催问替换灯何时能到。 |

### 四、把关防的灯换回来（20—29）

| 章 | 陆昊的目标 | 章末做成了什么 |
| --- | --- | --- |
| 20 巡一趟夜 | 算出应急照明究竟还能撑几天。 | 他再走石梁哨，跟到交班才发现白天报上来的时数漏算夜巡，几名军士连续顶班。陆昊向父亲改报自己的估算，接下限额内分批换灯的任务。 |
| 21 这一批先给谁 | 决定不够用的第一批好晶发给谁，也当面说清谁得再等。 | 他和哥哥按伤员通道、险弯与轮防时刻重排，先到货的两处有人接手，晚换的哨也取得备用油和明确日期。 |
| 22 一炉做不完 | 让器坊按答应的日期交出第一批灯。 | 卡住的是拆洗和校准。他随学徒量完一排旧灯座，撤掉非必需功能。陶守诚按新工序做出能逐件复核的第一批替换灯。 |
| 23 这辆车听谁的 | 想留下成品继续试验，又得让押运人有清楚的命令可听。 | 陆景珩问清安全检查已毕，照令发车。陆昊亲自向押运人撤回加测要求，从下一批领到试样。兄弟约定停运须说明具体风险。 |
| 24 雨里换灯 | 在阵雨里换好险弯的灯，赶上下一班巡路。 | 哥哥带巡兵绕行，陆昊以短时定风帮匠人稳好支架，又沿水流调整护壳。雨下到交班，新灯仍亮。 |
| 25 空出一张床 | 亲自等完一轮夜值，确认这批灯真能让人歇下来。 | 增派的巡兵按时下值，医署通道恢复。父亲批准下一批和一笔试验奖励，陆昊先把器坊替自己垫的耗材补上。 |
| 26 你来验一箱 | 把验收教给沿线匠人，试试自己离席后还验不验得出问题。 | 一名老师傅指出潮湿会让标板误报，两人一起修正，当场放行一批合格货。码头旁听的人也记住了外侧读数的位置。 |
| 27 谁的工钱还欠着 | 让受伤船工领到应得的钱，照护也能接上。 | 周有年核出已做工时，正式结算人先支付无争议部分，医署接手后续诊治。船工告诉陆昊，他们先前还替一户下游买家搬过同款好晶。 |
| 28 河边的一碗热面 | 向程见秋问清那户买家的航程，也听听她自己想去哪里。 | 她给出可核的行船月份，又说想独立领一段航路。陆昊第一次把“我想管一处地方”说给她听，两人约好今后出船先谈归期。查案人循月份去找买家。 |
| 29 最后一船分开走 | 把末批好晶交给匠人验发，让扣押旧料单独回仓。 | 两路货各有交接人，陆昊只占后侧验读位。换班时混进来一名杜魁的同伙，手里拿着第26章演示过的那种标板。 |

### 五、看错一次之后（30—39）

| 章 | 陆昊的目标 | 章末做成了什么 |
| --- | --- | --- |
| 30 太齐的一排数 | 查明货架在晃，标板读数为什么纹丝不动。 | 他叫停交接。有人怕夹层露馅，仓边护板被撞坏，工人撤离。陆昊退到验读侧，见泄流口的指示片已经翻白，判断可以关断。 |
| 31 那不是出口 | 趁余流伤人前关掉器具。 | 他信了指示片，主线上却还有余流，右前臂被回火灼伤。他松手示警，陶守诚隔断供能，祁烈救出工人。检台烧损，同伙趁乱拖走一箱旧料。 |
| 32 把右手放下 | 在停术后帮工人撤离，把仍有危险的箱子指出来。 | 他凭先前记下的位置指对箱子，伤者登上备用船。但他只向祁烈报了擦伤，晚饭时连筷子也捏不稳。 |
| 33 那句没说的话 | 向母亲争取再回码头，先得解释为什么漏报麻痛。 | 沈令仪查出气脉灼损。他承认既怕丢任务，也怕承认自己看错，交回外出牌，接受停术和分段复查。哥哥另派人照常送货。 |
| 34 赔掉的那一角 | 弄清哪部分损失出自自己的误判，给受牵连的人一个交代。 | 他和陶守诚逐件看残台，从个人奖励里限额补一部分耗材。余款由王府垫付追偿。事故记录第一次把他当时“看到的”和“猜的”分开。 |
| 35 祖母缺的一角图 | 弄明白当时究竟是哪一眼骗了自己。 | 许文瑛摊开缺页的旧测图，让他在空处落笔。他承认隔着护板看不到真实接线。祖父陪他练在看不清时先站稳。外祖母苏云岫从圣庭捎来的信问他吃饭能否用勺，他头一回用左手给她回了歪歪扭扭的一行字。 |
| 36 两次读到同一个错 | 找到能把表层假象从真实承载里分出来的办法。 | 陶守诚拆开残件，标板与泄流口的指示片竟都接在同一条旁路上。两样都报平安时，主线照样能烧红。另一名匠人改查实物接线与独立温升，复现了当初漏掉的危险。 |
| 37 让师傅自己挑 | 在自己不报答案时验证新验法。 | 混样盲测中，匠人独立挑出假件，一块无法定性的被留置。陆昊如实报告手臂仍不能负重，只获准短时低负荷操作。 |
| 38 外账上的一分钱 | 看看已有物证能不能坐实韩的获利，并说明自己到底能证明哪一段。 | 外查人取得买家结算原据，与周的副记、私栈副本和封样对上。韩敬山被正式拘押。旧灰窑已经查封，仍失落的旧料指向回澜渡。 |
| 39 我能守哪一个位置 | 请求回现场，也让大家看清自己做不到什么。 | 他在实演中按约退到后侧护栏，把须由成人接手的情形逐一交清。哥哥批准他只守低负荷复验位，众人试放过一道空货架，让它落在无人的空地。程家船队确认了撤离泊位。 |

### 六、让这一船人货都回来（40—48）

| 章 | 陆昊的目标 | 章末做成了什么 |
| --- | --- | --- |
| 40 回澜渡开船 | 把正常军需接入安全水道，同时给追捕人员让出作业面。 | 陆景珩统筹两路，石长庚移好备用船。祁烈交给陆昊一张普通护身符，约定符一破就退。陆昊接收第一批受控旧料，普通船先行。杜魁混入正常船队的打算落空。 |
| 41 烟里认出一只箱 | 人群撤离时，拦下眼看要混入好货的那箱旧料。 | 他认出旧记号，喊出箱位，搬工按已学的流程独立分货。失箱找回，程见秋点清离场工人，救援船赶在两路拥挤前离岸。 |
| 42 最亮的地方 | 找到真正要坏的那处器具，好让匠人近前。 | 他核对实物和温升，辨出两处假亮点。陶守诚处置真故障时，陆昊发觉后侧货架在吃重，有人正绕向撤离通道。 |
| 43 守住几息 | 为尚未过栏的最后几人争取时间。 | 面对四阶武修杜魁，他依约退到护栏，用未伤的手放下预先试过的空架，迫使对方改道。护身符碎了，工人过了栏，祁烈赶到制住杜魁。 |
| 44 这一趟送到了 | 把收尾做到最后一项，包括把自己的状态也报清楚。 | 他报告右臂疲劳、交还工具，杜魁由专人押解。坏料、证物分别交收，石长庚取得正常军需的接收回执，所有船员点名到齐。 |
| 45 把名字还给人 | 讲清自己亲见的环节，让无关货主也能取回被扣的货。 | 匠人证缺陷、船工证流向、买家证结算，陆昊当众认下误判。韩授意获利、杜转运并袭扰的经过可以独立复核，误扣货物开始发还。 |
| 46 该由谁领这份功 | 在正式处置时，把周的过失、船队的贡献和自己的功过各归其人。 | 韩被革职、追缴所得并长期监押，杜被判终身监押。周因补签受处分、获准补训。军府给陆昊记功，采用在用负荷复核办法，韩案结清。 |
| 47 把钥匙交出去 | 确认新验法有常设人员接手，伤工的钱也有着落。 | 一趟正常军需在他旁观时独立验发，船队收到尾款。周将另案一张缺页的神宫征调回执递给主管，单独求补。陆昊腾出了自己的工位。 |
| 48 回家吃饭 | 伤后第一次安心回家，把一顿饭吃完。 | 数周复查确认右臂能恢复正常训练。父亲没让他在饭桌上报数，哥哥却为他留着一封普通渡场来信。父亲问他，若没有军府急令，这件小事还愿不愿意管。 |

### 七、给他一处渡场（49—60）

| 章 | 陆昊的目标 | 章末做成了什么 |
| --- | --- | --- |
| 49 先坐一趟末班船 | 十二岁岁末，去信上那座小渡场看看，人们最急着修什么。 | 他带去修货架的想法，搭末班船才发现涨水便撤的踏板让卖菜人总错过归渡。陆昊把第一项试做定为让人连筐平稳上船。 |
| 50 一天也关不起 | 找到农忙照常摆渡的修法。 | 他跟渡夫记了一天人流，把大修拆成分段施工，亲自陪第一批人走临时通道。父亲批下限额和成年监办，钱只够先修一侧。 |
| 51 往下再低一寸 | 十三岁开春，让满筐上船的人也用得上新踏板。 | 空筐试走顺，满筐却卡住转身处。卖菜人当场演给他看，他请匠人改低接口。第二天同一批人自己推筐上船，赶上早市。 |
| 52 谁接最后一班 | 解决新通道开了，晚归的人仍常被留在对岸的问题。 | 他跟程见秋核了归船时刻，听出渡夫加开一班就赶不上自家晚饭。两班人重新轮替，一船晚集客按约回来，渡夫也按轮次歇班。 |
| 53 不能总借王府的船 | 让通道坏了也有人渡河，而渡场付得起这笔钱。 | 石长庚把备用运力的实价摊给他看。陆昊折起约书的纸角，转过去请他指给自己看候船钱算在哪一行。他削减扩货位的预算，经属官与民船订下限次接驳约，船家拿到头笔候船钱。 |
| 54 雨水替他验一次 | 在雨季第一次涨水时保住人和新修的踏板。 | 神术帮他稳住一阵侧风，武修训练使他能站稳交接位置。水仍漫过一道接口，他与渡夫叫停原泊位，约好的民船第一次把滞留乘客接回。 |
| 55 给下一场雨留钱 | 修好泡坏的木件，找到不用每次求父亲拨款的办法。 | 陆昊同属官从当季渡场进项划出维护费，买到通用替换件，匠人教会本地渡夫换装。第二次小涨水后，渡夫自己换好了第一块。 |
| 56 这一季谁来结账 | 支清人工、验收修缮，也兑现给自己的训练承诺。 | 他用实际收支取消了暂养不起的第二个货位，渡夫和匠人都领足工钱。一季维护结清。经过这一年的温养、演武与恢复，他通过三阶武修承载考核。 |
| 57 他离开三天 | 检验渡场离开王府小公子还能否运转。 | 他依约回城三天。逆风让末班船误点，值守渡夫自行启用候船约并告知乘客。陆昊回来时，只剩已经结清的收据等他看。 |
| 58 临川带来的旧账 | 十四岁复核前，弄清父亲提到的临川和这处小渡场有什么区别。 | 属官带来有王朝印记的旧封册。王府可在辖地任试治，正式分领须按原封条款报核。陆昊翻到后面，才看见欠薪、待修渡口和仍在此生活的人家。陆昊先列必须兑现的工钱和航次，主动撤去头季开新矿的设想。 |
| 59 哥哥问他要什么 | 当着父兄说清自己要哪些权、愿意受什么约束。 | 他交清小渡场钥匙，通过三阶神师、三阶武修复核。在备行的低阶驮兽中，陆昊能用灵压让领头那头止步，旁边一头照常嚼草。陆景珩认可他另做事业，陆昊同意大额财务和司法由成年属官会同办理。 |
| 60 临川试治令 | 拿到能真正办事的任命，把赴任的第一件事定下来。 | 陆峥给出一年试治令、限额经费和复核条件。程家按约承运，陆昊带人启程，约好到临川先见等工钱的渡工。正式封地待第二卷以治理实绩取得。 |
