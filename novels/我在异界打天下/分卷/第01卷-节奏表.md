# 第一卷《王府有个陆小爷》｜节奏板

| 章次 | 读者追着的问题 | 本段必须落在场景里的结果 |
| --- | --- | --- |
| 01—03 | 被说成早就知道的杨硕，等得到她亲手把信给他的那个明天吗？到了新家，他第一次能替谁做点什么？ | 他舍信拉住齐源，醒来听见婴啼。七岁凝水救信，十二岁稳火验晶。北关的家书、西北的失货与一箱已发走的军灯料，都有具体的人在等。 |
| 04—10 | 已经拿走坏料的人，今夜靠什么过活？ | 头一夜驿骑送到停用令，巡兵喊哑了嗓子。次日陆昊抬空担架过暗弯，才知道灯该留在哪儿。用灯人的困境之后才轮到追问谁交的货。 |
| 11—19 | 样品明明合格，货为什么会坏？ | 查换货路线时惊兽扬蹄，陆昊第一次用灵压救下车夫。杜魁拿出好样，船队拿出载重，夹层留下旧料。备用船把伤者带回来。 |
| 20—29 | 知道哪里错了，是否就有本事修好一条巡路？ | 父兄、军士和工匠帮陆昊推翻初估。一名巡兵按时换下值，比账面上的交付更早说明换灯有用。 |
| 30—39 | 这一次偏偏是陆昊看错了，谁还敢让他上场？ | 误判带来伤情与烧损；如实报伤、补损、由别人独立盲验之后，他才能申请受限岗位。 |
| 40—48 | 现场又出现假象，还能让人和货都回来吗？ | 陆昊守栏、伙伴完成处置和运送。结案后工钱、医护和正常供给各有接手人，给家人留一顿安静的饭。 |
| 49—60 | 查过一件大案，是否就管得好别人的日子？ | 陆昊折起约书一角递给船家，让船家亲手指出候船钱。末班渡工有人接替，陆昊离开也有人换件结账。父亲据此交付临川。此时陆昊已能把灵压用在选定的一头驮兽身上。 |

连续章次、目标与章末结果见[逐章大纲](第01卷-逐章细纲.md)。开篇三章的场景预算见[开篇计划](第01卷-开篇细纲.md)。
