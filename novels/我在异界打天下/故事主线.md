# 我在异界打天下｜故事主线

2026-11-24 修订。长期故事权威；本文件中的事件均为计划，不是已发生正文事实。世界硬规则以 [世界设定.md](世界设定.md) 为准。

## 起点与四次目标变化

十八岁的大一学生杨硕在校门外被同班的齐源当众指着说，你早就知道她喜欢你。齐源家里有钱，从军训起追同班的赖紫晴，她心里放着的却是杨硕。两人为她掉的一封信争执，争执把他们带到同一班公交上。车厢遭碰撞时，杨硕伸手拉住他，清醒时却只听见自己的婴啼。王府给这个孩子取名陆昊。陆昊抵达武元界的原因与护魂残印有关，卷八至十由界潮观测、旧物和记录互证。

他出生于大周淮北王府。刚醒时他想给母亲回消息，却连手都抬不起来，只能在陌生人的怀里听雨。后来他学会叫沈令仪“娘”，五岁随她学凝水。七岁那天，半盏泼水在他手边悬了几息，马夫的女儿从水底抽出写给父亲的家书。陶守诚把旁听牌换成灯房的见习牌，给了他每旬一次动手的机会。

十二岁他随兄长穿过靖原城，一匹马要送往正北与玄朔相邻的关口，一队商车等着王府护送过西北雁回岭。车夫数金币，术师验元晶。他在众人面前稳住灯焰，又亲自收术，让工匠用固定试台验出一块久用会回火的军晶。军需案由此开始。首卷他挣得临川试治资格，第二卷才获得正式封地。

四次欲望转移：

1. **我能自己做成事。** 从家族庇护中争得有限行动空间。
2. **已经做成的事不能任人收走。** 封地成果与伙伴利益遭压制，陆昊学习组织、外交和战争。
3. **我要建立能保护这些成果的国家。** 旧王朝要求撤防、交出独立军政权并执行强制征召，现有妥协条件无法同时保住边地与伙伴。
4. **任何上层权力也不能随意收回这一切。** 建国后仍受制于界路与神朝敕令，陆昊主动建立通天渡与诸界联盟。

## 对立如何逐级成立

第一阶段的敌手韩敬山，为填补自己经手军需的亏空，以旧料替换切制好的军用元晶并转嫁责任。他没有奉终局敌人的命令。陆昊以调查、验证和一次有准备的战斗破局，后果是获得资源，同时暴露自己能够改变地方利益。

大周南境还有一条从赈粮起家的地方势力线。丰济社主孟循让欠粮的村镇渡过饥年，也想把下一季的仓权握在手里。建立大昭时，陆昊必须让这些县镇的粮路接得下去。粮票还捏在饥户手里，攻下仓门之后依然有人等着兑现。

第二阶段是多个真实利益集团：旧商路经营者不愿失去定价权，炉城不愿承担未验证的生产风险，灵狐圣庭关心祖地，北荒部族关心通道。陆昊必须在具体问题上争取合作。成功的盟约应有已完成的交换、可见的义务和发生争议时的处理方式。

第三阶段是王朝与教权。皇帝萧承钧有守住中央权威的理由，并非看见天才就无条件迫害。天命神宫也提供治疗、防护与灾时支援。矛盾逐步集中到独立军队、地方收入、强制受箓及征召上；陆昊先尝试交涉和交换，再因代价不可接受而选择反抗。

第四阶段是诸界通行权。玄穹天庭由不同神国与职司组成，司契帝君晏执衡长期掌握一部分界路敕令。他在真实界潮加剧时提出“归契令”，以稳定航路为理由要求各界交出更大控制权。现有盟约有实际作用，新的集中征收也会造成实际受害。陆昊必须拿出能运行的替代方案，才能争取摇摆者。

晏执衡不是自然灾害的制造者，也不是每个地方敌人的幕后主人。他会争取人才、观察新工艺、提供有条件的帮助；当陆昊的替代网络足以威胁其统治方式时，冲突才成为全面战争。

## 三条长期故事线

### 事业与战争

一处试治产业 → 临川封地 → 跨族生产与商路 → 北境军团 → 海路与地底界关 → 大昭建国 → 通天渡 → 诸界共同防线。

临川第一次巡领，陆昊察觉远处异常兽威，潜近才看见九头蛇和赤尾蝎正在围杀龙马，想夺它的血脉。他拿自己能争来的一次破围机会换龙马应契。灵压让两兽齐齐一顿，龙马抓住空隙击杀两敌，活着回来履约。此后渡口遇险、山路失联，陆昊身边都有一个能独当一面的伙伴。

第五卷的失踪工役名册把众人引到地底旧井。井镇的转运收据和神宫签收联能证实谁把人带往上界。潮生界守渡会管的是另一段旧渡。倒灌时双方用旧铃互报水头，各自在本侧救人，才有往后互报潮讯的约定。第八卷试通天渡，这一渡的对岸才有人肯接第一批来客。

地底篇有自己的权力变化。阴月最先归入陆昊麾下，第一次听令承担救援。墨鼠须为庞大族群保住水渠与工坊，土龙寥寥几位强者各能镇守一段地脉。后两方各自决定合作条件，小势力的选择逐卷展开。

每份新资产要经历取得、验证、交付与维护。上一阶段的人和资源会继续发挥作用；大陆不会在陆昊进入上界后停止存在。

### 家庭与关系

父亲从允许试做，到不愿儿子越过君臣边界，再到亲自判断撤防命令会造成什么。兄长的世子继承权始终明确；他面对的是既定人生与新局势的冲突，不因弟弟有成绩便自动退位或突然黑化。祖父的战场见识和祖母的界术认识各有边界。

程见秋先要保住船队和船员。她与陆昊可以在运力、风险和撤退问题上争执；感情来自共同承担，成年后逐步形成明确选择。她建立自己的界航事业，不因成为伴侣便停止拥有目标。其他重要女性分别承担族群、旧史、信仰与邻国责任。

### 修行与揭示

陆昊随胎穿而来的魂力足以生出神识。首卷一头惊起的驮兽在车夫面前收蹄，车夫就地滚开，等陆昊收力才回来牵缰。临川一战，他要用同一份本事对付远比自己强的对手。真正能杀死九头蛇与赤尾蝎的是龙马，他必须先说服它把突围的时机交给自己。《源天》的内炼、联纹与后来的合流法域另有修炼过程。

揭示依次回答：道书为何有用 → 为什么有些术式能相互联结 → 儿时记下的残纹为何也刻在旧物上 → 古人曾怎样通行诸界 → 神朝掌握了哪些真实权力 → 哪些权力可以被替代。

#### 杨硕这个名字

首章，杨硕递纸时把右下角折起来，那是高中同桌一年替齐源咬短的指甲养出的习惯。赖紫晴写给他的信也折着这样一个角，齐源认了出来。上车后齐源要拆那封信。车一震，杨硕伸手去抓齐源，任由信飞走，信里写了什么他再也没看到。那天母亲给他留的饭，他也没能赶回去吃。

很多年后，陆昊把一张领粮名单转向桌子对面，同样折起了一个角。先让读者看清上面的人等着吃饭，等旧名响起，再让人认出这只手。场景的知情顺序与后果见[卷七安排](分卷/分卷规划.md)。

## 权力结果与结局

- 第七卷，陆昊先以临川粮储担下南境旧粮票，各县才肯把仓路接入联军。萧承钧退位后，陆峥与世子交还旧朝兵符，原有守军按新任命轮值。联军及归附州县共推已担起粮债和防务的陆昊，建立**大昭王朝**，陆昊即帝位。称帝不等于所有人族国家和异族势力都已归附。
- 淮北王爵的原定继承人仍是陆景珩。帝位来自新政权的建立，不通过夺兄长爵位取得；旧爵位在新朝的地位经公开安排处理。
- 邻国、圣庭、炉城和北荒部族可以保持自己的内部治理。对共同战争、交通、供给和界路的承诺由盟约约束。
- 陆昊在神域境后继续提升法域的精度、承载、持续性和多锚协同能力。帝君是职号，不能被用作随时追加的新境界。
- 终战先完成军团、交通与阵基层面的任务，再为陆昊与晏执衡的决战创造条件。切断神籍文书不能让敌人自动失去全部修为。
- 陆昊以多年练成的神域修为承住联阵，各界盟友分别守住供能与退路，他才有机会与晏执衡正面决胜。
- 他保有个人实力和大昭帝位，成为诸界共同防御与通行盟约的主要建立者。对盟友的影响力来自实力与履约，不等于可以任意支配所有族群。
- 世界损失有余波。已失去的普通生命不因终局胜利批量复活；家园、生产与关系以明确可见的恢复结果收束。
- 最后约十至十五章完成战后安排、人物选择与共同生活。陆昊明确把此世当作需要负责的家；前世记忆得到情感安置，不突然追加自由双穿。

## 后续规划必须保留

婴儿期简短；少年期有真实战斗回报；关系对象保有行动权；前期成果在后期继续有效；神域以内的差异有具体依据；大昭称帝与诸界联盟是不同权力结果；每卷兑现自己的责任，远期细节按新证据深化。
