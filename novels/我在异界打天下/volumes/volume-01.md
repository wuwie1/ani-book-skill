# 第一卷骨架｜王府有个陆小爷

状态：本次授权内定稿；章节正文尚未开始。范围1—60章，目标约15.6万字。依据 [全书战略](volume-strategy.md)、[故事主线](../story-bible.md)、[世界规则](../world-bible.md)、[人物索引](../characters/character-roster.md)。

## 本卷合同

- 主角主动欲望：得到一次可以负责到底的试治机会，而不是只被称赞聪明。
- 读者回报：有保护边界的婴儿自救、童年可验证的优势、少年亲自行动与战斗、家人和伙伴的真实认可、带责任的独立空间。
- 压力来源：新生儿承载有限；试验失败会耗掉信用；军需问题威胁真实使用者；韩敬山会销毁证据和破坏替代方案。
- 不可逆所得：可复核的能力声誉，程见秋等人的初步信任，正式试治文书及明确的临川接收任务。
- 不可逆代价：试验损耗和伤情留下恢复时间，陆昊必须修补一次隐瞒造成的失信；受损军需不得因抓到犯人立即恢复。
- 卷末牵引：临川有可经营的渡口与荒矿，也有必须接手的旧债、欠薪和维护责任。

## 时间、权限和战力

1—3章出生当天；4—10章通过年龄锚点跨过童年；11—57章为十二岁同一轮军需事件及数周后续，不拖成两年查案；58章结案与恢复；59—60章选取之后两年中有结果的试做与复核，进入十四岁。

首卷成年角色负责鉴证、执法、兵力调度与监护。陆昊负责提出可验证猜想、完成自己的检测和有限战斗任务；他能发现此前验收标准没覆盖的条件，不意味着所有军官和匠人不识真假材料。

十二岁时三阶神师、二阶武修。韩敬山四阶武修，具有真实正面优势。陆昊需要地形、已检查器具、时机与伙伴支援，不能因为“看见弱点”就自动越过身体差距。祁烈负责防护和封控，陆景珩承担正式兵力协同；主角的关键行动要能够改变结果，又不吞掉成人职责。

逐章深化后，现场主要武力对手为四阶武修杜魁，韩敬山负责授意与获利。第016章起限制韩的采购付款，第027章停职受控核账，第049章正式拘押；杜执行此前布置并为自保继续破坏，不依靠已被限制的韩无限遥控。两人第057章完成处置。陆昊第042章右前臂受伤，后续分阶段恢复，第058章确认无永久伤残；养伤时正常供给和成人调查继续推进。

十三岁阶段以真实训练和承载考核进入三阶武修，十四岁复核时为三阶神师、三阶武修；四阶神师突破留给第二卷。首卷任务地点限于靖原城、南渡仓、回澜渡、石梁哨及短途相关货线，其相对路程见逐章细纲。

## 关键因果链

护魂残印与一次护生阵不兼容 → 陆昊在身体极限内自保，意识到异界规则可被学习 → 少量童年试验建立能力与限度 → 见习时发现灵晶常规验收合格、持续负荷却不稳 → 小样复验取得合法调查空间 → 韩敬山改凭单与路线，暴露主动掩饰 → 陆昊提出分批换装，避免关防缺供 → 对手布假节点和截替换货，陆昊一次误判受伤 → 校准观测、把单点判断改为多证核对 → 渡仓护运、保护证人和完成合法取证同时成功 → 案件处置 → 两年有限试做证明能交付 → 取得临川试治令。

“灵晶不稳”须明确为劣质材料与验收负荷差异，不能事后又变成帝君施咒。韩敬山知道检测与交货流程，不知道《源天》；其假节点针对已暴露的外部检测方式，不能未曾观察便针对主角秘密视觉。

## 卷末应有与不应有

应有：陆昊更可靠而非无所不能；家族强大但有制度边界；程见秋是具有事实贡献的伙伴；试治文书可执行；军需案已结清主要责任。试治期暂定一年，允许依据实际绩效提前复核，故第二卷末正式领地授予与时间预算相容。

不应有：一卷塞入所有族群、神宫已经全黑、全部世界规则一次讲完、所有人已知穿越、把女主当奖励、陆昊成为世子、用突然更高阶反派强接下一卷。
