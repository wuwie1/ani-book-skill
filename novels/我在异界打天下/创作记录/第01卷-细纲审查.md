# 第一卷章纲核对

审查对象为[七个阶段与第1—60章计划](../分卷/第01卷-逐章细纲.md)。

| 核对项 | 章内落点 |
| --- | --- |
| 开篇与时程 | 第1章高三至王府初醒，第2章救治后跳七岁，第3章十二岁。第一日驿骑送令，第二日陆昊走到哨所，第6章解决第二夜的担架照明。案子在数周内办完，第49章以后再跨到十四岁。 |
| 首章视角 | 齐源的最后一个动作发生在车上。章末只有杨硕在王府醒来；他听不懂当地话。第2章从那声婴啼接起。 |
| 谁知道什么 | 第3章只证实受试晶异常，第7章才验出同箱数块坏晶。吃水差涉及整船，船位靠装卸簿及独立搬工。第38章外账与买家证据才指向韩敬山获利。 |
| 敌人如何反应 | 韩第8章受限、第19章停职、第38章拘押。杜从第15章出逃，第26章同伙旁听验法，第43章被捕，两人在第46章分责受处置。 |
| 伤与修为 | 第31章误判、右前臂受伤。第33、37、39章分别停术、限负荷、限定返岗，第43章由祁烈承担正面对抗，第48章恢复训练。十三岁考到三阶武修，十四岁复核。 |
| 功劳归属 | 陆昊找货、纠错并守住撤离的一步；陶守诚负责危险操作，兄长调度军需，石长庚掌船，军府逮捕与判处。 |
| 吉凶落到谁身上 | 工钱、救治、缺灯与替班均落到具体人。第49章起借一处小渡场检验日常治理，第57章以陆昊离场后的结果证明能交接。 |
| 卷二交接 | 第60章取得一年试治权、限额与成年属官协同，到临川先见欠薪渡工。正式封地留给第二卷。 |
| 初到临川的战力回报 | 第13章低阶惊兽收蹄，第59章定向收放。卷二巡领时才近距干扰两头高阶兽，龙马反杀、结契，陆昊的个人阶位另计。 |
| 折纸角的习惯 | 第1章折起讲义右下角，第53章转约书让船家亲自看候船钱。卷七最终对决才有人把这个动作与前世联系起来。 |
