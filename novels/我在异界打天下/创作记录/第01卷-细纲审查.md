# 第一卷章纲核对

审查对象为[七个阶段与第1—60章计划](../分卷/第01卷-逐章细纲.md)。

| 核对项 | 章内落点 |
| --- | --- |
| 开篇与时程 | 第1章大学校门口至王府初醒，第2章初醒想回家，五岁学法，七岁施术救信，第3章十二岁。第一日驿骑送令，第二日陆昊走到哨所，第6章解决第二夜的担架照明。案子在数周内办完，第49章以后再跨到十四岁。 |
| 首章视角 | 从校门口送花的小马起笔，他先看见杨硕通路、让齐源挪车，也先看见赖紫晴信封上的折角。第二场起贴着杨硕，表白只作回看，指控发生在公交站台。车祸后切一次母亲的厨房，不超过八十字，她还不知情。齐源的最后一个动作发生在车上，此后没有他的镜头或暗示。章末只有杨硕在王府醒来，他听不懂当地话，看见一团没人举着的亮。第2章从那声婴啼接起。 |
| 同窗 | 第2章两个应试的军官子弟暂名冯骁、祝平。冯骁那天最好，只拿到旁听牌。第3章两人是灯帐学徒，短测合格单上签的是冯骁，他验的三块确实合格。陆昊当众说“我没说你”。只给无名角色身份和立场，不改事件。 |
| 童年天赋 | 七岁只托一臂以内的半盏泼水，四息足够女孩抽出家书。尺子是同场两个大孩子送不全一滴，以及三阶的陶守诚接泼水要先看清去向。陶守诚用实做牌换回旁听牌。十二岁能稳火又能应答，验货时收术；第6章只替担架稳灯几息。 |
| 谁知道神识 | 沈令仪五岁教印时从腕脉觉出一丝波动，认为有利于修炼，不知道有多强。第2章末她摸到它变大，只当按错。 |
| 第一个带脸的对手 | 韩敬山第3章到灯帐交验，凭真合格单按惯例催发。试验只证实受试晶久用回火，此时无人怀疑他。第8章限采购与付款的时程不变。 |
| 一封家书 | 第2章的女孩暂名葛芹，父亲葛栓第3章已轮防石梁哨走夜巡。第4章查出货转石梁哨，第5章哑嗓的巡兵可以是他。只给无名角色身份，不改事件。 |
| 两线与两种钱 | 第3章正北接玄朔军报，西北收雁回岭失货状。车夫领金币，术师验矿出的元晶，军晶按器件验收。第27、53章工钱和候船钱以金币交割。第48章还回的空车和军毡只作物证。 |
| 谁知道什么 | 第3章同座、同冷态、同亮度各试两刻，只证实受试晶异常，第7章才验出同箱数块坏晶。吃水差涉及整船，船位靠装卸簿及独立搬工。第38章外账与买家证据才指向韩敬山获利。 |
| 敌人如何反应 | 韩第8章受限、第19章停职、第38章拘押。杜从第15章出逃，第26章同伙旁听验法，第43章被捕，两人在第46章分责受处置。 |
| 伤与修为 | 第31章误判、右前臂受伤。第33、37、39章分别停术、限负荷、限定返岗，第43章由祁烈承担正面对抗，第48章恢复训练。十三岁考到三阶武修，十四岁复核。 |
| 功劳归属 | 陆昊找货、纠错并守住撤离的一步；陶守诚负责危险操作，兄长调度军需，石长庚掌船，军府逮捕与判处。 |
| 吉凶落到谁身上 | 工钱、救治、缺灯与替班均落到具体人。第49章起借一处小渡场检验日常治理，第57章以陆昊离场后的结果证明能交接。 |
| 卷二交接 | 第60章取得一年试治权、限额与成年属官协同，到临川先见欠薪渡工。正式封地留给第二卷。 |
| 初到临川的战力回报 | 第13章低阶惊兽收蹄，第59章定向收放。卷二巡领时才近距干扰两头高阶兽，龙马反杀、结契，陆昊的个人阶位另计。 |
| 折纸角的习惯 | 第1章折起签收单右下角，赖紫晴的信封上有同样的折角，第53章转约书让船家亲自看候船钱。卷七最终对决才有人把这个动作与前世联系起来。 |
