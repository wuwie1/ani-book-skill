# 我在异界打天下｜表达合同

状态：用户授权 AI 在本次定稿中决定；版本1.0，2026-11-14。

来源：作者的强者反差与主动破局偏好；《斩神》已登记抽样的抽象方法，不声称覆盖全书，不模仿作者独特文风。来源范围、机制与指纹见 [参考使用说明](production/reference-use.md)。本文件为本书快照，源文件变化不自动改写此合同。

适用：全书。第三人称，以陆昊行动为主；本章表达例外写入章节计划。表达不得覆盖人物、因果与世界硬规则。

| ID | 正向规则与效果 | 适用与边界 |
| --- | --- | --- |
| STYLE-01 | 先呈现眼前需要、人物行动和后果，再补足理解它所需的设定 | 开场、转场；允许短说明，不让每件器物都带百科 |
| STYLE-02 | 战斗交代目标、位置、可用手段、限制和动作造成的变化 | 优势必须被使用；看见弱点不等于已有力量打穿 |
| STYLE-03 | 对白带着人物各自任务和知情边界；一人询问可能在争取权限，另一人在担心风险 | 军议、谈判、家常；不让人人替作者讲道理或互相喂设定 |
| STYLE-04 | 每次切换视角增加一项事实或改变一种判断，清楚标示地点与任务 | 多线行动、信息差；不为重复惊叹而轮换视角 |
| STYLE-05 | 支持表现为具体照顾、训练、分担和可退出的条件，被帮助者仍完成自己的责任 | 家庭、伙伴、感情；不靠每次受伤绑架来证明重视 |
| STYLE-06 | 让身体、材料、时间和承诺记录代价，读者先见行动再理解感情 | 关系与战后场；一件日用品本身不自动产生温情 |
| STYLE-07 | 完成一层责任后给共同生活、修复或安定感留落点 | 高潮后与终局；未解任务须有明确去向，不能含糊留白当完结 |
| STYLE-08 | 每3—5章检查实际进展，交付能力、信息、关系或成果中的一种变化 | 连载节奏检查，不是固定章式；允许完整静场和不同章末 |
| STYLE-09 | 用称谓、器物、土地与礼俗建立东方感，保持句意清楚 | 不堆冷僻字、伪古语和大段术名；初次出现只解释当前有用部分 |

| ID | 可观察的风险 | 修订权限 |
| --- | --- | --- |
| AAI-01 | 连续场景只有旁白宣布强大、温情或聪明，没有可见结果 | 在保留事实前提下定点改成行动与后果 |
| AAI-02 | 多个角色语气相同，反复用整齐排比或同一种感叹结束 | 按人物任务调整对白；不机械禁用正常句式 |
| AAI-03 | 每段都解释寓意，每章都强造震惊、反问和悬念 | 删除重复解释，按本章责任选择结束方式 |
| AAI-04 | 为“更爽”临时改写等级、契约或知情边界 | 不属于表达修文权限，返回上游检查因果 |
