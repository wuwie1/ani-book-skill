# 全书设定与因果核对

审查范围为十二卷的职责、卷际交接、首卷六十章及前三章写作计划。第一章从大学校门口进入王府，卷七建立大昭，卷十二终战与立约。下表列的是写到这些场面时可查的依据，均为规划。

| 读者可能追问什么 | 场上给出的答案 |
| --- | --- |
| 齐源为什么冲着替他跑过三趟腿的人去？ | 他从军训起追赖紫晴，为她改了不少，三回托杨硕递东西都被退回。五月二十号当众被拒，转头看见她的信折着杨硕才有的角，他认定杨硕早就知道、一直在看他的笑话。他家里有钱，略嚣张，这份难堪他咽不下去。信在争，碰撞时杨硕任信飞走，伸手抓住齐源，齐源也攥紧了他的袖口。 |
| 大一学生为什么会神术？ | 婴儿只听得清雨声、会想家。五岁沈令仪教法印，七岁他把练了两年的凝水诀用在一小片散水上。地球记忆让他在意那封家书，强大的精神力让他能在几息内把它救下来。 |
| 家里人知道他有神识吗？ | 沈令仪五岁教印时从腕脉觉出一丝神识波动。这种脉她只在圣阶的公公身上摸到过，于是认定儿子这点很浅、多半天生，有利于学印和入定。她不知道它有多强，七岁救信那晚摸到它变大，只当自己按错。读者从第2章就看得见它起作用，第13章惊兽收蹄以前没有人掂出分量。 |
| 齐源也穿越，读者什么时候知道？ | 卷七统一战揭名时才知道。作者已确认这是伏笔线：第1章齐源最后的动作是车里攥住杨硕的袖口，之后没有他的镜头或暗示。叙事可以切到旁观者、家人和对手，齐源这一世的视角揭名前不进入。 |
| 前三章凭什么让人往下看？ | 第1章先让送花的外人看见他三句话通开校门、一句话让富二代挪车，再让读者比他早看见赖紫晴信封上的折角。齐源当众说他早就知道，两人争到公交车上，她说明天亲手把信给他，明天没了。第2章回不去写足，七岁接住泼出去的水，三阶的陶守诚给尺子。第3章他当众说验过的货不能发，对面是拿着真合格单的韩敬山，一箱已经出库。每章按[写法合同](../写作风格.md)的四条读者合同和六条叙事办法验收。 |
| 替齐源折出来的角，为什么成了他早就知道的证据？ | 折角是高中同桌那一年替咬秃指甲的齐源养出的习惯，全校只有杨硕这么折。赖紫晴学了他，信封上也折一个。齐源比谁都认得这个角。三回东西是杨硕递的、三回都由他带回去，这些也是真事。能说清的只有她自己，她发消息说明天早八之前亲手把信给他，车祸把这一步拿走了。 |
| 主角凭什么让人觉得有魅力、能力强？ | 靠做事。保安求不动、齐源仗着父亲公司捐的校门不肯挪的车，他看五秒钟路、派三件事、说一句“十二路进不来，她坐十二路”就挪开了。齐源被拒时他把脸转开，信到手边他说等她自己给，撞车时他放掉信去拉人。办法参考《遮天》的叶凡，登记在[参考机制](参考机制使用说明.md)的 LEAD-01 至 LEAD-05。他对身边人的心思迟钝，到王府以后修为和规矩都从头学。 |
| 赖紫晴会不会也到异界？ | 现有大纲里不会。她不在那班车上，第1章以后没有她的镜头。作者若想让她后文再出现，需要另行决定并补档案。 |
| 同辈之间的冲突怎么一级一级变重？ | 被小看，争一个有限的位置，用真事搭起来的指控，旁人表态，拿人人能验的东西说话。第1章是杨硕和齐源，第2—3章由灯房的冯骁接上。办法取自《遮天》第1—33章，登记在[参考机制](参考机制使用说明.md)，桥段和人物关系不搬。 |
| 两种钱碰到同一块晶怎么办？ | 民间、军饷以金币计。术师收按成色净重交割的元晶，矿脉开采后才有供给。军府买的是切制灯料，旧晶只能按剩余量或残料收。丰济社粮票由有约的仓兑粮。 |
| 王府为什么会追查自家后手劫走的货？ | 兄弟二人保密，陆峥真守正北玄朔边关，也真办西北案。寨众有人收容军户，有人拦车夺货。卷七拒绝王命以后才认亲。陆砚川以枪神之身开山接人，旧货仍据单归还，不足折付金币。参见[叔祖的卷七档案](../人物/档案/陆砚川.md)。 |
| 南境的仓户凭什么信一个少年？ | 丰济社最初由有粮的成年仓户为粮票联保，孟循排粥棚的班。成年后他兑现旧票、救过车夫，才有当社首的本钱。粮户曾心甘情愿把钥匙给他，后来也有人因拒交钥匙而断粮。 |
| 统一战为什么到这一刻才认得出来？ | 两人前六卷各自生活在南北两地。仓内折角只引起怀疑。失足时又攥到袖口，两人才共同想起那次车祸。车夫讨粮曾让读者见过回声的边界。孟循付出代价才触到当年没说出口的心念。先听旧名，再回看心念。第八卷由陆昊亲自告诉母亲。 |
| 十二岁能证明的事有多大？ | 同一灯座回到相同的起始温刻，以夜巡亮度各试两刻，一块好晶稳定、一块待验晶回火。世子先停整批，哨所逐件复验才圈出同箱坏件。船的吃水只能证明载重变了，舱位靠装卸簿和搬工证言核准。第38章才有独立买家实据证明韩敬山获利。 |
| 少年怎样得到九阶龙马？ | 首卷先有第13章惊兽收蹄、第59章定向收力。临川面对两只高阶灵兽只争得合击中的一瞬。龙马反杀两敌，有机会离开，回头才真正完成兽契。它出外救人时，陆昊必须自己给渡口留下守军。 |
| 地底的三家为什么不做同一种选择？ | 阴月先看见伤者出井后仍可凭原籍领粮，才率部归附。墨鼠人口多，工匠先修高渠给居民供水，再领工粮。土龙派出一位强者就少守一处聚落，须先安置那里的人。越疏负责档案，各井镇授权才开库。 |
| 武元井道怎么走到另一界？ | 入井只到武元地底。征走工役的是神宫掌握的界门，卷六残关只能以短铃联系潮生界守渡会。卷八双方各自在本岸修阵，先通信、再收回空匣，核清返程承载才送人。 |
| 王府幼子为什么能称帝？ | 陆昊担下南境旧粮票，先付的代价是临川北运船改期。父兄等接防各部就位才交旧朝兵符。归附州县和各军推戴承担粮债与统一防务的人。陆景珩保有王爵承袭，大昭军职另行任命。 |
| 打退帝君以后，还能给受灾各界留一条活路吗？ | 帝君早年的敕令确实救过人。卷十另开的航路到终战还能接回伤船，收到守渡会回铃后，联军才切敌军供能。晏执衡仍有神域修为，陆昊须在余下潮窗内亲自决胜。 |

首卷的年龄、伤势与调查顺序见[首卷核对](第01卷-细纲审查.md)。开始细化第七卷时，先落下谁在仓内、谁在仓外和哪条船改期。禁术名“溯源”仍是暂称，齐源揭名后的去留和异族来历留给后文。
