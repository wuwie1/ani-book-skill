# 全书设定与因果核对

审查范围为十二卷的职责、卷际交接、首卷六十章及前三章写作计划。第一章从高三现场进入王府，卷七建立大昭，卷十二终战与立约。下表列的是写到这些场面时可查的依据，均为规划。

| 读者可能追问什么 | 场上给出的答案 |
| --- | --- |
| 齐源为什么需要害一个也替他署名的人？ | 最巧的一步是他熬夜想出来的，父亲还为看他主讲换了班。听见同学把他当成“帮过忙的人”，齐源明知稿上有两人的笔迹，仍要求撤换杨硕。讲义在争，碰撞时杨硕任纸飞走，伸手抓住齐源，齐源也攥紧了他的袖口。 |
| 高三学生为什么会神术？ | 婴儿只听得清雨声、会想家。五岁沈令仪教法印，七岁他把练了两年的凝水诀用在一小片散水上。地球记忆让他在意那封家书，强大的精神力让他能在几息内把它救下来。 |
| 两种钱碰到同一块晶怎么办？ | 民间、军饷以金币计。术师收按成色净重交割的元晶，矿脉开采后才有供给。军府买的是切制灯料，旧晶只能按剩余量或残料收。丰济社粮票由有约的仓兑粮。 |
| 王府为什么会追查自家后手劫走的货？ | 兄弟二人保密，陆峥真守正北玄朔边关，也真办西北案。寨众有人收容军户，有人拦车夺货。卷七拒绝王命以后才认亲。陆砚川以枪神之身开山接人，旧货仍据单归还，不足折付金币。参见[叔祖的卷七档案](../人物/档案/陆砚川.md)。 |
| 南境的仓户凭什么信一个少年？ | 丰济社最初由有粮的成年仓户为粮票联保，孟循排粥棚的班。成年后他兑现旧票、救过车夫，才有当社首的本钱。粮户曾心甘情愿把钥匙给他，后来也有人因拒交钥匙而断粮。 |
| 统一战为什么到这一刻才认得出来？ | 两人前六卷各自生活在南北两地。仓内折角只引起怀疑。失足时又攥到袖口，两人才共同想起那次车祸。车夫讨粮曾让读者见过回声的边界。孟循付出代价才触到当年没说出口的心念。先听旧名，再回看心念。第八卷由陆昊亲自告诉母亲。 |
| 十二岁能证明的事有多大？ | 同一灯座回到相同的起始温刻，以夜巡亮度各试两刻，一块好晶稳定、一块待验晶回火。世子先停整批，哨所逐件复验才圈出同箱坏件。船的吃水只能证明载重变了，舱位靠装卸簿和搬工证言核准。第38章才有独立买家实据证明韩敬山获利。 |
| 少年怎样得到九阶龙马？ | 首卷先有第13章惊兽收蹄、第59章定向收力。临川面对两只高阶灵兽只争得合击中的一瞬。龙马反杀两敌，有机会离开，回头才真正完成兽契。它出外救人时，陆昊必须自己给渡口留下守军。 |
| 地底的三家为什么不做同一种选择？ | 阴月先看见伤者出井后仍可凭原籍领粮，才率部归附。墨鼠人口多，工匠先修高渠给居民供水，再领工粮。土龙派出一位强者就少守一处聚落，须先安置那里的人。越疏负责档案，各井镇授权才开库。 |
| 武元井道怎么走到另一界？ | 入井只到武元地底。征走工役的是神宫掌握的界门，卷六残关只能以短铃联系潮生界守渡会。卷八双方各自在本岸修阵，先通信、再收回空匣，核清返程承载才送人。 |
| 王府幼子为什么能称帝？ | 陆昊担下南境旧粮票，先付的代价是临川北运船改期。父兄等接防各部就位才交旧朝兵符。归附州县和各军推戴承担粮债与统一防务的人。陆景珩保有王爵承袭，大昭军职另行任命。 |
| 打退帝君以后，还能给受灾各界留一条活路吗？ | 帝君早年的敕令确实救过人。卷十另开的航路到终战还能接回伤船，收到守渡会回铃后，联军才切敌军供能。晏执衡仍有神域修为，陆昊须在余下潮窗内亲自决胜。 |

首卷的年龄、伤势与调查顺序见[首卷核对](第01卷-细纲审查.md)。开始细化第七卷时，先落下谁在仓内、谁在仓外和哪条船改期。禁术名“溯源”仍是暂称，齐源揭名后的去留和异族来历留给后文。
