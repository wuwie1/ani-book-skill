# 我在异界打天下｜修行、战斗与器物表现

2026-11-22修订。修行场景按[世界设定的逐阶对照](世界设定.md#阶位的可见表现与称谓)和[分卷进度](分卷/分卷规划.md)安排。

## 三条修行路线如何同场成立

| 路线 | 修什么 | 实际优势 | 最容易被击中的短板 |
| --- | --- | --- | --- |
| 神师 | 灵元承载，以法印、咒诀与符具组织术式 | 远近神术、借媒介察看环境、操持阵式 | 施术准备、耗神、被逼近与器具误报 |
| 武修 | 气血、筋骨、经脉窍穴、真罡与武道真意 | 身体承载、近身压制、武器与军阵协同 | 距离、地形、感知遮蔽、持续战斗后的真实损伤 |
| 陆昊的古修路径 | 以《源天》修内息、通经脉，练习收放天生神识 | 能察觉灵兽散出的威压，也能以自身灵压使它失去片刻攻势 | 魂力虽强，身体年幼。离得远、对手已有防备或他自己已力竭时，都难以生效 |

一阶神师对应一阶武修，逐级相对至九阶。再往上，两路共用圣阶、神域两个境界名。常人晋入圣阶才可修习灵识。陆昊因胎穿而魂力异常强大，出生即有神识。灵压是他外放神识时施于灵兽的威压。个人阶位仍须按神术、武修各自的功力实测。

第1章内息微调引起祖母注意。第2章陆昊听见暖药炉热起来才刮响，陶守诚热机复验、拆修。第3章十二岁，三阶神师、二阶武修；持续负荷下的灯火和标板是当众验坏晶的凭据。第31章右前臂受伤，第48章才获准恢复训练，第56章通过三阶武修考核。

## 陆昊的标志性能力链

| 阶段 | 能力与表现 | 主动使用方式 | 明确不能做的事 |
| --- | --- | --- | --- |
| 出生与启蒙 | 天生神识，身体初时只能响应自己的一点内息 | 在回流的间隙松一口气，让祖母察觉尚有余地泄压 | 婴儿外放威压、辨认阵法或施展高阶术式 |
| 首卷 | 灵压使近处低阶灵兽受惊、僵住或收蹄 | 第13章为护车夫本能压住受惊驮兽。到十四岁能对准一头兽及时收力 | 控制神志、读取记忆、透视材料或靠这招定住人类武修 |
| 卷二初到临川 | 察觉远处兽威，潜近辨认；取合击的一瞬放出灵压 | 龙马应允结契后，陆昊令九阶初级九头蛇与八阶顶峰赤尾蝎同时一滞，龙马抓住空隙反杀 | 陆昊独斗两兽、反复压制高阶对手、把契兽的九阶修为算作自己的阶位 |
| 卷二至三 | 联纹法，将有限术式通过合适材料连接 | 改善器具稳定性，布置局部战场条件 | 任意叠加低阶术式、凭图纸瞬间量产 |
| 卷四至五 | 截流印与断潮枪技协同 | 先识别一段已暴露的能量输送，再在可承受窗口打断或偏移，创造近战机会 | 夺取对手全部灵元、越过力量差距吞掉任意神术 |
| 卷六至八 | 圣阶真意、合流阵的个人与多人版本 | 让不同来源力量按各自承载配合，保护阵基并完成有边界的联动 | 把同伴变成电池、无限扩大范围、不受体能与材料限制 |
| 卷九至十二 | 合流法域 | 对自身及已同意接入的阵基进行精密调度，先练单锚再练多锚；与足够强的自身修为共同发挥作用 | 强制控制他人法域与意志，取消所有术式，毁名册便杀神 |

龙马之战用一次灵压就够。两兽为夺天马与龙族的混合血脉，全力夹攻，留给陆昊潜近的一线机会。灵压落下，龙马先杀赤尾蝎，趁围势已破再杀九头蛇。等龙马转身，陆昊耗尽力气，已经无力再帮它。它仍照约回来与他结契。此后它能替陆昊赶到告急的渡口、从险地带人回来，陆昊自己的兵器、阵术与军队仍须从头练起。

## 常用神术与武修技法

以下学习窗口是本书计划中的常见门槛，不是另一套术法等级；熟练度、媒介与具体施术者另记。

| 名称 | 常见学习窗口与用途 | 代价或克制 |
| --- | --- | --- |
| 引焰诀 | 低阶神师引导小范围火势、点炉与临战牵制 | 耗灵，燃料与环境影响结果；不能低阶焚城 |
| 凝水诀 | 低阶神师凝聚、移动少量水，辅助生活与战斗 | 水量、杂质处理与持续时间有限，不能替代完整净水系统 |
| 定风印 | 中低阶神师使局部风流暂稳，辅助船帆与远射 | 强天气、施术距离与不断变化的环境会破坏效果 |
| 护身符 | 预先制成的一次或少次防护器物 | 消耗材料，有方向、承载和损坏上限，不是永久被动免伤 |
| 地缚术 | 中阶神师利用已理解的地质限制局部行动 | 对飞行、松散地层或纯强力突破各有不同限制 |
| 雷引诀 | 中阶以上引导已具备条件的雷性力量 | 需要绝缘、距离与导路；不能默认雷雨随时存在 |
| 净秽术 | 用于特定污染、病理或残留术式的辨识与处理 | 必须知道对象，不按种族或信仰自动判定邪恶 |
| 固脉术 | 医护与阵式稳态处理 | 只能在已诊断范围降低损伤，不瞬间治好一切 |
| 伏桩法 | 武修基础，建立气血、重心与承载 | 长期练习，疲劳和旧伤要管理 |
| 破岳步 | 中阶武修借重心与罡劲完成短距突进 | 是步法而非瞬移，路面与身体负荷影响结果 |
| 回澜式 | 武修卸力并配合自己的护持力量调整受力方向 | 角度、强度和时机缺一不可，不能无限反弹强敌攻击 |
| 镇阵枪 | 军中多人兵器协同技法 | 依赖训练、口令与阵位，队伍混乱后不能只喊阵名恢复 |

禁术之“禁”来自高风险、不可控或制度禁止，不自动代表最高阶。空间通行、干涉元神与大范围城防均依照已经建立的世界规则逐步出现；时间停止、无条件复生不作为常规技能保留。

## 阵法、器物与生产边界

| 类型 | 具体资产 | 取得与维护 | 剧情中的实际职责 |
| --- | --- | --- | --- |
| 个人 | 护脉环、护身符、断潮枪 | 分阶段制作、检验、修补；成长兵器要更换合适材料 | 承受有限冲击与战斗协同，不替主角修炼 |
| 城防 | 稳脉阵、守渡阵、分段刻纹阵基 | 地势、固定材料、持续供能与值守 | 保护生产和交通；离开位置后价值不同 |
| 工坊 | 试纹台、分段刻纹器、材料处理炉 | 赤衡、罗小满等专业者完成工艺；有工伤、良率与产能约束 | 让新方法成为可交付产品，保留共同功劳 |
| 军需 | 符甲、雷矢重弩、破阵重器 | 随材料、熟练工和运输扩大，不逐日无限增产 | 使普通精锐完成明确战场任务，不能代替战略强者 |
| 航运 | 御风舟、浮空楼船、海船与界舟 | 海船不能因换名直接跨界；各需航手、维修与供给 | 不同环境各有用途，程见秋事业持续成长 |
| 跨界 | 通天渡、界桥基座、界关 | 已核坐标、两端阵基、储能、窗口及回返安排 | 贸易、防御、撤离与终战的可见条件 |

阵名不自带神话无敌地位。凡“聚”“护”“联”类阵法，必须交代力量从何而来、由谁承担、坏在哪里；符箓和法器的品阶只说明适用能力范围，不自动替代实际测试。

## 军事组织

军种分工不是同时解锁的成品军团。第一卷只有王府既有军队；第二卷从临川护卫起步，第四卷才逐渐形成可持续的大军协同。

| 名称 | 职责 | 必须依赖的条件 |
| --- | --- | --- |
| 靖河卫 | 守城、要地与正规步阵 | 稳定训练、粮饷、军官与轮换 |
| 契兽游骑 | 侦察、追踪、山地机动 | 合作契兽、食物、熟悉地形；不是所有兽类都可乘骑 |
| 赤炉重装 | 正面承载与突破 | 材料、维修、运输与侧翼保护；人员不只限魔族 |
| 远射营 | 压制、掩护与反器械 | 视线、弹药、观测与保护，不能隔图锁定所有敌人 |
| 符阵工兵 | 建设、破障、护桥与修阵 | 时间、测绘与被保护的工作面 |
| 界舟水师 | 海路发展到跨界后的运输、护航与撤离 | 先海后界的航行训练、船坞、坐标与回航储备 |

这套组织服务于“陆昊亲自能打，又能让一群人做成更大的事”。个人决战、大军行动和政治选择各有职责，不用一种力量替代全部故事。
