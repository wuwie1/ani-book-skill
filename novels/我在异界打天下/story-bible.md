# 我在异界打天下｜故事主线

版本1.0，2026-11-14。长期故事权威；本文件中的事件均为计划，不是已发生正文事实。世界硬规则以 [world-bible.md](world-bible.md) 为准。

## 起点与四次目标变化

陆昊前世刚结束高考，在一次异常界潮中失去对原世界的感知。一份流散的护魂道书残印与他的意识相合，使其抵达武元大陆一个刚出生的孩子身上。开篇只呈现他能感知的结果；“界潮意外、残卷来源、非神明选定”的答案在第八至十卷由互相独立的证据逐步建立。

他出生于大周异姓淮北王府。父祖的战功给他优越教育，却也让家族处在朝廷、边境与各族盟约之间。婴儿期遇护生阵回流，他通过最小的内息调整自保，成人阵师完成现场处置；这一回报不把婴儿写成能指挥全府的统帅。

童年以少量完成的事件展示学习和失败。十二岁以后，他主动争取参加家族的运输、器物验证与边地事务，想得到凭本事经营一处产业的资格。首卷赢的是资格与试治机会，第二卷才获得正式封地权责。

四次欲望转移：

1. **我能自己做成事。** 从家族庇护中争得有限行动空间。
2. **已经做成的事不能任人收走。** 封地成果与伙伴利益遭压制，陆昊学习组织、外交和战争。
3. **我要建立能保护这些成果的国家。** 旧王朝要求撤防、交出独立军政权并执行强制征召，现有妥协条件无法同时保住边地与伙伴。
4. **任何上层权力也不能随意收回这一切。** 建国后仍受制于界路与神朝敕令，陆昊主动建立通天渡与诸界联盟。

## 对立如何逐级成立

第一阶段的敌手韩敬山，为填补自己经手军需的亏空，替换灵晶并转嫁责任。他没有奉终局敌人的命令。陆昊以调查、验证和一次有准备的战斗破局，后果是获得资源，同时暴露自己能够改变地方利益。

第二阶段是多个真实利益集团：旧商路经营者不愿失去定价权，炉城不愿承担未验证的生产风险，灵狐圣庭关心祖地，北荒部族关心通道。陆昊必须在具体问题上争取合作。成功的盟约应有已完成的交换、可见的义务和发生争议时的处理方式。

第三阶段是王朝与教权。皇帝萧承钧有守住中央权威的理由，并非看见天才就无条件迫害。天命神宫也提供治疗、防护与灾时支援。矛盾逐步集中到独立军队、地方收入、强制受箓及征召上；陆昊先尝试交涉和交换，再因代价不可接受而选择反抗。

第四阶段是诸界通行权。玄穹天庭由不同神国与职司组成，司契帝君晏执衡长期掌握一部分界路敕令。他在真实界潮加剧时提出“归契令”，以稳定航路为理由要求各界交出更大控制权。现有盟约有实际作用，新的集中征收也会造成实际受害。陆昊必须拿出能运行的替代方案，才能争取摇摆者。

晏执衡不是自然灾害的制造者，也不是每个地方敌人的幕后主人。他会争取人才、观察新工艺、提供有条件的帮助；当陆昊的替代网络足以威胁其统治方式时，冲突才成为全面战争。

## 三条长期故事线

### 事业与战争

一处试治产业 → 临川封地 → 跨族生产与商路 → 北境军团 → 海路与地底支点 → 大昭建国 → 通天渡 → 诸界共同防线。

每份新资产要经历取得、验证、交付与维护。上一阶段的人和资源会继续发挥作用；大陆不会在陆昊进入上界后停止存在。

### 家庭与关系

父亲从允许试做，到不愿儿子越过君臣边界，再到亲自判断撤防命令会造成什么。兄长的世子继承权始终明确；他面对的是既定人生与新局势的冲突，不因弟弟有成绩便自动退位或突然黑化。祖父的战场见识和祖母的界术认识各有边界。

程见秋先要保住船队和船员。她与陆昊可以在运力、风险和撤退问题上争执；感情来自共同承担，成年后逐步形成明确选择。她建立自己的界航事业，不因成为伴侣便停止拥有目标。其他重要女性分别承担族群、旧史、信仰与邻国责任。

### 修行与揭示

《源天》让陆昊能走一条罕见但可学习的古修道路。他的第二视野需要训练；早期看到的只是局部气机。神识、身体、材料和协同条件同时满足，才产生真正优势。

揭示依次回答：道书为何有用 → 为什么有些术式能相互联结 → 灵印异常究竟意味着什么 → 古人曾怎样通行诸界 → 神朝掌握了哪些真实权力 → 哪些权力可以被替代。

## 权力结果与结局

- 第七卷推翻大周对北境及相关战区的强制统治，建立**大昭王朝**，陆昊即帝位。称帝不等于所有人族国家和异族势力都已归附。
- 淮北王爵的原定继承人仍是陆景珩。帝位来自新政权的建立，不通过夺兄长爵位取得；旧爵位在新朝的地位经公开安排处理。
- 邻国、圣庭、炉城和北荒部族可以保持自己的内部治理。对共同战争、交通、供给和界路的承诺由盟约约束。
- 陆昊在神域境后继续提升法域的精度、承载、持续性和多锚协同能力。帝君是职号，不能被用作随时追加的新境界。
- 终战先完成军团、交通与阵基层面的任务，再为陆昊与晏执衡的决战创造条件。切断神籍文书不能让敌人自动失去全部修为。
- 陆昊最终获胜的关键，是原有观测能力、足够的自身修为、事先验证的联阵办法、盟友独立完成的战场任务，以及一次主动承担风险的选择。
- 他保有个人实力和大昭帝位，成为诸界共同防御与通行盟约的主要建立者。对盟友的影响力来自实力与履约，不等于可以任意支配所有族群。
- 世界损失有余波。已失去的普通生命不因终局胜利批量复活；家园、生产与关系以明确可见的恢复结果收束。
- 最后约十至十五章完成战后安排、人物选择与共同生活。陆昊明确把此世当作需要负责的家；前世记忆得到情感安置，不突然追加自由双穿。

## 后续规划必须保留

婴儿期简短；少年期有真实战斗回报；关系对象保有行动权；前期成果在后期继续有效；神域以内的差异有具体依据；大昭称帝与诸界联盟是不同权力结果；每卷兑现自己的责任，远期细节按新证据深化。
