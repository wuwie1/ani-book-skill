# 第001章写作上下文

配合[《你早就知道她喜欢你》](章节计划.md)。本章生效的写法是[写法合同](../../写作风格.md)的 HOOK-01 至 HOOK-04，NAR-01 至 NAR-06，STYLE-03、STYLE-05。同辈冲突的推进办法和主角怎么立，见[参考机制](../../创作记录/参考机制使用说明.md)的 PEER-01 至 PEER-07、LEAD-01 至 LEAD-05。本章没有修行内容，HOOK-02 的尺子是保安求不动的那辆车被他一句话挪开。

| 眼下的事 | 写作时抓住什么 |
| --- | --- |
| 从哪里开场 | 五月二十号傍晚的大学东门，送花的小马抱着九十九朵玫瑰，看一辆奔驰把门堵死。他谁也不认识，心里只惦记尾款。 |
| 杨硕怎么亮相 | 看五秒钟路，三句话派三件事，再对齐源说“挪车”。理由只有一句：十二路进不来，她坐十二路。他的话都短，旁人管他叫“高个子”，名字从齐源嘴里出来。 |
| 谁知道什么 | 小马和读者先看见信封上的折角和她的眼神。齐源捡到信才知道。杨硕最后一个知道，是齐源说出“她学的你”以后。赖紫晴不知道信掉在站台上，看了表白墙才发消息。 |
| 齐源为什么这么做 | 他家里有钱，习惯拿排场办事，可这两个学期是真改了。三回托杨硕递东西，三回被退回，五月二十号当众被拒，转头发现她折角折得跟杨硕一样。他认定杨硕早就知道。那句“你拿我当猴看”要说得快。 |
| 旁人怎么站 | 贺闯嘴快，帮忙帮出一句“他自己都没对象”。寸头问她折角怎么跟你一个样。班长只说看见的真事，偏偏越听越像那么回事，最后问出那句“你知不知道”。 |
| 杨硕的脾气 | 先愣，再是气。心里可以贫，嘴上要硬。他不认“早就知道”，也不让任何人拆她的信。 |
| 那个折角 | 校门口折在签收单上，没解释。站台上出现在她的信封上，交代是高中同桌那一年替齐源折惯的。公交上齐源捏着那个角撕开封口，撞车时信飞走。 |
| 车上 | 两个不认识的女生也在说他。母亲回“排骨，给你留着”。她的消息在撕信那一下亮起来。杨硕舍信拉人，齐源揪住他的袖口。车祸不少于三百五十字。 |
| 厨房 | 同一时刻，火拧到最小，排骨扣着，她没关火。不超过八十字，她还不知道。 |
| 停笔处 | 软布、听不懂的话、一团没人举着的亮，然后是自己的哭声。闭上嘴，哭声停了。 |

不能越过的线：齐源最后的动作发生在车里，此后没有他的镜头或暗示。赖紫晴只留在地球，信的内容不写。厨房那几句停在她不知情的时候，之后的地球消息是空白。异界的家人和新名字留给下一章。
