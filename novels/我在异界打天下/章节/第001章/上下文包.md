# 第001章写作上下文

采用[《明天我自己讲》](章节计划.md)。开场是地球高三教室，章尾是大周淮北王府，两个名字属于同一位主角。

| 当场用得到的事 | 写作时如何呈现 |
| --- | --- |
| 杨硕，十八岁，高三在读 | 还要上课，也曾等着和母亲一起吃晚饭。地球上的老师、同学、母亲都叫他杨硕 |
| 齐源，同班对头，过去同桌 | 两人合做讲义，各有贡献。齐源咬秃的指甲翻不开薄纸，杨硕习惯折起一角再递给他。教室和车上的进退就从这段交情里来 |
| 原稿在齐源家里 | 老师让两人明早复核，两人同乘公交去取。车祸打断了他们还没讲完的话 |
| 杨硕眼前最后一件事 | 齐源撕掉随身讲义的署名页，杨硕本想夺回。手机亮出母亲回的“给你留着”。碰撞时他任纸落下，改去拉齐源，对方攥紧他的袖口。意识在这里断开 |
| 他能感到的第一件新事 | 身体太小，喊母亲只发出婴啼，周围人声陌生。陆昊是本世的名字 |
| 章间承接 | 第2章起首才处理护生与救治，成年人根据孩子的反应作判断 |

正文素材取[新书简报](../../新书简报.md)、[开篇细纲](../../分卷/第01卷-开篇细纲.md)和[本书写法](../../写作风格.md)。齐源在本章所需的生平已摘在上表。事故后的地球消息对杨硕仍是空白。
