# 第001章写作上下文

配合[《明天我自己讲》](章节计划.md)。叙述紧贴高三学生杨硕，事故两头由同一双手、同一副耳朵接起。

| 眼下的事 | 写作时抓住什么 |
| --- | --- |
| 公开试讲 | 齐源确实想出了辅助线，杨硕让后排同学听懂并能复述。家长节目单只印主讲，讲义有两人署名。两张纸的用途不同。 |
| 齐源当众诬告 | 他父亲为了看他上台已经换班。别人把整道题算给杨硕后，他蓄意反称整稿归己。老师安排次日带原稿复核。 |
| 旧同桌的习惯 | 齐源咬短了指甲，杨硕递讲义前会折起右下角、把字转向他。这会儿杨硕还在生气，手上动作照旧。 |
| 车上 | 共用草稿在齐源家。母亲回“给你留着”。署名页被撕下，车遭碰撞。杨硕舍纸拉人，齐源攥住他的袖口。 |
| 停笔处 | 软布、自己的哭声、抱起他的臂弯。此刻听不懂当地话。出生平常，异界的家人和新名字留给下一章。 |

当章可用的齐源经历已列在表内。杨硕离开那班车以后的地球消息仍是空白。
