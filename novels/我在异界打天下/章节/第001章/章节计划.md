# 第001章｜这福气，先撤一半

开篇v2试写合同，2026-11-16。来源：新开篇窗口、写作风格.md及本章列出的硬事实。作者授权重做；正文尚待试写与选择。

## 即时目标与硬边界

出生当天，陆昊要争到下一口气。护生防护与自身护魂残印不适配，输入越强越难受；他只有身体感知及偶然闪现的一点内息方向，能尝试一次极小调整。许文瑛与医者据此减弱输入、撤开局部阵片，完成实际救治。结束时呼吸稳定、产室危机解除，绝不能停在“祖母抬手，还没动阵”。

第三人称贴近陆昊；出生当天不能听懂当地语言。成人判断需要一小段明确转入产室外部的叙述；随后通过触觉、声音、照护回到婴儿感知，不能让他解读阵名、王府政治或对白笑点。前世只记得高考结束后的普通生活和父母牵挂，没有确认死亡原因，更没有作战、查防、修仙经验。家人不知道前世记忆。

## 人物与规则

- 陆昊（CHAR-LU-HAO）：新生儿，无法坐起、说话或看清远处；无成熟第二视野、阶位、术式。身体疲惫是真限制。
- 沈令仪（CHAR-SHEN-LINGYI）：刚生产的母亲，疲惫、有医学判断，要求调整照护；不独自托起整阵。
- 许文瑛（CHAR-XU-WENYING）：祖母，能复核阵路并指挥泄压。由她完成专业操作；不识破残印来源。
- 陆峥（CHAR-LU-ZHENG）：先在外间让出空间，脱险后进来；行动可靠，抱婴儿时显得生疏。
- 陆景珩（CHAR-LU-JINGHENG）：八岁哥哥，获准后短暂探视；认真模仿大人照顾弟弟，产生一次轻微反差。
- 调用 RULE-BIRTH 与 STAGE-HOME：普通护生措施的适配问题；本章不涉及神籍签约、夺舍、终身神力追杀。PAY-01只埋“不适配与细微内息感应”。

## 读者体验合同

- readerQuestion：成年记忆困在婴儿身体里，他能不能自己争取一点生机？
- protagonistWant：吸进下一口气，停止越救越难受的刺激。
- primaryResistance：身体无法执行成年人的指令，也说不出自己的感觉。
- keyTurn：放弃强行维持完整呼吸，只在回流间隙缩短一次接续；成人捕捉到反应，改变救治方式。
- promisedReward / rewardLevel：一次微小主动选择产生实际作用，救治当章完成；partial。
- emotionalShift：窒息与陌生 → 有办法可试 → 脱险后的虚脱 → 被笨拙小心地接住。
- informationReveal：保护也有适配限制；那一点方法不是一次性的幻觉，尚不知是什么。
- netChange：危急新生儿变成稳定受照护的孩子；陆昊知道自己能尝试一个极小动作。
- inheritedHookResponsibilities：首章，无旧钩子。
- endingHook：休息片刻后，他在安全状态下主动找回一点同样的气息走向，来不及进一步尝试便睡去。把“偶然救命”变成“以后能学会什么”的期待，不再制造同一窒息危机。

## 节奏段与场景预算

目标2600字，允许2300—3000。出生救治占约前六成，余下交付放松、家人关系与方法萌芽；预算为指导，不机械凑字。

实际场景为救治、探视、安静收尾三场。低于下限仍须完成选择、泄压、稳定呼吸与家人互动；超长先删重复体感、两轮相似试错和解释性总结。
