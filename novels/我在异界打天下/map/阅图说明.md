# 武元大陆舆图

用浏览器打开[离线地图](离线地图/index.html)。页面包含立体地形、区域图志和三幅原图，可离线查阅。

点击山地、平原、河口、海面或群岛的任意位置，即可勾出所选区域、查看地标和通行记。也可从区域索引用键盘选择。点地标可继续读城邑、渡口、港埠与岛屿的说明。

在立体视角中拖动可旋转，滚轮可缩放，右键拖动可平移。触屏可用双指缩放、平移。俯视模式支持拖动平移。“图层”可开关地名与商路，“复位视角”返回当前图幅全景。未启用 WebGL 的设备会采用可点选的平面图。

## 图据

图取大周仍在、临川尚待授予试治的开篇时点。八个区域按地形与水系分组，轮廓、海拔和点间距离均为读图拟绘。七港以外仍属武元界。地底井址待勘，井道与汲水池见独立剖面。

## 修改与重建

修改后，在本目录使用 Node.js 22.12 或更高版本执行以下命令。构建产物为可单独复制的 `离线地图/index.html`。

```sh
npm ci
npm run build
```

开发预览使用 `npm run dev`，地图交互测试使用 `npm test`。若要调整地名、图幅分组或脚程，编辑[地理资料](地理资料.js)。地貌与区域拾取共用[地形坐标](地形.js)。

页面使用 React 和 Vite，地形交互复用 Three.js 的 OrbitControls 和 Raycaster，图标来自 Lucide。vite-plugin-singlefile 负责生成离线页。
