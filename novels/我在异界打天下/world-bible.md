# 我在异界打天下｜世界设定

版本1.0，2026-11-14。世界规则、族群分类、势力与舞台的权威来源。未来事件在故事与卷战略中规划，不作为本页“当前事实”。

## 世界前提

主舞台为武元大陆，属于武元界。人间诸国、森林山地、海疆和地底均在同一世界之内；地底不自动等于幽冥，出海也不自动等于跨界。武元界之外有自然洞天、附属小界及独立诸天世界。界海是世界之间的空间环境，不是一片可以普通帆船航行的海。

天地存在可供多种修行利用的灵气。神师以神识、法印、咒诀与术式驾驭灵气；武修锻炼身体承载并形成真罡；《源天》保留内炼与跨道联结的方法。三者有交叉，稀缺的是可实践的知识、观测与长期投入，而不是一方天生聪明、其他文明全无研究。

山川神祇、神宫、王朝和上界神朝是不同组织。部分神术依赖受箓与借法，更多术式可以由修炼者自行掌握。界潮为自然空间变化；原有界关与盟约确实降低旅行风险，也使掌握它们的势力拥有征收与干预能力。

| --- | --- | --- | --- |
| RACE-HUMAN | 人族 | 王朝、宗族、太学、宗门、军府、行会 | 治理方式与修行路线不只有一种 |
| RACE-FOX | 妖族中的灵狐族 | 稳定血脉族群，拥有祖地、圣庭、祠老与外部商路；长于感知、幻术、药性与山林阵禁 | 尾数是血脉显化之一，不直接等于阶位；不同族人各有专业 |
| RACE-YAO | 万妖各族 | 包含世代传承的妖族，也接纳有自主认知、学习礼法与建立关系的开灵个体；形成不同族群与组织 | 外形、是否化人形不决定智慧或道德；万妖工坊是组织，不是单一物种 |
| RACE-MO | 魔族 | 长期适应地火与重浊灵气的古老血脉族群，具有不同体貌与承载特点；炉城、师承与炉契重要 | 魔族不等于“修炼入魔的人”；有神师、武修、工匠与普通居民，不保留矮人体型模板 |
| RACE-HIDDEN | 地底隐族 | 古代迁入地下并形成独立传承的族群；维护祖城、水脉、井道与旧史 | 是活着的智慧居民，与鬼魂、地底妖兽、灵狐族分开 |
| RACE-BEASTKIN | 兽人诸部 | 以稳定兽裔血脉与部族传承形成的北荒诸部，经营迁徙、放牧、贸易与战争 | 与万妖各族可有血缘历史交叉，但按自身认同、族籍与政治组织区分；并非统由一个兽王控制 |
| RACE-FEATHER | 羽民诸部 | 天生有羽的智慧族群，拥有山巅与海岛聚落、飞行和测风传统 | 羽民是族群；巡界神将是职务，二者不能等同 |
| RACE-DI | 氐人与海国诸部 | 长期水居的智慧族群，发展水下城郭、潮路与交易制度 | 海国是政治体，不与所有水生生灵混称 |
| RACE-DRAGON | 龙族与蛟属 | 与山泽、水脉、云雨相关的多支血脉，形成龙宫或独立领地 | 智慧龙族有自己的承诺与产权；蛟、龙的名号不单独决定具体修为 |
| RACE-NETHER | 幽冥诸类 | 保有记忆的幽冥遗民、受役阴兵、祖灵及无自主意志的构装分别登记 | 肉身死亡、元神受损、残念与完整人格不能互相替代 |

灵兽是用于叙述特定生灵的通称，不能据此认定其属于任何人的财产。驳兽保有自己的意愿与习性；契约必须说明能做什么、双方承担什么，不能升级成无边界心灵控制。

## 核心世界规则

| ID | 允许与作用 | 禁止或边界 | 代价、验证与剧情用途 |
| --- | --- | --- | --- |
| RULE-POWER | 共同阶位为一至九阶、圣阶、神域；可跨修 | 神师、武修是路线；帝君、神君、武圣中的职号或尊号不能随意兑换成新境界 | 公共名声与实际战力分别核对，跨修增加训练和资源成本 |
| RULE-DOMAIN | 神域境可形成由自身修为支撑的法域 | 不意味着能在任意距离改写世界，也不自动控制别人的法域 | 范围、持续、精度、环境适配与锚点各有限制；脱离锚点仍有自身战力但战略覆盖下降 |
| RULE-ADVANCE | 神域之后继续提升掌握度、承载、稳定性及多锚协同 | 本版不追加“神域之后突然九个新境界”；多年积累仍有真实优势 | 卷九新入神域与资深强者的差距，通过具体能力表现；同盟和战场准备不能取代自身修炼 |
| RULE-ART | 神术可由独立修炼者学习；借法神术是另一个有契约条件的分支 | 不把所有神师写成依赖神明赐力的信徒 | 神师以神识定位、灵元承载、印诀组织；被夺借法资格不等于失去全部自修力量 |
| RULE-BODY | 武修以气血、筋骨、窍穴与真罡承载力量 | 强健身体不等于免疫全部精神、环境或术式影响 | 伤势、疲劳、距离与护具会影响战斗；武技需要训练 |
| RULE-DAO | 《源天》保存少量可实践的内炼与联结方法 | 不提供现成工业体系、敌人名单、无限丹方或预言；高考知识不等于发明家与统帅经验 | 以观察、试验和异界专业者协作完成；部分方法缺少本地对应材料 |
| RULE-SIGHT | 第二视野来自古修观测训练，可看已进入感知范围的气机变化 | 不读心、不看未观测的内部、不自动判断真假、不知道敌人未施展的能力 | 使用会疲劳；混乱信号、假节点、纯力量与环境变化可反制；需要校准 |
| RULE-TRANSFER | 出生时护魂残印与意识相合；转移是偶发界潮结果 | 陆昊不是已指定的古神转世；不自动获得原主人经验；不承诺自由往返现代 | 卷八至十以实物、记录和观测互证来源，角色当时不知道的答案不能提前泄露 |
| RULE-REGISTRY | 神籍记录受箓、借法及部分跨界契约 | 未入神籍的普通人很多；“没有神名”不能带来普遍神术免疫，更不能通过删名抹杀生命 | 对既有契约可暂停授权、追索约定资源；强制征召与非法扩张仍需具体执行者 |
| RULE-BIRTH | 护生祝祭只是一次有限防护，不等于替孩子签终身神契 | 不把新生儿灵印异常解释为所有神明都已知道他的身世 | 残卷护魂印与本地印式不完全兼容；陆昊微调自保，现场成人完成泄压 |
| RULE-ENERGY | 灵晶、火髓、雷晶、寒玉等可储能或提供属性材料 | 转化有损耗；见到图纸不等于已有产能；力量不可无限叠加 | 纯度、材料寿命、恢复时间和工匠能力进入计划；库存与产量区分 |
| RULE-FORMATION | 阵法可组织已有力量、扩大防护或改变局部条件 | 大量低阶者不能凭意愿无条件击杀高阶；破一个节点不等于全部敌人消失 | 需要阵基、协同、供能与保护；敌可改路线、断补给或毁阵基 |
| RULE-BEAST | 可与愿意合作的生灵订立有范围的契约 | 不以结契自动获得永久服从或全部能力 | 食物、伤势、习性、配合与双方选择持续生效 |
| RULE-SOUL | 灵魂保存、元神受伤、祖灵与复生分别建立证据 | 不从“有残念”推出完整人格健在；终战胜利不自动复活所有人 | 个别保魂需要事先具备方法、载体与时限；不能临场借用别人的特殊机制 |
| RULE-GATE | 通天渡需要已核对坐标、两端阵基、供能与稳定窗口 | 不能随念前往未发现世界；探测、货运、人员通行的门槛不同 | 容量、排队、恢复、出口安全与返程储备决定战争规模 |
| RULE-DESCENT | 上界强者可经适配界门或有限投影干预武元大陆 | 不能零成本在任意城池完整降临；出手不等于所有神庭都同意 | 不同世界的灵机会排斥不适配法域；需要锚点、时间和供能；早期投影范围小且可追踪 |
| RULE-TIDE | 界潮是自然空间变化，观测可改善预测 | 不是终局敌人制造的所有灾害；预测不保证精确无误 | 各地独立记录互证，误差与极端条件必须保留 |
| RULE-CHARTER | 家族、封地、王朝与族群各有权责范围 | 爵位不等于无限土地、无限忠诚或任意征用；盟约不是自动归附 | 人口、粮食、薪饷、维护与争议处理是胜利后的责任 |
| RULE-SUCCESSION | 陆家为异姓军功王族，陆景珩为世子；陆昊另获试治与正式封地 | 陆昊不得在未发生继承变更时自称世子；新朝帝位不能偷换成王府继承 | 试治授权限额明确；建国后公开安排旧爵与新职 |
| RULE-AGENCY | 重要伙伴有独立目标、专业能力和拒绝权 | 不把恋爱、救命之恩、种族或签约当作永久服从依据 | 关系会改变陆昊选择，并给人物真正完成自己职责的机会 |

## 阶位的可见表现与称谓

| 层次 | 神师侧重点 | 武修侧重点 | 公共作用 |
| --- | --- | --- | --- |
| 一至三阶 | 少量印诀、局部感知、稳定施展基础术式 | 体魄基础、气血运行、兵器基本技 | 学徒、基层修炼者 |
| 四至六阶 | 组合术式、较复杂感知与局部阵式 | 真罡渐成、技法与身体承载配合 | 精锐、护卫、基层统兵骨干 |
| 七至九阶 | 高阶术式与多人协作、重要城防职责 | 成熟罡劲、独立战场任务 | 一方强者；阶位不能替代指挥能力 |
| 圣阶 | 成熟本命术式与真意 | 成熟武道真意、强大承载 | 大陆公开的战略强者，需要考虑城防与供给 |
| 神域 | 形成并维护自身法域 | 以身与真意支撑法域 | 可参与上层世界竞争；自身修为、神职资源与外部锚点分开记 |

“武圣”是圣阶武修常见尊称；神师可被称为“圣阶神师”。“域主”可以是神域强者的社会称呼，但不自动拥有一片领土。“帝君、神君”属于神朝职号，任职者实际实力另记。术式品阶与施术者阶位不是同一张表，禁术也不天然高于一切常规神术。

## 器物、生灵与军队的发展

驳兽为陆昊第一头重要契兽，原典形象可供参考，具体成长能力由本书定义。它前期负责山地机动与近战协作，不具狮鹫的飞行能力。空中侦察由伙伴、灵禽与后续御风舟承担，避免换名后继续沿用旧能力。

个人器物：符箓、护脉环、成长兵器断潮枪。领地资产：守城阵、分段刻纹器具、材料处理与工坊。国家资产：符甲、重型法器、御风舟和浮空楼船。跨界资产：界桥基座、通天渡和界关。每项均需材料、制作、测试与维护。

军队逐步形成靖河卫、契兽游骑、赤炉重装、远射营、符阵工兵、界舟水师。组织名称不是种族所有权；人员可跨族，任务按专业分配。早期只有小队与护卫，军团规模随实际人口、供给和训练增长。

## 开篇公共状态

- WORLD-START-01：大周仍统治相关地区；陆家是受封的异姓王族，陆景珩为世子。
- WORLD-START-02：临川领尚未交陆昊治理，大昭尚不存在，没有跨族同盟或通天渡已建成。
- WORLD-START-03：神宫存在真实服务与政治利益；各地神师可以独立修炼。
- WORLD-START-04：陆昊出生时身体脆弱，仅能做最小内息调整；没有成熟武技、第二视野熟练度或可调用军队。
- WORLD-START-05：世界存在上层通行规则，但开篇人物只知道各自接触到的部分。作者设定不可直接变成人物百科。
