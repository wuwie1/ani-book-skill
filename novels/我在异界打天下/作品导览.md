## 这一版写什么

杨硕刚走出高考考场，便胎穿为大周淮北王府的幼子陆昊。他以天生神识压住惊兽，初巡临川时救下九阶龙马，得到一个能陪他打天下的伙伴。多年后，陆昊沿着失踪船工的线索追进地底，曾跟他争泊位的人却叫出了他的地球旧名。

番茄男频东方山海玄幻爽文，现代人胎穿、异界大陆、多族经营与战争、诸天争霸。预计12卷、960章、平均每章2600字，约249.6万字。

## 关键设定速览

- **主角**在地球叫杨硕，在武元大陆叫陆昊。首卷第3章进入十二岁主线，卷末十四岁离府赴任。
- **家族：**父亲陆峥为淮北王，母亲沈令仪主持医署，祖父陆砚山为圣阶武修，祖母许文瑛为八阶神师；兄长陆景珩是世子，陆昊另获封地。
- **灵压与契兽**　陆昊以天生神识施放灵压，给遭围杀的龙马争来一瞬。龙马亲自击杀九头蛇和赤尾蝎，双方依约结契。《源天》另授内炼与联纹。
- **力量**从一阶到九阶逐级对应。两路九阶之上同称圣阶、神域，常人入圣方可修习灵识。帝君是神朝职号。
- **东方舞台**从王府、临川、山地诸族与海疆延伸到武元界地底旧关。在那里与潮生界的一处渡区初结互助，往后才有通天渡和诸界共同防线。
- **感情：**多位重要女性，一条程见秋主线；少年先建立信任，成年后确认感情，第七卷成婚；其他女性保有独立事业与选择。
- **权力结果：**第七卷建立大昭并称帝；后续提升界路与共同防御能力，终局保有帝位及实力，不把所有盟友写成附庸。

## 十二卷一眼看完

王府争资格 → 临川结龙马、建根基 → 山海结盟 → 北境成军 → 东海开路 → 地底联邻界、入圣、闻旧名 → 建立大昭 → 通天渡运行 → 入神域、立足上界 → 联合诸界 → 守关转反攻 → 战胜司契帝君、山河与关系收束。

每卷的精确章节预算、时间跨度、成长窗口、实际得失和伏笔职责均在卷战略中；此页只作导航，不另立第二份可编辑设定权威。

## 保存与接续边界

本地权威为各模块 Markdown 与 `小说状态.yaml`；指纹、用量汇总和恢复记录为状态与检验材料。人物档案以十二岁主线为主要基准，出生段必须按年龄和当时能力回读；未来事件都仍是计划，不能作为已发生连续性。

11月17日的首章系统试稿曾取得自动审校通过，独立审读仍记录了人物知情越界等问题。历次试稿仅供读感对照。正式章节采用作者选定的版本，已提交连续性见[小说状态](小说状态.yaml)。

两项拆书不再重做。来源与旧路径映射见参考说明，仓库旧分析报告中的历史新书定位不覆盖本包的最新作者决定。完整档案以外的储备角色，在进入对应卷前深化，不一次性预写所有远期人物。
