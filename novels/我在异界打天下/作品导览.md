# 《我在异界打天下》作品导览

高三学生杨硕因一张署名讲义跟昔日同桌齐源上了同一班车。再睁眼，他成了大周淮北王府的幼子陆昊。十二岁，他能看出一盏军灯不对劲。十四岁，离开他管的小渡场三天，最后一班船仍然照开。他带着这份成绩去临川，开始有自己的地、自己要养活的人。

本书是男频东方山海玄幻爽文，按番茄连载规划。全书十二卷、960章，预算约249.6万字。当前可写第一章《明天我自己讲》，尚无正式验收正文。

## 十二卷的路

王府争试治资格 → 临川结契龙马、取得封地 → 山海结盟 → 北境成军 → 东海开路 → 地底收服阴月、联络邻界、入圣 → 建大昭 → 通天渡试航 → 入神域、立足上界 → 诸界结盟 → 守关转反攻 → 战胜司契帝君、战后立约。

陆景珩是淮北世子，陆昊的临川封地另有授予。程见秋是主感情对象，两人在卷四成年后确认感情，卷七成婚。大昭接掌原大周主体，各族仍能决定是否加入盟约。
