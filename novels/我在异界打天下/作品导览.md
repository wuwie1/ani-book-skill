# 《我在异界打天下》作品导览

## 上架简介

大一下学期的五月二十号，富二代齐源在校门口表白被拒，转头指着杨硕说，你早就知道她喜欢你。她发来消息，明天亲手把信给他。当晚公交被撞，他再没等到明天。

再睁眼，他是淮北王府的幼子陆昊，生来带着寻常人入圣阶才有的神识，全家只当这孩子学东西快。

七岁，他接住一盏泼出去的水。十二岁，他当众说军府验过的货是坏的。十四岁，他带着一纸试治令去临川，在那里和一匹九阶龙马谈成了契约。

从一个渡口到一座城，从大昭立国到打上神域。这一世他做成的事，一件都不许别人拿走。

## 现状

本书是男频东方山海玄幻爽文，按番茄连载规划。全书十二卷、960章，预算约249.6万字。当前可写第一章《他说我偷了他的稿》，尚无正式验收正文。前三章章名为《他说我偷了他的稿》《泼出去的水，他接住了》《这批军晶不能发》。

## 十二卷的路

王府争试治资格 → 临川结契龙马、取得封地 → 山海结盟 → 北境成军 → 东海开路 → 地底收服阴月、联络邻界、入圣 → 建大昭 → 通天渡试航 → 入神域、立足上界 → 诸界结盟 → 守关转反攻 → 战胜司契帝君、战后立约。

陆景珩是淮北世子，陆昊的临川封地另有授予。程见秋是主感情对象，两人在卷四成年后确认感情，卷七成婚。大昭接掌原大周主体，各族仍能决定是否加入盟约。
