# 我在异界打天下｜世界设定

2026-11-24 修订。世界规则、族群分类、势力与舞台的权威来源。未来事件在故事与卷战略中规划，不作为本页“当前事实”。

## 世界前提

主舞台为武元大陆，属于武元界。人间诸国、森林山地、海疆和地底均在同一世界之内；地底不自动等于幽冥，出海也不自动等于跨界。武元界之外有自然洞天、附属小界及独立诸天世界。界海是世界之间的空间环境，不是一片可以普通帆船航行的海。

天地灵气可供多种修行。神师以灵元催动法印、咒诀与术式，靠耳目、符具和阵盘定位。武修从筋骨气血练到真罡。两条路线都须越过九阶，晋入圣阶才可开始修习灵识。《源天》保留内炼与跨道联结的方法。

山川神祇、神宫、王朝和上界神朝是不同组织。部分神术依赖受箓与借法，更多术式可以由修炼者自行掌握。界潮为自然空间变化；原有界关与盟约确实降低旅行风险，也使掌握它们的势力拥有征收与干预能力。

## 阶位的可见表现与称谓

| 共同境界 | 神师的同阶表现 | 武修的同阶表现 |
| --- | --- | --- |
| 一阶 | 凭印诀点起一簇灵火 | 定桩引气血，稳持兵器 |
| 二阶 | 能收放基础术式，换手后仍能续上 | 行步运劲，移动中能保持发力 |
| 三阶 | 基础术式在外力干扰下仍能施稳 | 气血贯通肢体，受力时能稳住兵器 |
| 四阶 | 先后衔接两道术式 | 初成真罡，可护持一处要害 |
| 五阶 | 更换施术位置仍能维持组合 | 移步交手时可将真罡送至兵刃 |
| 六阶 | 能主持一座局部阵式 | 连续攻守间维持罡劲，可护住身边人 |
| 七阶 | 能独立施展高阶术式 | 罡劲收发自如，能独守一处阵位 |
| 八阶 | 能统筹多处阵位、及时调节供能 | 强攻中仍能分配劲力，持续守住一段战线 |
| 九阶 | 可担主阵、承受大术回冲，仍凭印器定位 | 全身真罡收束如一，能独当正面强敌 |
| 圣阶 | 本命术式凝成真意，开始具备修习灵识的资格 | 武道真意成形，同样开始具备修习灵识的资格 |
| 神域 | 由本命术式与真意展开、维持自身法域 | 以身与真意支撑自身法域 |

灵识是修行者用自身魂力向外感知的本领。陆昊因胎穿生来魂力强，幼时先显在听觉与注意力，七岁学会把同一道凝水诀稳在一片将散的水上。长大后他才学会有意收放神识，压向灵兽时称为灵压。其余人到圣阶才有资格学灵识。祖母许文瑛是八阶阵师，她靠阵片、短尺和多地观测校验旧图。

“武圣”是圣阶武修常见尊称；神师可被称为“圣阶神师”。“域主”可以是神域强者的社会称呼，但不自动拥有一片领土。“帝君、神君”属于神朝职号，任职者实际实力另记。术式品阶与施术者阶位不是同一张表，禁术也不天然高于一切常规神术。

## 器物、生灵与军队的发展

龙马是陆昊赴临川后收下的第一头重要契兽，初遇时已有九阶实力。养伤时它先替新主人守渡，能长途奔行后才与他巡边、救援失联船队。领地买不到第二匹这样的龙马，契兽游骑须逐头磨合。

个人器物：符箓、护脉环、成长兵器断潮枪。领地资产：守城阵、分段刻纹器具、材料处理与工坊。国家资产：符甲、重型法器、御风舟和浮空楼船。跨界资产：界桥基座、通天渡和界关。每项均需材料、制作、测试与维护。

军队逐步形成靖河卫、契兽游骑、赤炉重装、远射营、符阵工兵、界舟水师。组织名称不是种族所有权；人员可跨族，任务按专业分配。早期只有小队与护卫，军团规模随实际人口、供给和训练增长。

## 开篇公共状态

- WORLD-START-01：大周仍统治相关地区；陆家是受封的异姓王族，陆景珩为世子。
- WORLD-START-02：临川领尚未交陆昊治理，大昭尚不存在，没有跨族同盟或通天渡已建成。
- WORLD-START-03：神宫存在真实服务与政治利益；各地神师可以独立修炼。
- WORLD-START-04　陆昊出生时已有神识，身为现代学生只认得前世经历。五岁以后学法印，七岁才第一次在旁人面前施术见长。少年时又学会把灵压朝一头兽放出、收回。
- WORLD-START-05：世界存在上层通行规则，但开篇人物只知道各自接触到的部分。作者设定不可直接变成人物百科。

地图附图中的“隐城”指地底旧城。分水室、汲水池和高廊是空间位置，住户和通行权按地底三方及当地小势力分别落实。
